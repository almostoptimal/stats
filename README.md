# stats

统计学习笔记。

## 教材精读

《Advances in Financial Machine Learning》（López de Prado, 2018）分章笔记，梳理金融机器学习的统计对象、泛化控制与投资系统落地。

- [AFML 第 2—5 章：统计哲学、统一逻辑与量化实务](notes/AFML-第2-5章-统计哲学与量化实务.md)：依次改造样本、标签、权重与特征——活动时间 bars 与 imbalance bars、三重障碍法与 meta-labeling、并发与唯一性权重、分数差分保平稳，附每章的边界意识与批判性分析。
- [AFML 第 6—9 章：泛化控制与研究哲学](notes/AFML-第6-9章-泛化控制与研究哲学.md)：主线是防止把历史偶然性当作稳定规律。集成与交叉验证的改进（purging、embargo、时间切分），以及回测过拟合的计算与信息论度量。
- [AFML 第 10—16 章：从预测到投资系统](notes/AFML-第10-16章-从预测到投资系统.md)：把统计输出接入资本决策，覆盖仓位管理、可执行回测、不确定性诊断、失效风险与组合配置，形成「预测 → 仓位 → 回测 → 诊断 → 配置」的完整链条。

## 决策理论

- [未知世界中的最优动态决策：从强化学习到人生选择](notes/未知世界中的最优动态决策-从强化学习到人生选择.md)：沿无面板游戏的三轮讨论，解释如何认识未知、何时冒险，以及怎样面对变化中的目标与自我。保留完整案例与逐步论述，以思想和哲学为主，突出认知谦逊、行动责任、未来选择权与价值反思；少量公式置于可选附录，并逐一解释变量和适用前提。
- [决策科学的统一框架：复杂性、结构假设与有限理性](notes/决策科学的统一框架-复杂性结构假设与有限理性.md)：以「统一决策形式 → 复杂性 → 信息与识别 → 结构假设 → 具体方法 → 误差分解 → 实践流程」为主线，串联 MDP/POMDP、决策充分表示、预测与因果的区别、Regret 分解上界与计算资源配置，最后给出面对新问题的工作框架与常见误区。
- [DFL 理论笔记：目标、梯度、统计保证与论文导读](notes/决策导向学习-DFL理论.md)：以线性目标的 predict-then-optimize 为主线，扩展到非线性优化、组合决策与部分反馈，讨论可微优化、平滑与 surrogate 等路线，并附代表性文献导读。
- [端到端学习与 DFL：以 Coin Treatment 为例](notes/端到端决策学习-以金币档位为例.md)：从不同金币档位的 CTR 预测走到净利润决策，说明何时值得引入 DFL，附单位、因果识别与估计误差方面的适用条件。

## 统计思想与方法论

- [现代统计思想：复杂理论背后的统计哲学](notes/现代统计思想-复杂理论背后的统计哲学.md)：按目标与识别、推断与误差控制、决策与适应组织现代统计的重要思想，涵盖贝叶斯、高维、鲁棒、半参数因果、依赖、信息论、分布漂移与在线学习。
- [选择与估计分离：从赢家诅咒到算法内部的偏差](notes/选择与估计分离.md)：一条主线贯穿十个场景与算法内部。先用墨西哥湾租约拍卖与全基因组关联分析把“先筛选、再估计”的机制算清，给出偏差量级 σ√(2 log M) 的一把尺子，并区分多重检验、回归到均值与误差传播；第三部分把同一结构落到 DQN 的最大化偏差、Causal Forest 的 honesty 与 cross-fitting，末尾给落手清单；误差传播（正交性、DML）与全部证明放在附录。
- [RCT 场景下的两类 CATE 难题：高价值稀有用户 vs 弱效应用户](notes/RCT下的两类CATE难题-高价值稀有用户与弱效应.md)：统一处理基线、因果效应与噪声的估计框架，解释稀有高价值人群缺少局部有效样本、弱效应场景缺少可辨识因果信号这两类难题及其应对。
- [从计算不可约性到科学方法：知道规律之后，我们还能知道什么？](notes/计算不可约性与科学方法.md)：从三体问题出发，区分「有公式」「可求解」「可预测」「可决策」四层困难，讨论解析几何、群论与统计力学的降维思路，并延伸到金融市场与 AI 科研的实践含义。
