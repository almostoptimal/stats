## 1. 设计哲学总纲

### 1.1 指标的本质：三次压缩

一个策略的完整信息是**一条净值曲线 + 全部成交明细 + 全部持仓序列 + 参数搜索过程**。指标是对它的**有损压缩**：

```
净值曲线（T 个数字）
   ↓ 压缩 1：降维（一阶矩、二阶矩、极值、路径依赖量）
少数统计量（收益、波动、回撤）
   ↓ 压缩 2：比值（把两维压成一维）
单个数（Sharpe / Calmar / IR）
   ↓ 压缩 3：与基准比（SR* = 0 或 1）
一个判断（显著 / 不显著）
```

**每一次压缩都丢信息**。压缩 2 丢掉了"收益来自哪里"（高 Sharpe 可能是卖波动率，可能是杠杆，可能是数据窥探）；压缩 3 丢掉了"经济意义上值不值"（显著不等于能覆盖成本与容量）。

> **实践第一原则**：任何单一指标都不能作为上线依据。至少要**三个正交维度**交叉验证：收益水平、风险/路径、稳健性（样本外 + 显著性）。

### 1.2 好指标的六条判据

评价一个指标"好不好"，用这六条：

| 判据 | 含义 | 反例 |
|---|---|---|
| **可估计性** | 样本内估计的标准误小、收敛快 | 高阶矩（峰度、尾部指数）需要极长样本 |
| **稳健性** | 对少数离群点、非正态不敏感 | 最大回撤由一个点决定，换个起始日就变 |
| **可解释性** | 能拆到"钱从哪来" | Omega 比率很难直观解释成"每天赚多少" |
| **单调性** | 收益变好 → 指标一定变好 | 含最大回撤的指标在"慢牛后大跌"时排序失真 |
| **可对冲/可归因** | 指标变化能对应到具体风险暴露 | 只报总波动率，无法知道是 beta 还是个股 |
| **抗操纵** | 很难通过"做账"刷高 | 用日频收盘价算波动率，天然被收益平滑低估 |

### 1.3 四类不变性（判断指标"合不合法"）

| 不变性 | 要求 | 违反的后果 |
|---|---|---|
| **杠杆不变** | 加杠杆不改变"质量"指标 | Sharpe 满足；Calmar 近似满足；**总收益、绝对金额不满足** |
| **时间尺度一致** | 换频率后排序不乱 | 年化必须显式声明；**波动率 √T 外推只在无自相关时成立** |
| **货币/单位不变** | 汇率、计价单位不影响 | 相对指标满足；金额指标不满足 |
| **现金流剔除** | 申赎不影响策略评价 | TWR 满足；**IRR/MWR 不满足**（它评价的是投资者，不是策略） |

### 1.4 指标的代价：估计误差

任何指标都是**估计量**，误差随样本长度 $`T`$ 收敛。几个关键量级：

- **均值（年化收益）**：$`\text{SE}(\hat\mu) = \sigma/\sqrt{T}`$。年化后 $`\text{SE} = \sigma_{\text{ann}}\cdot\sqrt{P/T}`$（$`P`$ 为每年期数）。
  → 年化波动 20%、5 年日频数据，年化收益的标准误仍有 **8.9%**。这就是"5 年业绩说明不了太多"的数学根源。
- **波动率**：$`\text{SE}(\hat\sigma) \approx \sigma/\sqrt{2T}`$，收敛快，可信度高。
- **Sharpe**：$`\text{SE}(\widehat{SR}) \approx \sqrt{(1+SR^{2}/2)/T}`$（正态近似）。
- **高阶矩（偏度/峰度）**：误差量级 $`\sim\sqrt{24/T}`$（峰度），$`T=250`$ 时标准误约 0.31，基本不可用。

> **实践结论**：**二阶矩（波动率、相关性）可信，一阶矩（收益、Alpha）勉强，高阶矩与极值（最大回撤、尾部）最不可信**。所以"用最不可信的指标做决策"（比如只看最大回撤选策略）是最危险的。

### 1.5 一条主线：三个递进的问题

| 层级 | 问题 | 指标族 | 失败模式 |
|---|---|---|---|
| L1 | 赚了多少？ | 收益类 | 承担了不可知的巨大风险 |
| L2 | 承担了什么风险？ | 风险类 | 只知道风险，不知道值不值 |
| L3 | 值不值？ | 风险调整类 | 忽略了"是不是运气" |
| L4 | 是不是运气？ | 显著性类 | **99% 的策略死在这里** |
| L5 | 能装多少钱？ | 容量/执行类 | 纸面很美，实盘被成本吃掉 |

## 2. 收益类指标

### 2.1 单期收益率

**意义**：所有指标的输入原料。选错定义，后面全错。

**公式**

$$r_{t}^{\text{simple}} = \frac{P_{t} - P_{t-1}}{P_{t-1}}, \qquad r_{t}^{\text{log}} = \ln\frac{P_{t}}{P_{t-1}} = \ln(1+r_{t}^{\text{simple}})$$

多资产/多期聚合用**对数收益可加**：

$$r^{\text{log}}_{0\to T} = \sum_{t=1}^{T} r_{t}^{\text{log}}$$

简单收益必须连乘：$`\prod(1+r_{t}) - 1`$。

**设计哲学**：对数收益是"可加的"，天然适合时间序列建模、正态分布假设、连续复利；简单收益是"可组合的"（资产加权平均 = 组合收益），适合横截面加总。二者差异在 $`|r|<5\%`$ 时可忽略，在极端行情下差很多（$`-50\%`$ 的对数收益是 $`-0.693`$）。

**实践指导**
- 建模、求相关性、做优化：用**对数收益**（更接近正态，可加）。
- 汇报业绩、算组合权重收益：用**简单收益**（可横截面线性加权）。
- 不要混用：把对数收益当简单收益做组合加权，会系统性**高估**组合收益。

### 2.2 累计收益与年化收益（CAGR）

**公式**

$$R_{\text{cum}} = \prod_{t=1}^{T}(1+r_{t}) - 1 = \exp\!\Big(\sum_{t} r_{t}^{\text{log}}\Big) - 1$$

$$\text{CAGR} = \left(\frac{V_{T}}{V_{0}}\right)^{1/Y} - 1, \qquad Y = \frac{\text{日历天数}}{365}$$

**设计哲学**：CAGR 用**几何**而非算术，是因为投资是复利过程，"先涨 50% 再跌 50%"的真实结果是 $`-25\%`$，算术平均说"0%"。CAGR 回答的是"如果我每年都按这个速度复利，最后会得到什么"。

**实践指导**
- 年化必须**用几何**，绝不可以用"月均 × 12"。
- 样本不足 1 年**不要年化**（或用明确标注的方式外推，误差爆炸）。
- 高频策略的年化数字最容易失真（外推倍数大、成本未计、容量未计）。

### 2.3 算术 vs 几何：方差拖累（Volatility Drag）

**公式**

$$\mu_{\text{geo}} \approx \mu_{\text{arith}} - \frac{\sigma^{2}}{2}$$

更精确的二阶展开：$`\ln(1+r) \approx r - \frac{r^{2}}{2}`$，故 $`\mathbb{E}[\ln(1+r)] \approx \mathbb{E}[r] - \frac{1}{2}(\mathbb{E}[r]^{2} + \sigma^{2})`$。

**设计哲学**：波动本身在没有亏损的情况下也会降低复利终值。这不是"风险溢价"问题，是**数学恒等式**。它解释了为什么会存在 Kelly 最优杠杆——杠杆放大 $`\mu`$ 是线性的，放大 $`\sigma^{2}`$ 是二次的，两者必有交点。

**实践指导**
- 年化 15%、波动 25% 的策略，几何收益只有 $`15\% - 3.1\% \approx 11.9\%`$。**回测用算术平均报收益，是最常见的"无意造假"**。
- 高波动策略（ crypto、CTA 单边、个股集中）必须显式扣方差拖累。
- 反过来：想提高几何收益，降低波动和降低尾部同样有效——这是分散化的数学辩护。

### 2.4 时间加权收益 TWR / 资金加权 IRR / Modified Dietz

**意义**：当有申赎现金流时，"策略赚了多少"和"投资者赚了多少"是两回事。

**TWR（Time-Weighted Return）**

$$\text{TWR} = \prod_{i=1}^{M}\left(1 + \frac{V_{i}^{\text{end}} - V_{i}^{\text{start}} - CF_{i}}{V_{i}^{\text{start}} + CF_{i}^{\text{in}}}\right) - 1$$

把现金流发生的时点切成子区间，链乘各子区间收益。

**设计哲学**：**剔除现金流影响**，把"策略能力"和"择时运气"分开。TWR 回答"基金经理水平如何"。

**MWR / IRR（Money-Weighted）**

$$\sum_{t}\frac{CF_{t}}{(1+\text{IRR})^{(t-t_{0})/365}} = 0$$

**设计哲学**：IRR 回答"**投资者实际拿到多少**"。顶部大额申购会拉低 IRR——这不是经理的锅，但钱确实少赚了。这就是"行为差距（behavior gap）"：基金收益率 10%，投资者收益率 6%。

**Modified Dietz（折中方案）**

$$r = \frac{V_{1} - V_{0} - CF}{V_{0} + \sum_{i} w_{i} \, CF_{i}}, \qquad w_{i} = \frac{D - t_{i}}{D}$$

其中 $`D`$ 是期间总天数，$`t_{i}`$ 是第 $`i`$ 笔现金流发生的天数。

**设计哲学**：不做区间切分（TWR 麻烦），也不做迭代求解（IRR 可能无解/多解），用一个**时间加权分母**近似。当现金流相对 AUM 较小（<10%）时精度足够。

**实践指导**
- **评价策略 → TWR；评价投资者/产品 → IRR（MWR）；日常运营估值 → Modified Dietz。**
- 自评策略时若用 IRR，等于把"运气好的申购时点"算进自己的 alpha，属于隐性自欺。
- GIPS 标准要求对外披露用 TWR。

### 2.5 收益分解：钱从哪来

$$R_{\text{total}} = \underbrace{\beta R_{\text{benchmark}}}_{\text{市场 beta}} + \underbrace{\alpha}_{\text{选股 alpha}} - \underbrace{C_{\text{trading}}}_{\text{成本}} - \underbrace{D_{\text{cash}}}_{\text{现金拖累}} - \underbrace{D_{\text{tax/fee}}}_{\text{费税}}$$

**设计哲学**：这是所有归因的出发点。**先扣成本再看 alpha**，否则就是在给券商打工。

**实践指导**
- 回测每一版都要输出"毛 alpha / 换手 / 成本 / 净 alpha"。**一个年化 12% 的策略，若换手 30 倍、双边成本 20bp，成本吃掉 6%**，剩下 6% 才是真的。
- 现金拖累常被忽略：股票多头 95% 仓位、现金 5%，牛市里每年拖 0.3–0.5%。

## 3. 风险类指标

### 3.1 波动率（Volatility）

**公式**

$$\sigma_{\text{period}} = \sqrt{\frac{1}{T-1}\sum_{t=1}^{T}(r_{t} - \bar r)^{2}}, \qquad \sigma_{\text{ann}} = \sigma_{\text{period}}\sqrt{P}$$

（$`P`$：日频 252、周频 52、月频 12）

**设计哲学**：把"价格变动的不确定性"压成一个数，用**二阶矩**是因为它是所有风险度量中最可估计的（标准误 $`\sigma/\sqrt{2T}`$）。它假设收益是**独立同分布**——这是它最大的软肋。

**实践指导**
- $`\sqrt{P}`$ 外推要求**无自相关**。若收益序列正自相关（常见于收益平滑基金、低流动性资产），$`\sqrt{P}`$ 会**低估**年化波动，从而**高估 Sharpe**。用 **Lo (2002)** 或 **Newey–West** 修正。
- 波动率是**对称**的：上涨的波动也算风险。这是它最主要的哲学缺陷（引出下行偏差）。
- 用**日内数据**或**GARCH/EWMA** ($`\sigma_{t}^{2} = \lambda\sigma_{t-1}^{2} + (1-\lambda)r_{t-1}^{2}`$，$`\lambda\approx0.94`$) 能捕捉波动聚集。

### 3.2 下行偏差 / 半方差（Downside Deviation）

**公式**

$$\text{DD}(\tau) = \sqrt{\frac{1}{T}\sum_{t=1}^{T}\big[\min(r_{t} - \tau,\,0)\big]^{2}}$$

$`\tau`$ 是目标收益率（MAR, Minimum Acceptable Return），常取 0 或无风险利率。

**设计哲学**：**投资者不会被"涨得太多"伤害**。下行偏差只对低于目标的部分计风险，是对波动率"对称性"的直接批判。半方差的思想来自 Markowitz 本人——他原本主张用半方差，只因计算困难才用了方差。

**实践指导**
- 目标是 0 时用 $`\tau=0`$；不要混用（$`\tau`$ 取值不同，Sortino 无法横向比较）。
- 分母用 $`T`$（全部样本数）还是"下行样本数"要统一。用 $`T`$ 更保守（下行样本少时分母不会变小）。
- 对**卖期权、卖波动率**类策略，下行偏差比波动率更能反映真实风险形态。

### 3.3 回撤族（Drawdown Family）

**最大回撤 MDD**

$$\text{MDD} = \max_{t}\left(1 - \frac{V_{t}}{\max_{s \le t} V_{s}}\right)$$

**相关指标**

| 指标 | 定义 | 说明 |
|---|---|---|
| 平均回撤 AvgDD | 所有回撤深度均值 | 反映"常态痛苦" |
| 回撤时长 MDD Duration | 峰到谷的时间 | 与净值无关的时间维度 |
| **恢复期 Recovery** | 谷回到前高的时间 | **最该看的指标**：客户真正赎回的触发点 |
| 水下时间 %TUW | 处于回撤状态的时间占比 | 客户体验的直接度量 |
| Pain Index | $`\frac{1}{T}\sum_{t} D_{t}`$（$`D_{t}`$ 为当期回撤） | 连续版平均回撤 |
| **Ulcer Index** | $`\text{UI} = \sqrt{\frac{1}{T}\sum_{t} D_{t}^{2}}`$ | **平方惩罚深回撤**，比 Pain Index 更敏感 |

**设计哲学**：波动率是"**瞬时**"风险，回撤是"**路径**"风险。回撤抓住了三件波动率抓不到的事：(1) 顺序（先跌后涨 vs 先涨后跌，波动率一样，回撤差很多）；(2) 持续（亏一年和亏一天完全不同）；(3) 心理（投资者按回撤做决策，不按标准差）。Ulcer Index 用平方惩罚深度，是"深度 × 时长"的乘积型痛苦度量。

**实践指导**
- **MDD 只由一个点决定，是极其不稳健的估计量**——$`\text{SE}`$ 大、对样本起止点极敏感。不要用它做策略间的精细排序。
- 用 **Ulcer Index 或 Pain Index** 做排序，用 MDD 做"最坏情况披露"。
- **必须同时看恢复期**：MDD 20%、3 个月恢复，和 MDD 20%、3 年不恢复，是两个完全不同的策略。
- 回撤用**日频收盘价**计算会低估（日内低点看不到）；真实账户按日内极值触发风控。

### 3.4 VaR（Value at Risk）

**公式**

- **参数法（正态）**：$`\text{VaR}_\alpha = \mu + z_\alpha \sigma`$（$`z_{0.05} = -1.645`$，损失取正值表达）
- **历史模拟**：$`\text{VaR}_\alpha = -\text{Quantile}_\alpha(\{r_{t}\})`$
- **Cornish–Fisher（修正偏度峰度）**：

$$z_{cf} = z + \frac{z^{2}-1}{6}S + \frac{z^{3}-3z}{24}K - \frac{2z^{3}-5z}{36}S^{2}$$

$$\text{VaR}^{CF}_\alpha = \mu + z_{cf}\sigma$$

（$`S`$ 偏度，$`K`$ **超额**峰度）

**设计哲学**：VaR 把"风险"翻译成"**一个金额**"，这是它成为监管标准的原因。它用**分位数**而非方差，抓住了"我只关心左尾"。但 VaR **不满足次可加性**（不是一致性风险度量），且**不告诉你尾部有多深**——这是它被 CVaR 取代的理由。

**实践指导**
- 正态 VaR 在**肥尾 + 负偏**市场下系统性低估。务必用 Cornish–Fisher 或历史模拟交叉验证。
- VaR 是**条件于当前持仓**的，不反映流动性（平不掉仓的 VaR 无意义）。
- 常见做法：$`95\%`$ VaR + $`99\%`$ VaR + 压力情景三者一起看。

### 3.5 CVaR / 期望损失 ES

$$\text{CVaR}_\alpha = \mathbb{E}\big[\,r \mid r \le -\text{VaR}_\alpha\,\big]$$

**设计哲学**："**如果真的发生了最坏的 5%，我平均亏多少？**" CVaR 是**一致性风险度量**（满足次可加性、可直接在优化中作为目标/约束，且线性化后可解），这是它比 VaR 优越的根本原因——它问的是尾部的**期望**，而非尾部**边界**。

**实践指导**
- 尾部样本极少（1% 分位、250 个日数据 = 2.5 个观测），**CVaR 估计噪声极大**。用更长样本或极值理论（POT / 广义帕累托）拟合尾部。
- 组合优化中优先用 CVaR 约束（Rockafellar–Uryasev 线性化），比方差约束更能控尾部。

### 3.6 偏度与峰度

$$S = \frac{\mathbb{E}[(r-\mu)^{3}]}{\sigma^{3}}, \qquad K = \frac{\mathbb{E}[(r-\mu)^{4}]}{\sigma^{4}} - 3$$

**设计哲学**：前四阶矩完整刻画分布形态。负偏 + 高（超额）峰度 = "**平时小赚，偶尔巨亏**"，这正是卖保险式策略（卖期权、套利、carry）的典型形态，也是 Sharpe 会骗人的典型场景。

**实践指导**
- 样本需求极大（峰度 $`\text{SE} \approx \sqrt{24/T}`$）。**不要只看峰度数值做决策**，要结合策略逻辑（该策略是不是天然卖尾部）。
- 判别规则：$`S < -0.5`$ 或 $`K > 3`$ 时，**Sharpe 一定不能单独用**。

### 3.7 压力测试与情景分析

**设计哲学**：所有统计指标都是"**基于历史分布**"的条件度量。压力测试是**无条件**的——不问"历史上跌了多少"，只问"如果发生 X，我亏多少"。它绕开了估计问题，代价是**主观性**。

**实践指导**
- 至少做三类：历史重演（2008、2015、2020-03、2022）、因子冲击（利率 +200bp、波动率翻倍、信用利差 +300bp）、相关性断裂（分散化失效，所有相关 → 0.9）。
- 输出必须是**金额**和**保证金可用性**，不只是百分比。

## 4. 风险调整收益指标

### 4.1 Sharpe Ratio（夏普比率）

**公式**

$$SR = \frac{\mathbb{E}[r_{p}] - r_{f}}{\sigma(r_{p} - r_{f})}, \qquad SR_{\text{ann}} = SR_{\text{period}}\sqrt{P}$$

**估计误差与检验**

$$\text{SE}(\widehat{SR}) \approx \sqrt{\frac{1 + SR^{2}/2}{T}}$$

**设计哲学**：Sharpe 的伟大在于**杠杆不变性**——加杠杆同时放大分子分母，比值不变。所以它度量的是"**策略的质地**"，而不是"你下了多大注"。它把"该下多少注"分离成独立问题（Kelly），这是金融学里少有的干净分解。

**实践指导**
- 年化用 $`\sqrt{P}`$，但**只在收益无自相关时成立**。
- **SR 的经典骗局**：
  1. 收益平滑（低流动性资产、 appraisal 估值）→ 波动低估 → SR 虚高；
  2. 卖尾部（负偏高超额峰度）→ 短期 SR 极高，尾部未到；
  3. 数据窥探（试了 100 个参数取最优）；
  4. 未计成本/容量。
- **阈值经验**（日频、多年、含成本）：$`SR<0.5`$ 无实用价值；$`0.5\text{–}1.0`$ 一般；$`1.0\text{–}2.0`$ 好；$`>2`$ 必须怀疑过拟合或卖尾部。**对冲基金长期中位数约 0.5–0.8**。
- **必配**：Sharpe 一定要配 PSR（见 §9.1）一起报。

### 4.2 Sortino Ratio

$$\text{Sortino} = \frac{\mathbb{E}[r_{p}] - \tau}{\text{DD}(\tau)}$$

其中 $`\text{DD}(\tau)`$ 是 §3.2 的下行偏差。

**设计哲学**：对波动率的直接修正——**上行波动不是风险**。适合收益分布不对称的策略。

**实践指导**
- 必须声明 $`\tau`$。常见错误：用 $`\tau = 0`$ 算一个策略、用 $`\tau = r_{f}`$ 算另一个，然后比大小。
- Sortino 的分母（下行偏差）**估计噪声比波动率大**（只用部分样本），小样本下比 Sharpe 更不稳。
- 用法：**Sharpe 做横向筛选，Sortino 做"卖尾部体检"**。若 Sortino ≫ Sharpe，说明上行波动大，需确认这不是卖期权。

### 4.3 Calmar / Sterling / Burke / Martin（回撤类风险调整）

$$\text{Calmar} = \frac{\text{CAGR}}{|\text{MDD}|} \quad(\text{通常取近 36 个月})$$

$$\text{Sterling} = \frac{\text{CAGR}}{\big|\overline{\text{MDD}}_{N} - 10\%\big|} \quad(\text{前 } N \text{ 大回撤均值，减 10\% 无风险基准})$$

$$\text{Burke} = \frac{\text{CAGR}}{\sqrt{\sum_{i} \text{DD}_{i}^{2}}}$$

$$\text{Martin (UPI)} = \frac{\text{CAGR} - r_{f}}{\text{Ulcer Index}}$$

**设计哲学**：这一族共享一个信念——**投资者真正承受的痛苦是回撤，不是波动**。Calmar 用最坏一次，Sterling 用前几次均值（降低单点敏感），Burke 用平方和（同时惩罚深度与次数），Martin 用连续回撤（不只看峰谷）。**演进方向就是"降低 MDD 单点不稳健性"**。

**实践指导**
- **Calmar 分母是单点估计量，噪声最大**。策略筛选时用 Martin 或 Burke 更稳，用 Calmar 做对外披露（因为大家看得懂）。
- Calmar 常用 36 个月窗口，短窗口会漏掉上一轮熊市。
- 经验值：Calmar > 1（即年化收益 ≥ 最大回撤）是**好 strategy 的分水岭**；CTA 优秀者 0.5–1.0，股票多头长期 0.3–0.5（因为回撤大）。

### 4.4 Omega Ratio

$$\Omega(\theta) = \frac{\int_{\theta}^{\infty}\big[1-F(r)\big]\,dr}{\int_{-\infty}^{\theta} F(r)\,dr} = \frac{\mathbb{E}[(r-\theta)^+]}{\mathbb{E}[(\theta-r)^+]} = 1 + \frac{\mu - \theta}{\mathbb{E}[(\theta-r)^+]}$$

**设计哲学**：**Sharpe 只用了一、二阶矩，丢掉了整个分布形状**。Omega 用了**整个分布**（分子是阈值以上的全部"面积"，分母是阈值以下的全部"损失面积"）。理论上它是对所有"关于 $`\theta`$ 的一阶随机占优"的一致度量。

**实践指导**
- $`\Omega(\theta) > 1 \iff \mathbb{E}[r] > \theta`$；$`\Omega(\theta)`$ 越大越好；它对 $`\theta`$ 单调递减。
- **必须比较同一 $`\theta`$** 才有意义。常取 $`\theta = 0`$ 或 $`r_{f}`$。
- 缺点：不可加、难解释、对样本外的尾部极度敏感。**用于"两个候选策略的最终 PK"，不用于日常监控。**

### 4.5 M²（Modigliani）与 Treynor

$$M^{2} = SR \cdot \sigma_{\text{benchmark}} + r_{f}$$

$$\text{Treynor} = \frac{\mathbb{E}[r_{p}] - r_{f}}{\beta_{p}}$$

**设计哲学**
- **M²**：把 Sharpe 翻译成"**如果按市场波动率加杠杆，年化收益是多少**"——从抽象比值变回百分比，解决"Sharpe 1.5 到底是多少收益"的解释难题。
- **Treynor**：分母用 **beta 而非总波动**——前提是"组合已充分分散，非系统性风险不定价"。这是 CAPM 的世界观。

**实践指导**
- 对外沟通用 M²，易懂。
- **Treynor 只在"充分分散的组合"之间比较才合法**。用它比较单只股票是错的（个股 beta 无法解释全部风险）。

### 4.6 风险调整指标选择速查

| 场景 | 首选 | 备选 | 不要用 |
|---|---|---|---|
| 通用横向筛选 | Sharpe (+PSR) | Martin | 单看收益率 |
| 卖尾部/负偏策略 | Sortino、CVaR | Omega(θ) | 单看 Sharpe |
| 绝对收益/CTA | Calmar、Martin | Burke | 单看 Sharpe |
| 长期持有型 | Sharpe + MDD + 恢复期 | Ulcer | Calmar 单点 |
| 与基准比 | IR | Treynor | Sharpe |
| 完整分布比较 | Omega | — | 只比二阶矩 |

## 5. 相对基准与归因指标

### 5.1 Beta 与 Alpha（Jensen's Alpha）

$$\beta = \frac{\mathrm{Cov}(r_{p}, r_{b})}{\mathrm{Var}(r_{b})}$$

$$\alpha = (r_{p} - r_{f}) - \beta (r_{b} - r_{f})$$

回归式（带标准误与 t 检验）：

$$r_{p,t} - r_{f,t} = \alpha + \beta (r_{b,t} - r_{f,t}) + \varepsilon_{t}$$

**设计哲学**：CAPM 的核心分解——**beta 是"市场给的"，alpha 是"自己挣的"**。Alpha 的定义本身就是"剔除了线性市场暴露后的残余"，这是一种**正交化**思想：先把能免费获得的风险溢价剥掉，再看剩余部分。

**实践指导**
- **必须报 t 值**：$`\alpha`$ 的年化估计误差很大（$`\text{SE}(\hat\alpha) = \sigma_\varepsilon/\sqrt{T}`$ 年化后 ×$`\sqrt{P}`$）。常见错误：年化 alpha 3%，t 值 0.8，等于没有。
- **beta 时变**：牛熊、波动率 regime 切换时 beta 会变。用滚动 beta 或多因子 beta。
- **伪 alpha**：很多"alpha"其实是未识别的因子暴露（小市值、低估值、动量、流动性、波动率、行业）。**先做多因子回归，再看残差 alpha**。
- $`\alpha`$ 的正负与基准选择强相关：选错基准，"alpha" 就是风格暴露。

### 5.2 跟踪误差 TE 与信息比率 IR

$$\text{TE} = \sqrt{\frac{1}{T-1}\sum_{t} (r_{p,t} - r_{b,t})^{2}} \cdot \sqrt{P}$$

$$\text{IR} = \frac{\mathbb{E}[r_{p} - r_{b}]}{\text{TE}}$$

**设计哲学**：TE 是"**主动风险的预算**"，IR 是"**每单位主动风险换来多少超额**"。IR 是 Sharpe 在主动管理语境下的对应物：**复利下，长期超额财富正比于 IR²**（与 §2.3 的方差拖累同源：$`\text{超额几何收益} \approx \alpha - \text{TE}^{2}/2`$，最大化即最大化 IR）。

**实践指导**
- IR 的显著性：$`t = IR \cdot \sqrt{T}`$（$`T`$ 为年数，IR 用年化）。**要 t > 2，年化 IR=0.5 需要 16 年数据**——这是残酷但真实的门槛。
- TE 预算要**写进投资合同**：TE 3% 与 TE 8% 是两个完全不同的产品。
- IR 经验值：0.5 优秀，1.0 极佳罕见。**主动股票基金长期 IR 中位数接近 0**。

### 5.3 主动份额、Capture Ratio、胜率

**主动份额 Active Share**

$$\text{AS} = \frac{1}{2}\sum_{i} |w_{p,i} - w_{b,i}|$$

**设计哲学**：回答"**你的组合和基准到底差多少**"。TE 是**结果**（事后波动），AS 是**结构**（事前持仓差）。低 AS + 高 alpha = 真正的选股能力；低 AS + 低 TE =  closet indexing（收主动管理费卖指数）。

**上下行捕获率（几何法）**

$$\text{UpCapture} = \frac{\big[\prod_{t \in \text{up}}(1+r_{p,t})\big]^{1/n} - 1}{\big[\prod_{t \in \text{up}}(1+r_{b,t})\big]^{1/n} - 1}$$

下行同理（用"基准下跌的月份"）。

**设计哲学**：把 beta 拆成"**涨的时候跟得上多少**"和"**跌的时候躲得掉多少**"。这是非线性 beta 的粗粒度刻画（UpCapture/DownCapture 差异大 → 存在凸性，典型如趋势跟踪）。

**胜率（Win Rate）与 IR 的关系**（二元近似：每期超额收益为 $`\pm s`$，胜率 $`p`$）：

$$\text{IR}_{\text{period}} \approx \frac{2p-1}{2\sqrt{p(1-p)}}$$

**实践指导**
- 这个公式极有用：$`p=0.55 \Rightarrow IR_{\text{period}} \approx 0.10`$，年化（月度）×$`\sqrt{12} \approx 0.35`$；$`p=0.60 \Rightarrow IR_{\text{period}} \approx 0.204`$，月度年化 $`\approx 0.71`$。
- **结论：胜率 55% 的策略并不稀奇，但配上适当的盈亏比才有价值**。
- 评估时**胜率与盈亏比必须一起看**：$`\mathbb{E} = p\cdot W - (1-p)\cdot L`$。
- Closet index 筛查：$`AS < 0.6`$ 且 $`\text{TE} < 2\%`$ → 高度疑似。

### 5.4 Brinson 归因（配置 / 选股 / 交互）

$$R_{p} - R_{b} = \underbrace{\sum_{i} (w_{p,i} - w_{b,i})(R_{b,i} - R_{b})}_{\text{资产配置}} + \underbrace{\sum_{i} w_{b,i}(R_{p,i} - R_{b,i})}_{\text{个股选择}} + \underbrace{\sum_{i} (w_{p,i} - w_{b,i})(R_{p,i} - R_{b,i})}_{\text{交互项}}$$

**设计哲学**：把超额收益拆成"**选对了哪个池子**"（配置）和"**在池子里选对了哪个**"（选股）。交互项的存在本身就说明二者不可完全分离——这是归因方法的诚实之处。

**实践指导**
- 多期要用 **Brinson–Fachler** 或 **Carino** 平滑链接，否则各期归因加总 ≠ 总超额。
- 归因必须在**同一层级**做（行业层 → 个股层分开做两层）。
- 对量化组合，归因应换成**因子归因**（Barra 风格）：市值、价值、动量、质量、波动率、流动性、行业。

### 5.5 Grinold 基本定律（Fundamental Law）

$$\text{IR} = \text{IC} \times \sqrt{\text{BR}}$$

IC = 信息系数（预测与实现的截面相关），BR = Breadth（独立预测次数/年）。

**设计哲学**：量化行业最重要的一条公式。它说明 **alpha 有两条路**：提高预测精度（IC），或提高独立下注次数（Breadth）。IC 提高很难（从 0.03 到 0.05 是巨大进步），但 Breadth 从 50 提到 500，IR 提升 $`\sqrt{10}=3.16`$ 倍——**这是量化相对主观投资的根本优势**。

**实践指导**
- 提高频率 = 提高 BR，但成本也随之线性上升。**净 IR 才是目标**：$`\text{IR}_{\text{net}} = \text{IC}\sqrt{\text{BR}} - \text{cost}(\text{BR})`$。
- 关键陷阱：**BR 不是"股票数"，是"独立赌注数"**。1000 只高度相关的股票，有效 BR 可能只有 10（见 §8.2 有效 N）。
- 带约束的推广：$`\text{IR} \approx \text{IC}\sqrt{\text{BR}} \times (\text{转移系数 TC})`$，TC 衡量约束（不能做空、仓位上限）吃掉多少 IC。

## 6. 交易与执行质量指标

### 6.1 换手率 Turnover

$$\text{TO}_{\text{one-way}} = \frac{\sum_{i} |\Delta w_{i}|}{2}, \qquad \text{TO}_{\text{two-way}} = \sum_{i} |\Delta w_{i}|$$

或金额口径：$`\text{TO} = \min(\text{买入额}, \text{卖出额}) / \text{NAV}`$（单向）。

**设计哲学**：换手率是**成本的代理变量**。它本身不是好事也不是坏事，它是"信号衰减速度"的直接映射——信号半衰期短就必须高换手。

**实践指导**
- **成本拖累估算**：$`\text{drag} \approx \text{TO}_{\text{one-way}} \times 2 \times (\text{半价差} + \text{冲击})`$。TO=10 倍、双边 30bp → 年拖累 3%。
- 换手率必须与**衰减曲线**对照（§7.4）：若信号半衰期 60 天却每天调仓，90% 的换手是白花的。
- 监控"**无效换手**"：交易了但组合风险暴露没变的交易量。

### 6.2 滑点与实现缺口（Implementation Shortfall）

**滑点**

$$\text{Slippage}_{i} = \frac{P^{\text{exec}}_{i} - P^{\text{decision}}_{i}}{P^{\text{decision}}_{i}} \cdot \text{sign}(\text{side})$$

**实现缺口（Perold）**

$$\text{IS} = R_{\text{paper}} - R_{\text{actual}} = \underbrace{C_{\text{delay}}}_{\text{决策到下单}} + \underbrace{C_{\text{spread}}}_{\text{价差}} + \underbrace{C_{\text{impact}}}_{\text{冲击}} + \underbrace{C_{\text{timing}}}_{\text{择时}} + \underbrace{C_{\text{opportunity}}}_{\text{未成交的机会成本}}$$

**设计哲学**：Perold 的贡献在于指出**机会成本是真实成本**——没买到的那部分，如果它涨了，你确实亏了。只看成交单的滑点会系统性低估总成本。

**实践指导**
- 回测必须**用决策价的下一根 bar 成交**（至少滞后 1 期），否则是前视偏差。
- 分项记录五项成本，才能知道问题出在信号延迟、算法、还是容量。
- **未成交也要记账**：机会成本可用"未成交部分 × 该标的后续 N 日收益"估算。

### 6.3 冲击成本模型

$$\text{cost} \approx \underbrace{\frac{\text{Spread}}{2}}_{\text{半价差}} + \underbrace{Y \cdot \sigma_{\text{daily}} \cdot \sqrt{\frac{Q}{\text{ADV}}}}_{\text{平方根冲击}}$$

$`Y \approx 0.3\text{–}1.0`$（经验系数），$`Q`$ 为成交量，$`\text{ADV}`$ 为日均成交量。

**设计哲学**：平方根律是实证发现的稳健规律——**冲击成本随规模的平方根增长，不是线性**，因为市场深度随价格偏离而增加。这意味着"规模翻倍，成本只涨 41%"，是容量估算的基础。

**实践指导**
- 自建成本模型：回归 $`\text{slippage} \sim a + b\sqrt{Q/\text{ADV}}`$，用自己真实成交数据标定 $`Y`$。
- 小盘股的 $`Y`$ 显著更大。**不要用大盘股的 $`Y`$ 去估小盘策略的成本**。

### 6.4 盈亏比、期望、Profit Factor

$$\text{Payoff} = \frac{\overline{W}}{\overline{L}} = \frac{\text{平均盈利}}{\text{平均亏损}}$$

$$\mathbb{E}[\text{per trade}] = p\cdot \overline{W} - (1-p)\cdot \overline{L}$$

$$\text{Profit Factor} = \frac{\sum \text{盈利}}{\sum |\text{亏损}|}$$

**设计哲学**：把策略看成"**下注系统**"，用赌博数学（期望为正 + 仓位管理）而非金融数学来分析。这对高频、日内、CTA、套利策略比对长期选股更贴切。

**实践指导**
- $`\text{PF} > 1`$ 是底线；$`>1.5`$ 可用；$`>2`$ 优秀（但要检查是不是靠少数极端盈利撑起来的）。
- **看 PF 必须看"最大单笔盈利占总额比"**：若一笔贡献 80% 利润，PF 无意义。
- 期望必须与**交易次数**一起看：单笔期望 0.1%、年交易 1000 次 = 年化 ~100%（未计成本与容量）；单笔 2%、年交易 20 次 = 年化 40%。

### 6.5 Kelly 准则与破产风险

**离散 Kelly（赔率 $`b`$，胜率 $`p`$，$`q=1-p`$）**

$$f^{\ast} = \frac{p\,b - q}{b} = p - \frac{q}{b}$$

**连续 Kelly**

$$g(f) = f\mu - \frac{f^{2}\sigma^{2}}{2}, \qquad f^{\ast} = \frac{\mu}{\sigma^{2}} = \frac{SR}{\sigma}, \qquad g^{\ast} = \frac{SR^{2}}{2}$$

**分数 Kelly**：$`f = c \cdot f^{\ast}`$，$`c \in [0.2, 0.5]`$ 实务常用。

**破产概率（等赔率赌博近似）**

$$P(\text{ruin}) \approx \left(\frac{q}{p}\right)^{B}, \quad p > q$$

（$`B`$ 为按单位下注计的资金量）

**设计哲学**：Kelly 是唯一在"**长期复利最大化**"意义下有理论最优解的仓位规则。它深刻的地方在于 $`g^{\ast} = SR^{2}/2`$——**长期增长率只取决于 Sharpe 的平方，与波动率无关**。这也是为什么杠杆后 Sharpe 不变但"能赚多少"变了（杠杆改变了 $`\sigma`$，而你要在 $`f^{\ast}`$ 上才拿到 $`SR^{2}/2`$）。

**实践指导**
- **全 Kelly 在实务中过于激进**：参数估计误差（$`\hat\mu`$ 的误差）会让全 Kelly 的实际表现远差于分数 Kelly。行业惯例 $`\frac{1}{4}\text{–}\frac{1}{2}`$ Kelly。
- Kelly 假设**参数已知且稳定**。现实中 μ 的估计误差极大 → 必须做**稳健 Kelly**（用 $`\hat\mu`$ 的置信下界，或对 $`\hat\mu`$ 做收缩）。
- 破产概率公式告诉你的实践事实：**即使期望为正，资金太薄也会必输**。风控第一问永远是"连续 N 次最坏情况，我死不死"。

### 6.6 成交率与参与率

$$\text{Participation Rate} = \frac{Q_{\text{strategy}}}{\text{Volume}_{\text{market}}}, \qquad \text{Fill Rate} = \frac{Q_{\text{filled}}}{Q_{\text{submitted}}}$$

**实践指导**
- 参与率上限：流动性好的大盘股 10%，中小盘 5%，薄流动性 1–2%。超过则冲击成本非线性上升。
- Fill rate 低意味着信号在"抢不到的单子上"——**幸存者偏差**：成交的都是对你不利的（逆向选择）。必须统计"未成交单的后续收益"。

## 7. 因子与信号指标

### 7.1 IC / Rank IC / ICIR

**定义（每一期截面）**

$$\text{IC}_{t} = \mathrm{Corr}\big(f_{i,t},\; r_{i,t+1}\big) \quad \text{(Pearson)}$$

$$\text{RankIC}_{t} = \mathrm{Spearman}\big(f_{i,t},\; r_{i,t+1}\big)$$

**汇总**

$$\overline{\text{IC}} = \frac{1}{T}\sum_{t} \text{IC}_{t}, \qquad \sigma_{\text{IC}} = \text{std}(\text{IC}_{t})$$

$$\text{ICIR} = \frac{\overline{\text{IC}}}{\sigma_{\text{IC}}}, \qquad \text{ICIR}_{\text{ann}} = \text{ICIR} \times \sqrt{P}$$

$$t(\overline{\text{IC}}) = \text{ICIR} \times \sqrt{T}$$

**设计哲学**：IC 是 Grinold 基本定律的分子，是**量化里最核心的单指标**。它的优雅在于：把"预测能力"和"波动率"完全分离，IC 只度量**排序的正确性**，不涉及仓位、杠杆、风险。Rank IC 用秩相关，是为了**对因子分布的极端值与非线性单调变换免疫**——这是极其重要的稳健化设计（一个因子的原始值可能有 1000 倍离群值，但秩不会）。

**实践指导**
- **优先用 Rank IC**：对离群值稳健，且直接对应"排序选股"这一实际操作。
- 阈值：IC 均值 0.02–0.05 已是**可用**的股票因子（月度）；0.05+ 很强；ICIR（月度）> 0.4 可用，> 0.6 优秀。
- **必须做 t 检验**：IC 均值 0.03、ICIR 0.3、60 期 → t = 2.3，勉强显著。IC 均值 0.03、ICIR 0.15 → t = 1.16，**等于没有**。
- **IC 序列的自相关**：若 IC 序列自相关，$`\sqrt{T}`$ 与 $`\sqrt{P}`$ 的缩放失效，用 Newey–West。
- **IC 为负也可能是好因子**（反向因子），但必须稳定为负，不能时正时负（那是噪声）。
- **本项目实证注记**（见 §14）：IC 均值 −0.107、t = −1.31，即"排序无效"——这正是 IC 检验的典型用法。

### 7.2 分层回测与单调性

**做法**：每期按因子值分 $`G`$ 组（常 5 或 10），计算各组下期收益 $`\bar r_{1}, \dots, \bar r_{G}`$。

**指标**
- 多空收益：$`\text{L/S} = \bar r_{G} - \bar r_{1}`$
- 单调性：$`\rho_{\text{mono}} = \mathrm{Spearman}(\text{组号},\ \bar r_{\text{组}})`$，理想接近 $`\pm 1`$
- 各组的信息比率、最大回撤

**设计哲学**：IC 是**压缩到一阶的线性度量**，分层回测是**展开看形状**。因子与收益的关系常是**非线性**的（U 型、只在头部有效、只在小市值有效），IC 会平均掉这些结构。分层回测回答："**这个因子是靠全区间起作用，还是只靠头尾 10% 起作用？**"——这直接决定你能用它做多空、还是只能做多头增强。

**实践指导**
- **单调性是比多空收益更强的稳健性证据**：单调的因子不容易是数据挖掘的产物。
- 必须看**多空组合的净值曲线**，不只是平均收益——很多因子 2015 年后就失效了，全样本均值掩盖了这一点。
- 分层要**等权重 + 行业中性**，否则测的是市值/行业暴露。

### 7.3 因子收益率与 Fama–MacBeth

**截面回归（每期）**

$$r_{i,t} = \lambda_{0,t} + \sum_{k} \lambda_{k,t} f_{k,i,t} + \varepsilon_{i,t}$$

**Fama–MacBeth 两步**
1. 每期做截面回归，得到 $`\hat\lambda_{k,t}`$（$`t=1..T`$）；
2. 对时间序列检验：$`\bar\lambda_{k} / \text{SE}(\bar\lambda_{k})`$，$`\text{SE}`$ 用 $`\text{std}(\hat\lambda_{k,t})/\sqrt{T}`$（或 Newey–West）。

**设计哲学**：解决**截面残差相关**（同一期股票的残差高度相关，OLS 标准误严重低估）的问题。Fama–MacBeth 把推断从横截面搬到时间序列，让标准误合法。这是"**用时间维度的独立性换空间维度的相关性**"的经典技巧。

**实践指导**
- 必须用 **Newey–West** 修正自相关（因子收益常有的）。
- 多元回归给出的是**该因子相对于其他因子的增量信息**——这才是你真正能收的钱。单因子 IC 高但多元回归不显著 = 该因子被其他因子完全解释。
- 标准化：因子值每期做**横截面标准化（去均值 / 除以标准差 或 排序标准化）**，否则 $`\lambda`$ 不可跨期比较。

### 7.4 因子换手与衰减（半衰期）

**自相关法**

$$\rho(h) = \mathrm{Corr}(\text{rank}_{i,t},\ \text{rank}_{i,t+h})$$

**半衰期**

$$h_{1/2} = \frac{\ln 0.5}{\ln \rho(1)} \quad (\text{若 } \rho(h) = \rho^{h})$$

**IC 衰减曲线**：计算 $`\text{IC}(h) = \mathrm{Corr}(f_{i,t}, r_{i,t \to t+h})`$，画成曲线。

**设计哲学**：这条曲线直接决定**最优调仓频率**——信号衰减快就必须快调仓，慢就可以慢调仓省成本。它与换手率、成本一起构成"频率三角"：$`\text{净收益} = f(\text{IC}(h)) - \text{cost}(\text{TO}(h))`$。

**实践指导**
- 调仓周期 ≈ 半衰期量级是最优的粗略起点，然后用成本模型微调。
- **常见错误**：日频调仓但因子半衰期 60 天 → 换手 250 倍，成本吃光 alpha。
- 用"**衰减加权的因子值**"（EWMA 混合历史值）可以降低换手而不损失太多 IC。

### 7.5 中性化与正交化后的 IC

**做法**：$`f^{\perp} = \text{残差}(f \sim \text{行业哑变量} + \ln \text{市值} + \text{其他因子})`$，再算 IC。

**设计哲学**：这是**去混杂（deconfounding）**。原始 IC 可能完全来自"因子恰好选中了小市值股"。中性化后的 IC 才是因子**独立**提供的信息。对称地，这也防止了组合在无意中押注某个风险因子。

**实践指导**
- **至少中性化市值和行业**（中国 A 股尤其：市值因子极强）。
- 中性化是双刃剑：若你的目标就是暴露某个风格（如小市值），中性化会把它去掉。**先想清楚要"纯 alpha"还是"风格 beta"**。
- 中性化回归用**加权最小二乘**（权重为市值平方根或流通市值），缓解异方差。

### 7.6 覆盖率与容量

$$\text{Coverage} = \frac{\text{有因子值的股票数}}{\text{股票池总数}}, \qquad \text{ADV 覆盖率} = \frac{\sum_{i \in \text{选中}} \text{ADV}_{i} \cdot w_{i}}{\text{AUM}}$$

**实践指导**：因子在"全市场有效、在可交易的前 500 只无效"是常见现象。必须**在可交易池上测 IC**。

### 7.7 因子拥挤度（Crowding）

**常用代理指标**
- **估值价差**：因子多头组的估值 − 空头组的估值（相对历史分位）
- **因子收益波动率**：近期波动突然放大 = 去杠杆风险
- **多空组合与其他因子的相关性上升**
- **成交额占比**：该风格股票的成交占比异常

**设计哲学**：拥挤的核心机制是**去杠杆的负反馈**——太多人用同一因子 → 头寸集中 → 一旦有一方被迫平仓 → 价格反向 → 所有人同时触发止损。**拥挤度不预测因子何时失效，但预测失效时的跌幅**。

**实践指导**
- 拥挤度是**风险指标不是择时指标**：用它做仓位缩减（$`w \leftarrow w \cdot (1 - \text{crowd\_penalty})`$），不要用它做反向交易（能拥挤很久）。
- 至少监控"估值价差的历史分位"这一个，性价比最高。

## 8. 组合与风险模型指标

### 8.1 协方差矩阵质量

**条件数**

$$\kappa(\Sigma) = \frac{\lambda_{\max}}{\lambda_{\min}}$$

**有效秩（Participation Ratio）**

$$\text{PR} = \frac{(\sum_{i} \lambda_{i})^{2}}{\sum_{i} \lambda_{i}^{2}}$$

**Ledoit–Wolf 收缩**

$$\Sigma_{\text{shrunk}} = (1-\delta) S + \delta \cdot \mu I, \quad \mu = \frac{\mathrm{tr}(S)}{N}$$

$`\delta \in [0,1]`$ 由数据决定（$`N/T`$ 越大，$`\delta`$ 越大）。

**设计哲学**：样本协方差在 $`N > T`$ 时**秩亏**（不可逆），在 $`N \approx T`$ 时虽然可逆但**病态**——优化器会把估计误差放大成极端权重（"error maximization"）。收缩的思想是**偏差-方差权衡**：用有偏但低方差的估计换更好的**样本外**表现。$`\delta \to 1`$ 就是放弃所有结构信息（等权/等风险）。

**实践指导**
- **经验法则**：$`T/N > 10`$ 才勉强能用样本协方差；$`T/N < 3`$ 必须收缩或因子化。
- 条件数 $`\kappa > 1000`$ 时优化结果基本不可信，必须正则化（收缩、PCA 降维、因子模型）。
- **先看 PCA**：若 PC1 解释了 80%+ 的方差（本项目实证 87.8%），说明组合的本质是"一个 beta + 噪音"，应该**在因子层面处理风险，在残差层面做分散**。
- 相关矩阵用**同步数据**估计：异步交易（不同市场、不同流动性）会低估相关性（Epps effect）。

### 8.2 分散度指标

**分散化比率**

$$\text{DR} = \frac{\sum_{i} w_{i} \sigma_{i}}{\sigma_{p}} = \frac{\mathbf{w}'\boldsymbol{\sigma}}{\sqrt{\mathbf{w}'\Sigma\mathbf{w}}}$$

**有效持仓数**

$$N_{\text{eff}}^{\text{weight}} = \frac{1}{\sum_{i} w_{i}^{2}}, \qquad N_{\text{eff}}^{\text{risk}} = \frac{1}{\sum_{i} (\text{RC share}_{i})^{2}}, \qquad N_{\text{eff}} \approx \text{DR}^{2}$$

**集中度 HHI**

$$\text{HHI} = \sum_{i} w_{i}^{2}, \qquad \text{Top-}N = \sum_{i=1}^{N} w_{(i)}$$

**设计哲学**："我持有 500 只股票" ≠ "我分散了 500 个风险"。若这 500 只高度相关（同一个 beta），实际只有 **1 个赌注**。有效 N 把"名义分散"换算成"**独立赌注数**"，直接代入 Grinold 基本定律的 BR。这是把第 7 章和第 8 章连起来的桥。

**实践指导**
- **$`N_{\text{eff}}`$ 才是 BR 的正确输入**：$`\text{IR} = \text{IC} \times \sqrt{N_{\text{eff}}}`$（而非股票数）。
- DR = 1 意味着完全没有分散（等同单一资产）；DR = $`\sqrt{N}`$（等权且不相关）是理想上限。
- **用风险维度的 $`N_{\text{eff}}`$**：权重分散但风险集中在少数几个高波动标的，风险维度会暴露这个问题。
- 监控 Top-10 权重和：超过 40% 时应检查是否有隐性集中。

### 8.3 风险贡献与风险平价 / HRP

**边际风险贡献与风险贡献**

$$\text{MRC}_{i} = \frac{(\Sigma \mathbf{w})_{i}}{\sigma_{p}}, \qquad \text{RC}_{i} = w_{i} \cdot \text{MRC}_{i} = \frac{w_{i} (\Sigma \mathbf{w})_{i}}{\sigma_{p}}$$

$$\sum_{i} \text{RC}_{i} = \sigma_{p} \quad (\text{欧拉分解})$$

**风险平价**：求 $`\mathbf{w}`$ 使 $`\text{RC}_{i} = \sigma_{p} / N,\ \forall i`$。

**层次风险平价 HRP**
1. 距离：$`d_{ij} = \sqrt{2(1-\rho_{ij})}`$，做层次聚类；
2. 准对角化相关矩阵；
3. 递归二分，簇内按**逆方差**分配。

**设计哲学**
- **风险平价**的哲学是：既然收益难预测而风险可测（§1.4），那就**只按风险分配**。它对"等权"的批评是：等权实际上是**风险集中**于高波动资产。
- **HRP** 的哲学更进一步：**不要求协方差可逆**。它只用相关矩阵的**层次结构**（聚类），用逆方差分配（只需方差，不需要完整协方差），因此在 $`N \gg T`$ 时仍能工作。这是把"数值稳定性"作为首要设计目标的产物。

**实践指导**
- **风险贡献表必须日常输出**：它回答"我的风险到底押在哪里"。权重 2% 的标的可能贡献 15% 的风险。
- HRP 在 $`N/T`$ 大、相关性结构不稳定的场景（如本项目：N=647、T=179，LW $`\delta=0.949`$，PC1 解释 87.8%）**优于均值-方差优化**。
- 分簇（聚类）可用于**风险归因与限额**，但**不要指望它提升收益**——本项目的置换检验证明：分簇组合的风险收益并不显著优于随机分组。

### 8.4 约束下的"有效前沿"失真

**设计哲学**：均值-方差优化的解对**输入误差极度敏感**（$`\hat\mu`$ 的误差被放大 $`1/\lambda`$ 倍）。实践中真正稳健的做法往往不是改进优化器，而是**减少输入**：只优化权重，不预测收益（等权、风险平价、HRP、最小化方差）。

**实践指导**
- 必加的稳健化：权重上下限、行业/单票限额、换手惩罚项 $`\lambda \|\Delta w\|^{2}`$、协方差收缩。
- **回测每一组权重都要报告"该权重在样本外的表现"**，而不是只报告优化目标值。
- 一个诚实的对照：**永远把"等权/逆波动"作为 baseline**。跑不赢 baseline 的优化等于没优化。

## 9. 统计显著性与过拟合

> 这一章是量化从业者最该反复读的一章。**绝大多数"回测很美"的策略死在这里。**

### 9.1 概率夏普比率 PSR

$$\text{PSR}(SR^{\ast}) = \Phi\!\left[ \frac{(\widehat{SR} - SR^{\ast})\sqrt{T-1}}{\sqrt{1 - \hat\gamma_{3} \widehat{SR} + \frac{\hat\gamma_{4} - 1}{4}\widehat{SR}^{2}}} \right]$$

$`\hat\gamma_{3}`$ 偏度、$`\hat\gamma_{4}`$ 峰度、$`T`$ 观测数、$`\Phi`$ 标准正态 CDF。

**设计哲学**：Sharpe 是**点估计**，PSR 把它变成**概率陈述**："真实 Sharpe 超过 $`SR^{\ast}`$ 的概率是多少？" 分母中的偏度/峰度修正，正是承认"**非正态收益下，同样长度的样本提供的信息更少**"——负偏 + 肥尾会**降低**置信度。

**实践指导**
- 用法：报 Sharpe 时**同时报 $`\text{PSR}(0)`$**（真实 SR > 0 的概率）和 $`\text{PSR}(1)`$。$`\text{PSR}(0) > 0.95`$ 才可以说"显著为正"。
- 陷阱：$`T`$ 要用**独立观测数**。日频数据但持仓周期 20 天 → 有效 $`T`$ 只有实际的 1/20。这是最常见的 PSR 造假方式。

### 9.2 最小跟踪记录长度 MinTRL

$$\text{MinTRL} = 1 + \left[1 - \gamma_{3} SR + \frac{\gamma_{4} - 1}{4} SR^{2}\right] \left(\frac{z_\alpha}{SR - SR^{\ast}}\right)^{2}$$

**设计哲学**：反向提问——"**要证明这个 Sharpe 是真的，我至少需要多长的历史？**" 它把"业绩说服力的成本"量化了。

**实践指导**（正态 $`\gamma_{3}=0,\gamma_{4}=3`$，$`\alpha=0.05`$ 单侧即 $`z_\alpha=1.645`$，$`SR^{\ast}=0`$，**年化 SR、$`T`$ 以年计**）
- $`SR = 0.5`$ → MinTRL ≈ **11 年**
- $`SR = 1.0`$ → MinTRL ≈ **2.7 年**
- $`SR = 2.0`$ → MinTRL ≈ **0.7 年**（约 8 个月）

> **这是全手册最该记住的数字组合**：一个 Sharpe 0.5 的策略，需要约 11 年数据才能在 95% 置信度下证明它不是运气。所以"三年翻倍业绩"在统计上几乎没有任何信息量。

**口径警告（本表曾经踩过的坑）**：MinTRL 对 SR 与 T 的**频率一致性**极其敏感——公式里的 SR 是**单期**（如日频）Sharpe、T 是**单期数**。若手上有年化 SR 而观测为日频，正确换算是 $`\text{MinTRL}_{年} \approx z_\alpha^2 / SR_{年化}^2`$（偏度峰度修正项在日频下近似为 1）。把单侧 $`z=1.645`$ 误用成 $`3.29`$，或把年化 SR 直接当单期 SR 代入又用年数读出，都会让答案差 4 倍上下——差出来的恰好是"看起来更严谨"的假象。出表前先检查三个数是否满足同一公式。

### 9.3 多重检验与 Deflated Sharpe Ratio

**问题**：试了 $`N`$ 个参数/策略，取最优的 $`\widehat{SR}_{\max}`$，这个数字的分布已不是真实 SR 的分布，而是**最大值分布**。

**Bonferroni / FDR(BH)**：阈值 $`\alpha/N`$ 或 BH 步进法控制错误发现率。

**Deflated Sharpe Ratio**

$$\widehat{SR}_{0} = \sqrt{\mathbb{V}[\widehat{SR}]}\left[(1-\gamma) z_{1-1/N} + \gamma\, z_{1-1/(Ne)}\right]$$

$$\mathbb{V}[\widehat{SR}] \approx \frac{1 - \gamma_{3} SR + \frac{\gamma_{4}-1}{4}SR^{2}}{T-1}$$

然后 $`\text{DSR} = \text{PSR}(\widehat{SR}_{0})`$。

**设计哲学**：不用"$`\alpha/N`$"这种粗暴修正，而是**直接建模"你搜了 $`N`$ 次"这件事对最大值分布的影响**。它承认一个事实：**回测的搜索过程是业绩的一部分**。$`\gamma \approx 0.5772`$（欧拉常数）用于刻画多次试验的期望最大值。

**实践指导**
- **必须记录 $`N`$**：从项目开始就记录"我一共试过多少个参数组合 / 因子 / 变体"。这是唯一诚实的做法。$`N=1000`$ 时，Sharpe 2 的策略可能完全不显著。
- 流程控制优于事后修正：**预注册假设** → 保留**留出集（holdout）**到最后一刻 → 只在留出集上做一次检验。
- 用 Bonferroni 做快速筛查，用 DSR 做最终判定。

### 9.4 White's Reality Check / SPA / PBO

| 方法 | 解决的问题 | 做法 |
|---|---|---|
| **White's Reality Check** | $`K`$ 个策略里最好的那个，真的优于基准吗？ | 用 bootstrap 在原假设（所有策略无 alpha）下生成 $`\max`$ 统计量的分布，比较 |
| **Hansen's SPA** | 同上，但功效更高（修正 RC 的保守性） | 标准化 + 自举，对"差的策略"降权 |
| **CSCV / PBO** | 整个调参过程的过拟合概率 | 组合对称交叉验证：把样本分成 S 份，取 S/2 训练、S/2 检验的所有组合，看"样本内最优"在样本外的排名分布 |

**PBO（Probability of Backtest Overfitting）**：

$$\text{PBO} = \Pr\big[\text{rank}_{\text{OOS}}(\text{best IS}) \text{ 处于后半段}\big]$$

用 logit 变换后的 rank 分布估计。

**设计哲学**：这一族方法的共同点是——**不检验单个策略，而检验"选择过程"**。White 的原假设是"最好的那个也是运气"，这是对"我们在 $`K`$ 个里挑最好的"这一行为的直接建模。CSCV/PBO 更彻底：它把整个调参轨迹当作随机对象。

**实践指导**
- $`K>20`$ 个候选策略时，必须做 White RC 或 SPA，否则选出的"最优"几乎必然是噪声。
- **PBO > 0.4 就应该重新设计流程**（减少参数、增加样本、简化模型）。
- Bootstrap 时**必须保留时间序列结构**（用 stationary/moving block bootstrap），不能对日收益做 IID 重抽样。

### 9.5 样本外验证：Purged K-Fold 与 Embargo

**设计哲学**：金融数据的三大泄漏源：
1. **重叠标签**：日频采样但标签是未来 20 日收益 → 相邻样本标签重叠 → 训练集和验证集信息泄漏；
2. **序列相关**：波动聚集使相邻样本非独立；
3. **信息渗透**：特征用了未来数据（财报、复权价、行业分类）。

**做法**
- **Purging**：删除与验证集时间窗重叠的训练样本；
- **Embargo**：在验证集之后留出一段"隔离带"（$`\approx`$ 标签长度），防止训练用到验证后的信息。

**实践指导**
- 采样频率必须**高于**标签重叠频率才有意义；否则先做"按非重叠标签采样"。
- 时间序列**绝不可以用随机 K-Fold**。
- **Walk-Forward**（滚动前推）是最贴近实盘的验证方式，应该作为最终裁决。

### 9.6 收益平滑修正（Getmansky）

**模型**：观测收益是真实收益的加权滑动平均：

$$r^{\text{obs}}_{t} = \sum_{j=0}^{J} \theta_{j} r^{\text{true}}_{t-j}, \quad \sum_{j} \theta_{j} = 1$$

**修正**

$$\sigma_{\text{true}} \approx \frac{\sigma_{\text{obs}}}{\sqrt{\sum_{j} \theta_{j}^{2}}} \quad \Rightarrow \quad SR_{\text{true}} \approx SR_{\text{obs}} \cdot \sqrt{\sum_{j} \theta_{j}^{2}}$$

**设计哲学**：对冲基金、私募、非流动性资产的"漂亮净值曲线"，很大一部分是**估值平滑**制造的——不是风险低，是**波动被推迟确认**。这个模型把平滑显式建模，反推出真实波动。

**实践指导**
- 用 AR(1) 检验月收益：显著的**正自相关**（如 $`\rho > 0.2`$）是收益平滑的红旗。
- 后果极其实际：平滑使 Sharpe 虚高、使 **beta 低估、使与市场的相关性低估**——你以为找到了"低相关另类资产"，其实只是估值滞后。
- **流动性越差的资产，越要做这个修正**。

## 10. 流动性与容量指标

### 10.1 Amihud 非流动性

$$\text{ILLIQ}_{i,t} = \frac{1}{D}\sum_{d=1}^{D} \frac{|r_{i,d}|}{\text{Volume}_{i,d}} \times 10^{6}$$

**设计哲学**：度量"**单位成交额造成多少价格变动**"——这是流动性最本质的定义。它不需要买卖报价数据，只用日频量价，实用性极强。

**实践指导**
- 按月计算，用于横截面排序和流动性因子构造。
- **流动性溢价**：ILLIQ 高的股票长期有正溢价，但危机时流动性会**同步崩塌**（流动性因子的负偏极强）。

### 10.2 ADV 占比与参与率

$$\text{ADV}\% = \frac{Q_{\text{strategy}, i}}{\text{ADV}_{i}}$$

### 10.3 容量估算

**单标的约束**：$`\text{AUM} \cdot w_{i} \le \rho_{\max} \cdot \text{ADV}_{i} \cdot H`$（$`H`$ 为建仓天数）

**换手约束（更常用）**：

$$\frac{\text{TO} \cdot \text{AUM}}{252} \le \rho_{\max} \cdot \text{ADV}_{\text{portfolio}} \quad \Rightarrow \quad \boxed{\text{AUM}_{\max} \approx \frac{252 \cdot \rho_{\max} \cdot \text{ADV}}{\text{TO}}}$$

**成本约束（盈亏平衡）**：

$$\alpha_{\text{gross}} - \text{TO} \cdot \big(\text{spread} + Y\sigma\sqrt{Q/\text{ADV}}\big) > 0$$

**设计哲学**：容量不是一个"策略属性"，而是"**策略 × 市场 × 规模**"的函数。它必须同时满足三个约束（持仓占比、换手速率、成本盈亏平衡），取**最小值**。

**实践指导**
- 经验：股票多因子中频策略，AUM 上限 ≈ 组合 ADV 的 **1–5%**；高频策略容量小得多且衰减快。
- **容量衰减曲线**：画出"预期 alpha vs AUM"的曲线，找到 alpha 降到边际成本线以下的那一点，那就是硬上限。
- 规模上升后 alpha 通常在 **AUM 超过某阈值后加速衰减**（因为开始影响价格）。

### 12.2 指标上线检查清单（策略评审用）

**收益侧**
- [ ] 用的是**几何年化**，不是算术 × 周期
- [ ] 明确区分 TWR / IRR，评价策略用 TWR
- [ ] 已扣**全部成本**（佣金、印花税、冲击、借贷、融券费）
- [ ] 已扣**方差拖累**并单独列出

**风险侧**
- [ ] 同时报 MDD **和** 恢复期 **和** Ulcer Index
- [ ] 报了偏度、峰度；若 $`S<-0.5`$ 或 $`K>3`$，已加 CVaR/压力测试
- [ ] 用**日频以上**数据算回撤（含日内极值）
- [ ] 有至少 3 个历史 + 3 个假想压力情景

**风险调整侧**
- [ ] Sharpe 与 PSR 一起报
- [ ] Sortino 的 $`\tau`$ 已声明
- [ ] Calmar 与 Martin 一起报（不单独用 Calmar 排序）

**相对基准侧**
- [ ] alpha 报了 **t 值**（不只是百分比）
- [ ] 做了多因子回归，**残差 alpha** 是多少
- [ ] TE 与 IR 在合同/设定的预算内

**执行侧**
- [ ] 回测成交**滞后于决策价**至少 1 期
- [ ] 换手率与成本拖累单独列出
- [ ] 有容量曲线（alpha vs AUM）
- [ ] 统计了未成交单的后续收益（机会成本）

**显著性侧（最关键）**
- [ ] 记录了**试验总次数 $`N`$**，并计算了 Deflated SR
- [ ] 用了 **purged K-fold + embargo** 或 walk-forward
- [ ] 有**真正的留出集**，且只用过一次
- [ ] 与 **baseline（等权/逆波动/买入持有）** 对比过
- [ ] 参数数量 vs 样本长度合理（参数越多，要求样本越长）

### 12.3 常见陷阱 20 条

**收益类**
1. 用算术平均年化（高估，见方差拖累）
2. 用 IRR 评价策略（把申购时点运气算成 alpha）
3. 净值曲线从最低点起算
4. 未扣成本或只扣佣金不扣冲击

**风险类**
5. 只用日频收盘价算回撤/波动（低估）
6. 用最大回撤做精细排序（单点估计量，噪声最大）
7. 正态 VaR 用于肥尾资产（系统性低估）
8. 忽略回撤**恢复期**（这是客户真正赎回的原因）
9. 波动率用 $`\sqrt{P}`$ 年化但收益自相关（低估波动 → 高估 SR）

**风险调整类**
10. 只报 Sharpe（不报 PSR、不报偏度峰度）
11. Sortino 的 $`\tau`$ 不统一就横向比较
12. 用不同时间窗口的 Calmar 比较

**基准类**
13. 单因子回归的 alpha 当真 alpha（未剥离风格）
14. 报 alpha 不报 t 值
15. 用 beta 不稳定的基准做归因

**因子类**
16. 用股票数当 Breadth（应该用 $`N_{\text{eff}}`$）
17. IC 显著但换手成本吃光（没算净 IR）
18. 因子在不可交易池上测（覆盖率陷阱）
19. IC 序列自相关却用 $`\sqrt{T}`$ 缩放

**组合与显著性类**
20. 随机 K-Fold 做时间序列验证 / 用样本内最优当结论 / 没记录试验次数 $`N`$

## 结语：指标使用的三条铁律

1. **先看是否可信，再看有多好。** 任何指标都要配一个"它自己有多不确定"的量（t 值、PSR、SE、置换检验）。没有不确定度的高性能数字，等于没数字。

2. **指标是决策的输入，不是决策本身。** Sharpe 高不等于能上线——还要问：容量够不够、成本扣了没、是不是卖尾部、是不是试了 1000 次才试出来的、和 baseline 比赢了多少。

3. **用最可估计的指标做主要决策。** 波动率、相关性、回撤频率（二阶矩与频次）可信；收益、alpha、最大回撤（一阶矩与极值）不可信。所以稳健的做法总是：**减少需要估计的参数**，而不是把估计做得更精细。
