# AFML 第 2—5 章：统计哲学、统一逻辑与量化实务

> 阅读对象：Marcos López de Prado，《Advances in Financial Machine Learning》（2018）第 2—5 章。本文为中文学习与研究笔记；方法概要与批判性分析分开陈述，公式统一使用 GitHub 数学语法。涉及实施优先级的判断是研究建议，不是书中定理，也不代表已经获得实盘收益证据。

## 1. 四章合起来，究竟在解决什么？

**先定义可以学习的金融问题，再选择预测模型。** 金融数据不是天然排列好的独立样本：行情更新的速度在变化，交易结果依赖退出路径，多个标签共享同一段收益，而价格水平又随时间漂移。这四章依次改造样本、目标、权重与特征。

| 章节 | 核心问题 | 主要方法 | 改变的统计对象 | 必须保留的边界意识 |
| --- | --- | --- | --- | --- |
| 第 2 章 Financial Data Structures | 什么时刻值得形成一个观测？ | 活动时间 bars、imbalance/runs bars、CUSUM、ETF trick | 观测时钟与采样机制 | 活跃程度不等于信息量；事件采样改变目标总体 |
| 第 3 章 Labeling | 预测的结果应对应哪一种交易决策？ | 波动率阈值、triple barrier、meta-labeling | 标签与停止规则 | 路径标签依赖交易政策；命中率不等于收益 |
| 第 4 章 Sample Weights | 哪些样本重复使用了同一段行情？ | concurrency、uniqueness、sequential bootstrap、收益归因、时间衰减 | 经验风险中的样本贡献 | 降低重叠不等于恢复 IID；权重改变优化目标 |
| 第 5 章 Fractionally Differentiated Features | 怎样提高跨期可比性，同时少丢失历史结构？ | 分数差分、固定窗口 FFD、平稳性诊断 | 特征表示与低频响应 | 有记忆不等于有 alpha；有限截断不保证严格平稳 |

用一个研究框架把它们连起来。设原始市场记录为 $`\mathcal D`$，整套数据处理与交易政策参数为 $`\theta`$：

```math
\mathcal D
\xrightarrow{\;\theta\;}
\{(t_{i,0},t_{i,1},X_i^{(\theta)},Y_i^{(\theta)},w_i^{(\theta)})\}_{i=1}^{N}.
```

```math
\widehat f_{\theta}
=\arg\min_f
\left\{
\frac{\sum_{i=1}^{N}w_i^{(\theta)}\ell(Y_i^{(\theta)},f(X_i^{(\theta)}))}
{\sum_{i=1}^{N}w_i^{(\theta)}}
+\lambda\Omega(f)
\right\}.
```

这个统一表达是本文的概括：**bar 阈值、标签屏障、样本权重、差分阶数都是研究设计的一部分。** 固定模型而反复挑选这些参数，同样会产生选择偏差。因此验证必须覆盖整个处理流程，不能只验证最后的分类器。

这里的顺序是概念顺序，不必是代码顺序。实际常先构造完整 bar 序列与因果特征，再用事件时点抽取特征行，随后产生未来标签与训练权重。

## 2. 第 2 章：把观测单位与市场过程对齐

### 2.1 数据不是天然同质的

书中先区分基本面、市场、分析和另类数据。它们不仅来源不同，可用时间、修订机制、成本、噪声与可复现性也不同。实务中首先要记录“当时何时能知道”，而不是只记录“数据属于哪一天”：财报发布日期、供应商到达时间、修订版本与幸存者偏差都会影响可交易性。

固定每分钟抽样，得到的是日历时间上的等间距，并不代表等风险或等信息。一分钟可能没有成交，也可能包含政策公告后的密集交易。按市场活动累计形成 bar，是在尝试让单个观测的经济含义更稳定。

设逐笔记录为价格 $`p_n`$、成交量 $`v_n`$，上一根 bar 结束于 $`n_{k-1}`$。活动 bar 的一般形式为：

```math
n_k=\inf\left\{n\gt n_{k-1}:
\sum_{j=n_{k-1}+1}^{n}a_j\ge B_k\right\}.
```

| bar 类型 | 累计量 | 直觉 | 主要问题 |
| --- | --- | --- | --- |
| Time | 固定日历时长 | 对齐报告、风险和交易安排 | 不同时段的活动强度不同 |
| Tick | 成交笔数 | 相同成交次数形成一个观测 | 拆单、合并成交及数据口径会改变含义 |
| Volume | 成交数量 | 相同交易数量形成一个观测 | 单位、拆股、合约乘数与市场规模变化 |
| Dollar | 成交金额 | 相近名义交易价值形成一个观测 | 价格、汇率、市场规模与流动性仍会变化 |

公式中的累计量依次可取 1、成交量、价格乘成交量。期货名义金额还应考虑合约乘数；跨币种比较需要明确汇率口径。单笔大成交跨越阈值时，要事先规定是否拆分及如何处理超额量。

**统计哲学：时间轴可以是模型设计变量。** 但活动 bar 只是信息时钟的代理，不能宣称收益因此正态、独立或同分布。异步 bar 还会增加多资产对齐的难度。

### 2.2 Imbalance bars 与 runs bars：从活动量到方向性活动

用 tick rule 推断成交方向：价格上涨记为正，下降记为负；价格不变时沿用上一次非零方向。它是方向代理，不等于真实主动买卖方标记。

```math
b_n=
\begin{cases}
1,&p_n\gt p_{n-1},\\
-1,&p_n\lt p_{n-1},\\
b_{n-1},&p_n=p_{n-1}.
\end{cases}
```

在一根候选 bar 内，方向加权活动的净不平衡为：

```math
\theta_T=\sum_{n=1}^{T}b_n a_n.
```

Imbalance bars 关注净方向活动何时相对历史预期足够异常；阈值由历史估计的预期 bar 长度与方向性活动规模决定，并可随历史更新。不能用完整样本或尚未结束的未来 bar 来估计当时的阈值。

Runs bars 则累计买方和卖方各自的活动量，考察其中较大的一侧：

```math
R_T=\max\left\{
\sum_{n=1}^{T}a_n\mathbf 1_{\{b_n=1\}},
\sum_{n=1}^{T}a_n\mathbf 1_{\{b_n=-1\}}
\right\}.
```

这里的 runs 不应误解为“最长连续同方向成交串”。两侧活动不会像净不平衡那样相互抵消。两类方法都在用历史预期定义“什么时候值得结束一个观测”，也都引入了初始化、平滑长度和阈值稳定性的工程问题。

### 2.3 CUSUM：bar 构造之后的事件筛选

CUSUM 可以作用于价格变化、对数收益或某个残差序列。以下写成零参考值的双侧版本；$`z_t`$ 是预先明确的输入，不能自动把它当成统计上独立的“创新”。

```math
S_t^+=\max(0,S_{t-1}^++z_t),\qquad
S_t^-=\min(0,S_{t-1}^-+z_t).
```

当正侧超过阈值或负侧低于负阈值时记录事件，并将触发侧的累计量清零。阈值必须与输入同单位；是否两侧同时重置也应固定为明确的实现约定。

**bar 构造与事件抽样是两层操作。** 前者聚合逐笔行情，后者从已有序列中挑选决策时点。CUSUM 可减少大量微小波动产生的重复样本，但并不自动识别“新信息”，也不自动消除标签重叠。

事件过滤后的学习对象是“触发条件成立时的结果分布”。如果模型将来用于每一分钟，就不能直接假定在 CUSUM 事件上估计的概率仍然适用。这是采样机制与部署总体是否一致的问题。

### 2.4 ETF trick 与期货连续序列：表示必须对应财富变化

多资产价差的数值未必是一条可投资财富曲线。动态权重直接乘价格，可能把权重调整本身误算成收益。ETF trick 的核心是把篮子交易记成自融资账户的价值演化。

下面是帮助理解的简化记账式，不是书中完整实现：

```math
V_t=V_{t-1}
+\sum_j q_{j,t-1}m_j(P_{j,t}-P_{j,t-1})
+C_t-K_t.
```

其中持仓数量和合约乘数决定实际敞口，现金流与交易成本另行记账；真实系统还要处理现金账户、融资、分红、汇率和换仓成交。调整持仓不应凭空创造收益。

期货换月也是同一问题：直接拼接不同合约可能出现非持仓收益造成的跳点。用于信号研究的复权连续价格、可成交合约价格和真实滚动持仓 PnL 必须分清。连续化可以服务统计建模，但不能代替换月成本与可成交性建模。

### 2.5 实务判断

对有可靠逐笔成交数据的单资产日内研究，volume/dollar bars 值得与 time bars 做比较；imbalance/runs bars 更适合作为后续实验。若策略目标本来就是每周调仓或固定时点风险管理，日历时间往往更直接。选择时钟的标准应是样本外决策质量及实施成本，而非分布图“更漂亮”。

## 3. 第 3 章：标签是交易政策的结果

### 3.1 固定期限收益与动态阈值

固定期限标签回答“未来某个确定时点的收益是多少”。若策略确实按该时点退出，这个目标完全合理；问题在于它可能与实际止盈、止损规则不一致。

用历史可得的波动率估计缩放收益阈值，可以提高不同风险环境下标签的可比性：

```math
r_i=\frac{P_{t_{i,0}+H}}{P_{t_{i,0}}}-1,
\qquad
y_i=
\begin{cases}
1,&r_i\gt k\widehat\sigma_i,\\
-1,&r_i\lt -k\widehat\sigma_i,\\
0,&\text{otherwise}.
\end{cases}
```

波动率只能用决策时点以前可得数据估计，并明确对应的收益期限。不能未经检验就对所有事件时钟使用平方根时间缩放。

### 3.2 Triple barrier：由到期值转向首次触达

为事件设置上屏障、下屏障和最长持有期。若方向已由主策略给出，令 $`s_i\in\{-1,1\}`$，方向调整后的简单收益为：

```math
R_i(t)=s_i\left(\frac{P_t}{P_{t_{i,0}}}-1\right).
```

```math
\tau_i^+=\inf\{t\gt t_{i,0}:R_i(t)\ge a_i\widehat\sigma_i\},\qquad
\tau_i^-=\inf\{t\gt t_{i,0}:R_i(t)\le-b_i\widehat\sigma_i\}.
```

```math
t_{i,1}=\min\{\tau_i^+,\tau_i^-,t_{i,0}+H_i\}.
```

其中两侧倍数为正；未触达时对应触达时间视为无穷。未给方向时，可直接对价格收益定义上下屏障来学习方向。触及垂直屏障后的标签可以按退出收益符号定义，也可以按明确规则记为中性，不能把某一种约定说成唯一标准。

例：价格从 100 先跌到 98，随后在期限末涨到 103。固定期限的多头标签可能为正；若止损为 1%，实际交易已经退出，路径标签应反映先止损。这里改变的是预测问题，而不是仅仅换一种编码。

**局限：** 同一根 OHLC bar 的最高价和最低价同时越过两侧屏障时，不知道哪一侧先发生。应使用更细数据、标记歧义样本，或采用预先规定的保守成交假设。跳空也不能按屏障价保证成交。持有期使用交易时长、日历时长还是 bar 数，必须事先明确。

### 3.3 Meta-labeling：方向与是否执行分开学习

主策略负责给方向；次级模型在“主策略已发出信号”的条件下，预测该交易是否值得执行。实务中可以把扣费后盈利作为正类：

```math
Y_i^{\mathrm{meta}}
=\mathbf 1_{\{R_i(t_{i,1})-c_i\gt 0\}},\qquad
p_i=\Pr(Y_i^{\mathrm{meta}}=1\mid X_i,s_i).
```

这里扣费定义是对交易目标的工程扩展。成本口径应含手续费、价差、滑点以及必要时的融资或借券费用，不能用中间价结果冒充可交易收益。

次级模型的负类表示“过滤这笔原交易”，不等于反向交易。概率也不是天然仓位大小：在简化的二结果模型中，平均毛盈利为 $`G`$、平均毛亏损绝对值为 $`L`$、每笔成本为 $`c`$ 时：

```math
\mathrm{EV}=pG-(1-p)L-c\gt 0
\quad\Longleftrightarrow\quad
p\gt \frac{L+c}{G+L}.
```

所以 0.5 不是普遍正确的执行阈值。现实盈亏幅度随状态变化，还需估计条件收益、尾部风险、容量与组合约束。第 3 章提供方向/执行分离的接口，并不完成整套仓位优化。

若主策略由数据训练得到，训练次级模型时必须使用主策略的真实历史预测或适当时间切分产生的样本外预测；在重叠标签情形下还要清除跨折信息重叠。用主策略对自身训练集的拟合信号，会让次级模型面对虚假的高质量候选交易。主策略版本改变后，次级模型的条件分布也会改变。

### 3.4 Quantamental 与稀少类别

人工判断或经济逻辑可以生成方向，机器学习负责估计执行条件，这是 quantamental 的一种组织方式。但人工信号也必须保存当时的记录，不能事后补写“当时会怎么判断”。

删除极少数标签可以缓解难以学习的类别，但会改变研究总体。中性样本不应仅因难预测就随意删除；如果“不交易”本来就是部署决策的一部分，必须保留相应评估。类别处理规则只在训练折内确定。

**统计哲学：目标应服务于决策。** 标签包含入场、退出与成本假设。它回答的是“在这套政策下会发生什么”，并非与政策无关的市场真相，也不是自动完成了因果识别。

## 4. 第 4 章：按共享的底层信息重新分配样本影响

### 4.1 行数不等于独立信息量

若每天生成一个持有五天的标签，相邻标签会重复使用大部分收益增量。即使底层增量独立，标签也可能相关；若底层市场本身存在共同因子和持续性，不重叠标签也未必独立。

为避免端点歧义，把基本单位定义成单期收益增量。令 $`A_{t,i}=1`$ 表示标签 i 使用了第 t 个增量，反之为零。采用哪种端点约定必须与标签计算一致。

```math
c_t=\sum_{i=1}^{N}A_{t,i},\qquad
u_{t,i}=\frac{A_{t,i}}{c_t}\quad(c_t\gt 0),\qquad
\bar u_i=\frac{\sum_tu_{t,i}}{\sum_t A_{t,i}}.
```

无事件覆盖时将局部唯一性记为零。平均唯一性位于零与一之间，衡量的是收益区间的非重叠程度。

一个可手算的例子：A 使用增量 1、2、3；B 使用 3、4；C 使用 5、6。

| 增量 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| A | 1 | 1 | 1 | 0 | 0 | 0 |
| B | 0 | 0 | 1 | 1 | 0 | 0 |
| C | 0 | 0 | 0 | 0 | 1 | 1 |
| 并发数量 | 1 | 1 | 2 | 1 | 1 | 1 |

```math
\bar u_A=\frac{1+1+1/2}{3}=\frac56,\qquad
\bar u_B=\frac{1/2+1}{2}=\frac34,\qquad
\bar u_C=1.
```

**唯一性不是互信息，也不是一般意义下的有效样本量。** 把其总和解释为“精确有多少个独立样本”缺乏一般依据。它未描述共同市场因子、非线性依赖和特征窗口重叠。

### 4.2 Sequential bootstrap：动态降低重复抽样的吸引力

普通 bootstrap 等概率、有放回地抽取样本行。对共享大量未来收益的标签，这容易反复抽到同一底层信息。顺序 bootstrap 根据已经选中的标签，重新计算每个候选样本加入后的唯一性。

设 $`\phi`$ 是已抽取的序列，允许重复；候选 j 的寿命长度为 $`T_j=\sum_tA_{t,j}`$：

```math
\widetilde u_j(\phi)
=\frac{1}{T_j}\sum_{t:A_{t,j}=1}
\frac{1}{1+\sum_{k\in\phi}A_{t,k}},\qquad
\Pr(j\mid\phi)=\frac{\widetilde u_j(\phi)}{\sum_m\widetilde u_m(\phi)}.
```

初始为空时等概率。若上例第一轮抽中 B，则 A、B、C 的候选唯一性分别为 5/6、1/2、1；第二轮概率为：

```math
\Pr(A\mid\{B\})=\frac5{14},\qquad
\Pr(B\mid\{B\})=\frac3{14},\qquad
\Pr(C\mid\{B\})=\frac6{14}.
```

它保留重复和部分重叠的可能性，只是改变抽样倾向。适合研究 bagging 中的冗余与模型相关性；不能将其当作独立性证明，也不能直接替代用于统计推断的 block bootstrap。

袋外样本即使没有被抽到，其结果仍可能与袋内样本共享行情，因此 OOB 分数可能乐观。缩小每棵树抽样规模是一种可比较的简单方案；顺序抽样是否值得增加计算成本，要看样本外增益。

### 4.3 Return attribution：共享收益按并发数量分摊

对方向型标签，书中考虑先把单期对数收益按并发数量分摊，再累加并取绝对值：

```math
\widetilde w_i
=\left|\sum_{t:A_{t,i}=1}\frac{r_t}{c_t}\right|,\qquad
w_i^{\mathrm{return}}
=\frac{N\widetilde w_i}{\sum_j\widetilde w_j}.
```

注意是**求和后取绝对值**，并非先对每期收益取绝对值再相加。前者允许正负收益抵消，后者更接近路径活动量。若全部归因权重为零，需要明确定义回退方案，不能除以零。

这类权重同时表达“共享程度”和“收益幅度的重要性”。因此它已经改变了损失函数所强调的样本；不是免费提高精度。中性标签、小幅但可重复的交易、尾部极端收益，可能需要其他权重设计。采用截尾或权重上限属于额外稳健化选择，应在训练内验证。

### 4.4 Time decay：沿累计唯一性衰减

把训练事件按时间从旧到新排序：

```math
x_i=\sum_{j=1}^{i}\bar u_j,\qquad U=\sum_{j=1}^{N}\bar u_j.
```

以 $`c\in(-1,1]`$ 控制遗忘程度，并要求最新样本的衰减因子为一：

```math
D(x)=
\begin{cases}
c+(1-c)x/U,&0\le c\le1,\\
\max\left(0,\dfrac{x+cU}{(1+c)U}\right),&-1\lt c\lt 0.
\end{cases}
```

```math
w_i^{\mathrm{final}}=w_i^{\mathrm{return}}D(x_i).
```

c 为一时不衰减；c 为零时线性增加；c 为负时，累计唯一性位置不超过负 c 倍总量的旧事件权重为零。由于第一个实际样本的位置通常大于零，其权重不一定恰好等于 c。需要时再把最终权重归一化到均值为一。

这里用累计唯一性定义“统计年龄”，不是按经过多少天。但市场活跃、波动大并不必然让唯一性增加得更快：若同时触发很多长事件，重叠反而可能加重。因此应把这看成一种遗忘机制，与日历衰减做经验比较。

### 4.5 Class weights、概率校准与训练边界

类别平衡权重强调少数类，收益权重强调经济幅度，唯一性修正强调减少重复，时间衰减强调近期相关性。四种目的不同，机械连乘可能造成少量样本支配训练，或重复惩罚同一种重叠。

加权训练输出的概率也未必等于真实部署频率。例如只做类别加权时，原始条件正类概率为 p，正负类权重分别为 a 和 b，在加权对数损失下，最优概率为：

```math
p_w=\frac{ap}{ap+b(1-p)}.
```

这解释了为什么 meta-labeling 的执行阈值不能直接套在未经校准的加权输出上。校准需用有代表性的独立时间验证数据，且不得消耗最终测试集来反复调整。

唯一性和收益权重可以使用已经结束的训练标签所包含的未来结果；它们是监督学习的训练信息。它们不能作为事件起点的实时特征，也不能引入验证/测试标签的退出时间来构造训练折权重。每次训练只能使用当时已经成熟的标签。

**统计哲学：从“每行一票”转向“明确每行为何有这份影响力”。** 权重不能补救错误标签、前视特征或泄漏的验证切分。

## 5. 第 5 章：尽量少破坏历史结构的特征变换

### 5.1 平稳性、记忆与预测力是三个不同概念

价格水平常存在随机趋势；直接拟合水平可能把时间漂移误认为可迁移规律。差分可以去掉某些随机趋势，但也改变低频结构。第 5 章的主张是把差分强度当作可调参数，而非无条件使用一阶差分。

弱平稳通常要求均值不随时间变化，协方差只依赖时间差；严格平稳要求联合分布对平移不变。ADF 检验的是特定回归设定下的单位根原假设，并非检验所有形式的平稳性。

平稳不是所有预测模型都必须先满足的万能门槛；一阶差分也不保证平稳，更不必然删除全部预测信息。即便是完全不可预测的随机游走，价格水平也包含历史冲击的累计。**历史被保留、序列有依赖、未来收益可预测，不能画等号。**

### 5.2 分数差分与权重递推

令滞后算子 $`LX_t=X_{t-1}`$，形式上定义：

```math
(1-L)^dX_t=\sum_{k=0}^{\infty}\omega_kX_{t-k},\qquad
\omega_k=(-1)^k\binom{d}{k}.
```

```math
\omega_0=1,\qquad
\omega_k=-\omega_{k-1}\frac{d-k+1}{k}.
```

d 为零时保留原序列；d 为一时得到普通一阶差分；零与一之间提供连续的变换强度。对于 d=0.4，前几个权重为：

```math
1,\;-0.4,\;-0.12,\;-0.064,\;-0.0416,\ldots
```

频域上，理想无限滤波器的增益为：

```math
|1-e^{-\mathrm{i}\lambda}|^d
=\left(2|\sin(\lambda/2)|\right)^d.
```

因此 d 控制低频抑制的强度。把它理解成滤波器，比把“保留记忆”直接等同于“保留 alpha”更准确。无限历史表达还需要相应过程假设与初始化处理，有限样本计算只是其实现或近似。

### 5.3 Expanding window 与固定窗口 FFD

扩展窗口从样本起点一直使用到当前时点。随着有效权重数量改变，初始化和截断效应可能随时间变化。固定窗口 FFD 固定保留最近 K+1 个观测：

```math
Z_t^{(d,K)}=\sum_{k=0}^{K}\omega_kX_{t-k},\qquad t\ge K.
```

这样预热期后的每个时点使用相同的滤波定义，便于流式实现。窗口长度通常由单个权重阈值决定，或直接设置 K；这两种选择应明确记录。

**单项很小不代表整个尾部很小。** 对零到一之间的 d，权重尾部按幂律衰减：

```math
|\omega_k|\sim\frac{d}{\Gamma(1-d)}k^{-1-d}.
```

截断单项阈值与累计尾部质量容忍度不是同一标准。若限制最大窗口而提前停止，也必须记录实际截断原因。d 与阈值或 K 要联合考察；d 较小并不必然意味着需要的计算更少。

### 5.4 一个关键局限：固定有限 FFD 不保证去掉单位根

以下是对有限滤波器的直接数学分析。对零到一之间的非整数 d 和有限 K，其权重和为：

```math
S_K=\sum_{k=0}^{K}\omega_k
=(-1)^K\binom{d-1}{K}\gt 0.
```

若输入是真正的随机游走：

```math
X_t=X_{t-1}+\varepsilon_t,
```

代入有限滤波器可写成：

```math
Z_t^{(d,K)}
=S_KX_t
-\sum_{k=1}^{K}\omega_k\sum_{j=0}^{k-1}\varepsilon_{t-j}.
```

第二项是有限长度的创新滤波，第一项仍含非零倍数的随机趋势。所以**固定有限窗口且权重和非零的 FFD，不会严格消除这个随机游走的单位根**。K 较大时该成分可能很小，有限样本检验可能表现不同，但不能据此给出渐近平稳保证。

也不能把这个结论错误推广到理想无限差分：在常见分数整合模型的适当条件下，无限差分会把整合阶数从 q 降为 q-d；协方差平稳的典型范围是剩余阶数小于 1/2。无限滤波与固定有限截断是不同对象。

FFD 的工程价值是提供一组可比较的有限滤波特征，并减轻可变窗口效应；不是用一个检验结果证明所有分布漂移已经消失。若强制修正权重使和为零，那是另一个滤波器，需要重新评估其频率响应和预测价值。

### 5.5 怎样选择 d 才不自欺？

可以在训练数据上扫描少量候选阶数，用 ADF、必要时 KPSS、滚动均值/方差与分段诊断筛选。ADF 的滞后阶数、截距/趋势项、样本长度和结构突变都会影响结论。多个 d 反复试到显著，也构成选择过程。

与原价格的相关系数可以作为变换幅度的描述，但高相关不证明预测力，也可能来自残留趋势。最终应比较原始收益、滞后收益、滚动标准化、距移动均值的偏离、经济上合理的价差或协整残差等基线，在相同部署时钟和时间外样本上检查净收益贡献。

对数价格要求正价格；非正价格、价差和已复权连续序列必须选择合适表示。还要统一缺失值规则、预热长度和样本对齐，避免因不同 d 留下不同日期而把样本选择差异误认为特征优劣。

## 6. 蕴含怎样的统计哲学？

### 6.1 观测、目标、度量与表示都需要设计

传统表格学习容易默认数据行与标签已经给定。AFML 的这四章把更前面的工作显式化：市场如何被采样、什么结果值得预测、哪些结果反复使用了同一信息、哪些变换能提高跨期可比性。复杂模型不能替代这些定义。

### 6.2 追求局部可比性，而不是假设全球同分布

活动时钟处理不同时间段的活跃程度差异；波动率屏障处理收益尺度差异；唯一性处理区间重叠；时间衰减承认旧经验可能失效；分数差分调整低频结构。它们在不同层面减少可比性障碍，但没有任何一步证明整个数据集已经 IID。

### 6.3 统计目标应当与经济对象相容

财富过程应对应可实现的持仓损益，标签应对应退出政策，训练权重应说明为何某些错误更重要。由此可以把这四章理解为一种“面向决策的数据设计”。不过，收益加权的分类损失仍不等于最终组合效用，triple barrier 也不等于完整执行模拟。

### 6.4 减少不必要的破坏，同时接受无法消除的依赖

不必为了标签不重叠就删除所有交叠事件，也不必为了去趋势只允许整数差分。保留可能有用的结构，再显式管理其代价。这种“最小必要变换”的原则值得保留，但它不是一个保证保留充分统计量的定理。

### 6.5 “信息”是启发性语言，需要具体化

成交金额不是香农信息，唯一性不是独立信息的精确计数，历史相关不是可交易信号，ADF 拒绝单位根不是证明未来分布不变。把这些区别讲清楚，才能让书中的工程直觉接受可证伪的检验。

## 7. 四章方法之间的联动，为什么不能各自调参？

1. 改变 bar 时钟，会同时改变波动率估计、CUSUM 事件、标签期限和 FFD 的实际日历记忆长度。100 根 bar 在不同日期可能覆盖完全不同的时长。
2. 增加事件密度或放宽持有期，会提高标签重叠，继而改变唯一性、收益归因、顺序抽样和时间衰减。
3. 改变止盈止损屏障，会改变类别比例、盈亏幅度及持有时间，因此也改变 meta-labeling 的决策阈值和样本权重。
4. 加权或重采样改变了训练分布，预测概率、校准方法和执行阈值需要匹配；不能只看分类 AUC。
5. 特征滤波长度影响可用历史和跨折数据依赖。合法使用预测时已知的历史，与错误使用未来拟合变换参数，必须区分。

因此最重要的研究对象是**从原始行情到组合损益的整条流程**，不是其中某一项指标。

## 8. 量化实务中的可行性与采用顺序

以下是本文的工程判断，并非普遍收益排序。

| 方法 | 较适合的场景 | 主要落地成本与局限 | 建议优先级 |
| --- | --- | --- | --- |
| Point-in-time 数据与真实收益记账 | 几乎所有策略 | 数据修订、复权、融资及换仓细节 | 基础设施，优先处理 |
| 时间或活动 bars 的比较 | 有稳定逐笔数据的日内策略 | 数据质量、阈值漂移、多资产异步 | 先建立简单基线 |
| Imbalance/runs bars | 订单流相关策略 | 方向误判、参数初始化、市场制度变化 | 证据支持后再采用 |
| CUSUM | 事件触发交易 | 事件密度与选择总体变化 | 与简单采样消融比较 |
| 波动率阈值与 triple barrier | 有明确止盈止损的策略 | bar 内路径、跳空及成交假设 | 目标匹配时优先 |
| Meta-labeling | 已有可复现候选信号 | 样本外主信号、概率校准、候选样本减少 | 主策略稳定后采用 |
| 重叠诊断与训练权重 | 多个持仓区间重叠 | 区间计算、尾部权重、校准 | 先诊断，再比较权重 |
| Sequential bootstrap | 冗余严重的 bagging | 计算与实现复杂度；不修复验证泄漏 | 在简单抽样后比较 |
| 时间衰减 | 有概念漂移证据的市场 | 样本量减少、稀有风险事件被淡化 | 少量预设方案比较 |
| FFD | 价格水平类特征研究 | 长预热、参数选择、残留随机趋势 | 作为候选特征，而非默认必选 |

低频横截面研究往往更应优先处理行业/规模暴露、点时可用性、交易约束与横截面比较；未必需要订单流 bars。高频策略则可能更受排队、延迟和冲击成本约束，数据处理上的统计改进不能替代执行建模。

### 8.1 一条可审计的最小流程

1. **定义部署政策。** 明确市场、交易时段、候选信号、持有期、成交规则、资金及风险约束。
2. **构造点时数据。** 保留原始数据与版本；记录发布时间、可用时间和价格调整规则。
3. **生成因果特征和事件。** bar 阈值、波动率、CUSUM 和滤波只用当时可得信息；保存每个事件的特征窗口起点与决策时间。
4. **生成成熟标签。** 在未来路径上应用已固定的退出规则，记录实际退出时间、退出原因、毛收益和净收益；尚未结束的事件不混入已成熟训练标签。
5. **按时间划分研究数据。** 保留最终未触碰的时间外测试区间。训练时只用当时已经得到结果的事件，清除与验证标签区间重叠的训练事件。
6. **在训练折内拟合整个流程。** 包括数据驱动阈值、标准化、FFD 参数、类别处理、主策略、权重及校准；顺序抽样也只访问该训练折。
7. **做组合与执行层评估。** 多笔事件同时出现时按真实资金和净敞口聚合，不能把每笔标签收益直接相加当作组合收益。
8. **冻结选择后做时间外测试。** 再进行延迟、价差、冲击和成本上升压力测试，最后进入模拟盘或受控上线。

Purging 与 embargo 的系统讨论属于后续章节，这里把它们作为实务接口补充：前者清除与验证信息区间冲突的训练事件；后者在适当的交叉验证设置中留出时间隔离，以降低剩余依赖。隔离长度应依据持有期、特征回看与信息依赖设计，而非机械选一个百分比。它们不能消除所有序列依赖或多重试验偏差。

验证/测试特征使用其预测时点以前已经公开的训练期历史，本身并不是泄漏；泄漏在于使用未来信息、跨期拟合参数，或把评估期的结果带回训练。

### 8.2 怎样判断新增方法真的有用？

建立固定的简单模型与执行假设，逐项添加：活动 bars、事件过滤、路径标签、权重、meta-label、FFD；必要时再测试关键交互。预先限制候选参数数量，记录失败实验与总尝试次数。

报告不仅包括 AUC/PR-AUC，也包括概率校准、净收益、回撤、换手、敞口、持有时长、成本敏感性及分市场状态结果。不确定性评估应反映时间依赖；不能用普通 IID 行级重采样的窄区间制造确定性。

改变标签意味着改变任务，所以不同标签定义下的分类分数通常不能直接横比。应放回相同资本、时间轴与可执行政策上比较。若最终只在一个市场、一个样本期或忽略成本时有效，证据仍然有限。

## 9. 复习时最值得记住的六句话

- 第 2 章：观测时钟应该服务于研究对象；等活动只是等信息的代理。
- 第 3 章：标签由交易政策定义；首次触达与固定期限是不同问题。
- 第 4 章：共享行情的样本不能简单每行同权；唯一性也不是独立性证明。
- 第 5 章：变换应尽量少丢失有用结构；记忆、平稳与预测力必须分别验证。
- 四章的共同逻辑：把金融监督学习的数据生成过程纳入研究设计与验证。
- 实务的最终标准：在严格时间外、成本与资金约束下，是否改善可执行决策。
