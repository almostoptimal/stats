## 摘要

概率论提供的是给定概率空间之后的严密推理规则；它不回答现实问题是否具有唯一、可识别且可迁移的概率分布。本文沿一条主线展开：**"一个系统有概率"要过五道关——数学存在、经验解释、统计识别、计算可行、跨环境有效**。三体混沌（第 3 章）说明确定性不保证可预测、"有概率"不等于"有依据"；统计物理（第 5–6 章）说明宏观规律为什么能在微观复杂性中出现，以及这依赖哪些条件；金融市场（第 7–8 章）在前两者之外还多了适应性与反身性——**预测会改变被预测的对象**。前半部分的结论不是"物理可以、金融不行"，而是：**每一层可靠性的代价都要单独论证，谁也不能替谁付账**。后半部分处理概率不够用时的决策：归纳的边界、可迁移结构的三类对象，以及反馈决策的基本循环（第 9–12 章）。

## 1. 核心问题与论证层次

“这个系统有概率吗？”至少包含五个不同问题：

| 层次 | 实际问题 | 需要的依据 |
|---|---|---|
| 数学存在 | 能否在某个可测空间上定义概率测度？ | 测度论构造 |
| 物理或认识论解释 | 这个测度代表随机机制、制备方式，还是信念？ | 机制、实验设计或推断规则 |
| 统计识别 | 数据能否区分不同候选测度？ | 可识别性、观测条件、样本信息 |
| 计算可行 | 即使测度已知，能否计算所需概率或最优行动？ | 算法、近似误差、计算资源 |
| 跨环境有效 | 历史得到的规律能否用于未来和干预之后？ | 稳定性、结构假设、反馈分析 |

这些问题不能相互替代。一个模型可以数学上完全合法，却经验上缺乏支持；一个分布可以客观存在，却难以识别；一个已知的随机机制，也可能具有难以计算的尾部概率。

本文的基本立场是：**概率论的推理有效性，与现实概率模型的适用有效性，应分别论证。**全文据此分两半：第 2–8 章逐层检验"一个概率模型何时可信"——从数学存在一路查到跨环境迁移；第 9–12 章处理"可信度不足时如何决策与修正"。三体、统计物理和金融市场在文中不是三个并列话题，而是同一组检验在三种环境下的试金石：三体负责检验"确定性与概率的关系"，统计物理负责检验"宏观规律从何而来"，市场负责检验"预测与行动纠缠时还剩多少可靠性"。

## 2. 概率测度的数学存在与经验正当性

### 2.1 概率公理规定什么

概率空间记为

```math
(\Omega,\mathcal F,P),
```

其中 $\Omega$ 是样本空间，$\mathcal F$ 是事件的 $\sigma$-代数，$P$ 满足

```math
P(A)\geq 0,\qquad P(\Omega)=1,
```

以及对两两不交的事件 $A_1,A_2,\ldots$，

```math
P\!\left(\bigcup_{n=1}^{\infty}A_n\right)
=\sum_{n=1}^{\infty}P(A_n).
```

公理给出一致的运算规则，却不替我们决定样本空间、信息集合或概率数值。把未知结果列成几个选项后赋予均匀概率，也不是由“无知”唯一推出的结论；换一种参数化，所谓均匀可能就改变了。

### 2.2 “所有不确定性都有概率测度”如何回答

从纯数学角度，只要非空可测空间中选定一点 $\omega_0$，就可以定义狄拉克测度

```math
\delta_{\omega_0}(A)=\mathbf 1_{\{\omega_0\in A\}}.
```

但这显然不能解决现实中的无知。**能赋予某个测度，不等于存在一个由现有证据充分支持的唯一测度。**

还应区分：

- **机制不确定性：** 在采用的理论中，结果由随机机制产生。
- **状态不确定性：** 动力学给定，但初始状态、参数或观测不精确。
- **模型不确定性：** 不确定哪些变量、方程或机制适用。
- **结构性无知：** 相关事件、制度变化或新行为方式尚未进入建模范围。

这些层次可以同时存在。概率表示能够覆盖很多不确定性，但把它们全部压缩为一个精确分布，可能掩盖证据不足。

### 2.3 概率不必依赖可重复实验

频率解释、贝叶斯信念解释和物理机会解释回答的问题并不完全相同。一次性事件也可以有主观概率或模型条件概率；关键在于说明其来源和可检验含义，而不是将“一次性”误判为“不允许谈概率”。

这一区分有两个经典出处。**Knight（1921）**把可赋概率的“风险”与不可赋概率的“不确定性”分开，并指出利润的来源正是后者——若一切皆可事先计算，竞争会把所有机会套利殆尽。**Ellsberg（1961）的双瓮实验**把这一区分带进实验室：瓮 A 装有 50 个红球和 50 个黑球，比例已知；瓮 B 也装 100 个红黑球，但比例完全未知。实验反复显示，多数人愿意为“从瓮 A 摸出红球”支付更高的价格——可是按任何单一主观概率（对瓮 B 同样赋 50/50），两个赌局的期望完全相同。这个结果说明：人对瓮 B 缺的不是一个数，而是**对“这个数是否可信”的信心**；强行给两个瓮配上同一个先验，就把这个差别抹掉了。Knight 的区分与 Ellsberg 的实验，是本文“数学存在 ≠ 经验正当性”这一层在经济学与心理学中的实证版本。

当单一测度缺乏支持时，可以使用候选测度集合 $\mathcal P$：

```math
\underline P(A)=\inf_{P\in\mathcal P}P(A),\qquad
\overline P(A)=\sup_{P\in\mathcal P}P(A).
```

这表达概率判断的范围，但上下概率一般不具有普通概率测度的可加性。集合如何确定仍需证据，不能以形式上的保守替代实质论证。

## 3. 三体问题：确定性、混沌与概率

### 3.1 确定性方程不保证长期可预测

牛顿引力三体系统满足

```math
\ddot{\mathbf r}_i
=G\sum_{j\ne i}m_j
\frac{\mathbf r_j-\mathbf r_i}{\|\mathbf r_j-\mathbf r_i\|^3},
\qquad i=1,2,3.
```

在无碰撞的适当时间区间内，给定完整初始状态，通常的微分方程存在唯一性理论适用。确定性表示初值决定演化；它不表示有限精度观测足以支持任意长时间的精确预测。

在具有正最大李雅普诺夫指数的区域，小扰动在线性近似有效时可表现为

```math
\|\delta x(t)\|\approx \|\delta x(0)\|e^{\lambda t},
\qquad \lambda>0.
```

若允许误差为 $\Delta$、初始误差为 $\delta_0$，则粗略预测时域为

```math
t_{\mathrm{pred}}\approx\lambda^{-1}\log(\Delta/\delta_0).
```

这是局部指数增长阶段的估计，不能无条件延伸到误差饱和、近碰撞或所有初始状态。三体问题也存在周期解和其他规则运动；不能说所有三体轨道都是混沌的。关于方程、特殊解及一般动力学背景，参见 [Chenciner 的三体问题综述](https://www.scholarpedia.org/article/Three_body)。

### 3.2 三体系统当然可以使用概率测度

设流映射为 $\Phi^t$，初始状态服从 $\mu_0$。只要该流在所研究状态和时间上良好定义，分布演化就是推前测度

```math
\mu_t=(\Phi^t)_\#\mu_0,
\qquad
\mu_t(A)=\mu_0\big((\Phi^t)^{-1}A\big).
```

因此，困难不是“混沌没有概率”，而是：初始测度来自什么测量或制备过程？结果对它有多敏感？计算能否可靠传播这种不确定性？

如果初值完全指定，可取 $\mu_0=\delta_{x_0}$，其演化仍是单点测度。混沌不会仅凭动力学把精确已知初值变成客观随机初值。

### 3.3 概率存在不等于有自然的平衡分布

无约束引力系统可以逃逸，相关能量壳也未必具有有限相空间体积。因此不能不加条件地给三体系统写下一个归一化的“全局均匀平衡测度”。有限时间的初值分布、逃逸概率与平衡不变概率测度，是不同对象。

## 4. 计算不可约性及其适用边界

### 4.1 三种困难不能混为一谈

| 概念 | 主要问题 | 不自动意味着什么 |
|---|---|---|
| 混沌 | 初值误差是否随时间放大？ | 不意味着不存在统计规律 |
| 非可积性 | 是否缺少足够的独立守恒量以作通常意义的完全积分？ | 不意味着所有任务都不可计算 |
| 计算不可约性 | 指定预测任务能否显著快于逐步演化？ | 不意味着所有宏观量都没有简化表达 |

“没有简单闭式通解”“计算代价很高”“严格不可计算”“不存在渐近加速算法”是不同强度的命题。

### 4.2 不可约性必须相对于任务定义

对离散系统 $x_{n+1}=F(x_n)$，考虑

```math
Q(x_0,T)=g(F^T(x_0)).
```

要讨论是否存在计算捷径，必须明确输入编码、时间 $T$ 的编码、输出精度、可用算法、最坏或平均情形，以及比较的计算成本。逐步迭代 $T$ 次只是一个基准算法，不是“所有算法都必须如此”的证明。

Wolfram 将计算不可约性用于描述某些演化难以被整体预测捷径取代的现象；这一方法论主张不能直接充当普通牛顿三体问题的复杂性下界定理。**本文不再展开**：元胞自动机、Rule 110、学界对“不可约性”主张的批评与 AlphaFold 等实证案例，见《计算不可约性与科学方法》。对本文主线，这一章只需保住一句话：**“算不出”与“没有概率”是两回事**——计算上不可约的系统，仍然可以在分布层面回答问题，前提是初值测度有依据（第 3.2 节）。

### 4.3 微观难预测仍可有宏观简化

即使完整轨迹难以压缩，守恒量、对称性、长期平均、尺度关系或粗粒化变量仍可能容易计算。总能量守恒并不要求先重建每个时刻的全部坐标。

科学因此不必只追求完整复现。它也可以寻找：**对当前问题足够、对细节不敏感、计算上可行的描述。**

## 5. 统计物理：测度、典型性与宏观规律

### 5.1 动力学为什么提供测度结构

哈密顿系统满足

```math
\dot q_i=\frac{\partial H}{\partial p_i},\qquad
\dot p_i=-\frac{\partial H}{\partial q_i}.
```

对足够光滑的哈密顿量，哈密顿向量场散度为零，流保持刘维尔体积

```math
d\Gamma=\prod_{i=1}^{d}dq_i\,dp_i.
```

这提供了与动力学相容的测度结构，但**体积不变性本身不唯一决定实验中应采用的概率分布**。初始制备、能量和其他约束仍然重要。

### 5.2 微正则与正则分布的条件

对能量固定、相应归一化常数有限的系统，微正则分布形式上写为

```math
d\mu_E(x)=\frac{\delta(H(x)-E)d\Gamma}{Z_E},
\qquad
Z_E=\int\delta(H(x)-E)d\Gamma.
```

这里的 $\delta$ 表达能量壳上的诱导测度；在正则能量面上，它对应 $d\Sigma/\|\nabla H\|$，不是不加权的任意曲面面积测度。其他独立守恒约束也应纳入。实际讨论还可使用窄能量层，避免将形式表达误作普通密度函数。

对于与大热浴弱耦合、处于热平衡且配分函数有限的系统，正则分布为

```math
\rho_\beta(x)=Z(\beta)^{-1}e^{-\beta H(x)},
\quad Z(\beta)=\int e^{-\beta H(x)}d\Gamma,
\quad \beta=(k_BT)^{-1}.
```

这些分布的正当性来自明确条件下的物理建模，而非“物理对象天然服从某个已知分布”。

### 5.3 典型性相对于测度和宏观划分

设宏观状态 $M$ 对应微观区域 $\Gamma_M$。以固定参考尺度使体积比无量纲，可定义玻尔兹曼熵

```math
S_B(M)=k_B\log\frac{m(\Gamma_M)}{m_{\mathrm{ref}}}.
```

如果平衡宏观区域 $\Gamma_{\mathrm{eq}}$ 占允许区域 $\Gamma$ 的绝大部分，即

```math
\mu(\Gamma_{\mathrm{eq}})\geq1-\varepsilon,
```

那么相对于这个 $\mu$，平衡宏观状态是典型的。典型性不是“没有假设的大多数”，它依赖参考测度、约束和粗粒化方式。

还须区分静态体积结论与动态趋近平衡：区域很大，并不单独证明某个低熵初态会在实验时间内进入它。后者还需要动力学性质和初始条件的论证。量子理论中，[Goldstein 等的典型正则性研究](https://arxiv.org/abs/cond-mat/0511091)在相应能量约束与子系统条件下说明，大量纯态的子系统可呈现近似正则行为；这不是任意经典系统均会热化的证明。

### 5.4 大自由度为什么有帮助

若 $X_1,\ldots,X_N$ 独立同分布且方差有限，则

```math
\operatorname{Var}\!\left(\frac1N\sum_{i=1}^N X_i\right)
=\frac{\operatorname{Var}(X_1)}N.
```

在一般相关情形下，准确表达是

```math
\operatorname{Var}(\bar X_N)
=\frac1{N^2}\sum_{i,j=1}^{N}\operatorname{Cov}(X_i,X_j).
```

这揭示宏观稳定性的一个来源：当相关性足够弱，平均可以压低相对涨落；但临界点、长程相互作用和强相关可能破坏简单的 $N^{-1/2}$ 缩放。大数目不是充分条件。

## 6. 不变性、平稳性、遍历性与混合性

### 6.1 四个概念的准确关系

**不变测度：** 对动力学映射 $T$，

```math
\mu(T^{-1}A)=\mu(A),\qquad A\in\mathcal F.
```

**严格平稳：** 随机过程所有有限维联合分布在时间平移下不变：

```math
(X_{t_1},\ldots,X_{t_k})\overset d=
(X_{t_1+h},\ldots,X_{t_k+h}).
```

若 $x_0\sim\mu$ 且 $\mu$ 对 $T$ 不变，则 $X_t=g(T^t x_0)$ 是平稳过程。平稳并不意味着每条轨道恒定，也不意味着无波动。

**遍历性：** 在测度保持系统中，每个满足 $T^{-1}A=A$（模零集）的不变事件，其概率都是 $0$ 或 $1$。它排除了正测度的不变分区。

**强混合性：**

```math
\mu(A\cap T^{-n}B)\longrightarrow\mu(A)\mu(B).
```

强混合蕴含遍历，遍历一般不蕴含强混合。不变测度也不必唯一。

### 6.2 遍历定理说什么、不说什么

设 $T$ 保持概率测度 $\mu$，$f\in L^1(\mu)$，$\mathcal I$ 是不变事件构成的 $\sigma$-代数。Birkhoff 定理给出

```math
\frac1N\sum_{n=0}^{N-1}f(T^n x)
\longrightarrow\mathbb E_\mu[f\mid\mathcal I](x)
\quad\text{对 }\mu\text{-几乎处处的 }x.
```

若系统遍历，则极限为

```math
\int f\,d\mu.
```

这个定理连接无限时间平均与系综平均，但不自动给出有限时间收敛速度，也不保证一次现实观测已足够长。参见 [Birkhoff 原始论文](https://doi.org/10.1073/pnas.17.2.656)。

### 6.3 为什么遍历性不是统计物理的唯一基础

宏观观测量可能在绝大多数微观状态上接近同一值，即使系统并未探索全部相空间，仍可获得稳定预测。可积系统、玻璃态、亚稳态和近可积系统，则提醒我们必须明确观测时标、变量以及适用的系综。

因此，应分别问：测度是否合适？宏观量是否集中？动力学是否到达相关区域？所需时间是否可接受？“遍历”不能一次回答全部问题。

## 7. 金融市场：非平稳性、适应性与反身性

### 7.1 非平稳不等于没有概率

对于信息集 $\mathcal F_t$，仍可建模条件预测分布

```math
P_t(A)=\Pr(Y_{t+1}\in A\mid\mathcal F_t).
```

在标准可测空间等通常条件下，这可以用正则条件分布表达。未来分布可以随时间变化，而完整路径空间上仍存在一个概率法则。

还要避免把“条件分布变化”直接定义为“非平稳”：平稳过程的条件均值和条件方差也可以随已观测状态变化。严格非平稳指联合分布不满足时间平移不变性。

实践难点是识别：只有一条历史路径时，如何区分随机波动、隐藏状态变化和生成机制改变？近期分布估计不必等于下一阶段分布。

### 7.2 适应性让机制成为内生变量

可用以下示意模型表达：

```math
x_{t+1}=F(x_t,a_t,\theta_t,\varepsilon_{t+1}),
```

```math
a_t=\pi_t(\mathcal F_t),\qquad
\theta_{t+1}=G(\theta_t,x_t,a_t,\eta_{t+1}).
```

其中 $x_t$ 为状态，$a_t$ 为参与者行动，$\theta_t$ 表示制度、技术或行为规则。主体会学习、模仿和竞争，行为改变价格及资源约束，改变后的环境又触发新一轮学习。

Arthur 的[复杂性经济学框架](https://sites.santafe.edu/~wbarthur/complexityeconomics.htm)强调行动与预期会响应它们共同生成的环境；这为分析市场适应性提供了一种机制视角，而非宣称所有市场模型都必须永远远离均衡。

### 7.3 反身性：预测可能改变预测对象

简化反馈链条是

```math
\text{预测}\longrightarrow\text{行动}\longrightarrow
\text{价格、约束与信息}\longrightarrow\text{新预测}.
```

预期可能自我实现，也可能自我否定；方向取决于机制。例如普遍预期某机会存在，会改变参与规模，从而改变机会本身。

经济学为这个现象准备了两个正式名字。**Lucas 批评（1976）**：用历史数据估出的政策—产出关系（如菲利普斯曲线），一旦政策制定者利用它来制定新政策，行为主体的预期随之改变，估出的关系本身就会失效——宏观计量的“参数”依赖正在被评估的政策体制。**Goodhart 定律**的通俗版本是：**“当一个压力指标变成目标，它就不再是一个好的压力指标”**——银行按某一风险指标被监管，就会重组资产负债表让指标好看，而真实风险换了个地方。Lucas 批评、Goodhart 定律与下文的 performative prediction，是同一件事在宏观经济、金融监管与机器学习中的三个版本：**估计对象与使用方式纠缠时，“历史规律”自带保质期**。

设部署参数 $\theta$ 会诱导数据分布 $\mathcal D(\theta)$，部署后的风险为

```math
R(\theta)=\mathbb E_{Z\sim\mathcal D(\theta)}[\ell(\theta,Z)].
```

它与在固定历史分布 $\mathcal D_0$ 上最小化损失不是同一问题。这一形式来自[执行性预测研究](https://arxiv.org/abs/2002.06673)，可作为反身性的一个局部模型，但不穷尽金融反身性的全部社会与制度含义。

### 7.4 扩大状态空间能否消除困难

有时把隐藏状态、制度或时间纳入状态变量，可以把时变模型改写为形式上的齐次模型。然而，这不保证新增状态可观测、转移规律可识别、过程存在平稳分布，或未来创新已被完整列举。

因此，“总能写出更大的模型”不等于“已经获得可用于决策的稳定知识”。

## 8. 统计物理与金融的关键区别

### 8.1 应比较适用结构，而不是贴遍历标签

| 比较维度 | 常见平衡统计物理建模 | 适应性金融市场建模 |
|---|---|---|
| 动力学 | 在适用尺度内可采用稳定、受实验支持的基本方程 | 有效行为规则受学习、政策、技术与组织影响 |
| 测度选择 | 守恒量、制备方式、热浴及几何结构提供较强约束 | 条件分布更依赖制度、行为假设和有限历史样本 |
| 主体行为 | 微观对象通常不根据研究者公布的预测修订策略 | 参与者会理解预测、竞争并调整行动 |
| 重复与控制 | 许多实验能控制约束并重复制备 | 历史场景难以完整复制，制度干预常有联动 |
| 宏观简化 | 大自由度和弱相关常支持集中与普适关系 | 同向反应、网络关联和拥挤可能放大共同波动 |
| 时间尺度 | 平衡、弛豫与观测时标需要明确比较 | 估计、学习、制度变化和执行时标共同作用 |
| 遍历性 | 在部分模型中有用，也可能不成立 | 在特定模型中可成立，但不能据此保证现实外推 |

这是一组典型建模差异，而不是将两个领域划分为绝对不相交的类别。非平衡物理也有驱动、反馈和历史依赖；市场也有会计恒等式、结算约束、合约规则和相对稳定的局部机制。

### 8.2 更准确的核心命题

**统计物理与金融的关键区别，在于有效规律、概率结构及其经验支撑的稳定程度，以及预测和行动是否会内生地改变这些结构。遍历性只是给定动力学与测度之后的性质。**

如果连“哪个动力学、哪个测度、哪个观测量、哪个时标”都未明确，直接问“市场是否遍历”常常缺乏确定的数学对象。

### 8.3 乘法增长不能代替领域层面的比较

设独立同分布的收益率为 $R_t>-1$，

```math
W_T=W_0\prod_{t=1}^{T}(1+R_t).
```

若相应期望存在，则

```math
\mathbb E[W_T]=W_0(1+\mathbb E[R])^T,
```

而在 $\mathbb E|\log(1+R)|<\infty$ 时，

```math
\frac1T\log\frac{W_T}{W_0}
\longrightarrow\mathbb E[\log(1+R)]
\quad\text{几乎必然}.
```

由 Jensen 不等式，

```math
\mathbb E[\log(1+R)]\leq\log(1+\mathbb E[R]).
```

这解释了平均财富与典型路径增长之间的差别，但它比较的是不同统计对象。收益率过程即使是独立同分布、平稳且遍历，也会出现这种差别。因此，不能从该不等式推出“金融整体非遍历”。

把这个区别做成投资决策的完整算例（期望增长与路径增长何时给出相反答案、最优杠杆为何是 $\ell^*=\mu/\sigma^2$），见 Peters（2011, *Quantitative Finance*；2019, *Nature Physics*）与《未知世界中的最优动态决策》§13.1。注意那个论证的正确用途：它警告的是**“用错误的统计对象做决策”**（拿期望代替路径增长去上杠杆），而不是宣布“市场非遍历所以概率论失效”——后者正是本节想守住的口径。

<a id="s9"></a>
## 9. 归纳问题与可迁移结构

### 9.1 历史证据不能无条件推出未来

从“过去观察到规律”到“未来仍成立”，必须增加某种持续性假设。用“过去外推曾经成功”来证明今后的外推可靠，又使用了同类归纳推理。

休谟问题并不证明经验研究无用，而是指出其正当性不能简化为无前提的演绎证明。相关哲学背景见[《归纳问题》](https://plato.stanford.edu/archives/spr2021/entries/induction-problem/)。

### 9.2 贝叶斯更新没有消除模型边界

在模型 $M$ 内，

```math
p(\theta\mid D,M)
\propto p(D\mid\theta,M)p(\theta\mid M).
```

这规定怎样使用证据更新已有假设，却不保证 $M$ 包含真实机制。对多个模型进行平均，仍依赖候选集合、先验和似然的适当性。后验集中也可能是在错误模型内部变得越来越自信。

### 9.3 迁移的对象可以比完整分布更小

设环境由 $e$ 标记。边际分布 $P_e(X,Y)$ 变化，不排除某个局部关系近似稳定，例如

```math
P_e(Y\mid X_S)\approx P_{e'}(Y\mid X_S).
```

但条件关系稳定不是因果性的充分证明；隐藏混杂、选择偏差和环境变化范围都可能影响判断。

可迁移结构可分成三类：

1. **恒等与约束：** 守恒、会计关系、资源约束、合约定义。其有效性依赖对象定义与适用制度。
2. **机制关系：** 在限定干预与环境范围内成立的因果或动力学关系。
3. **经验规律：** 跨样本或跨环境表现稳定的统计关系，需持续检验失效条件。

约束通常比精确参数更容易迁移，机制可能比边际相关更稳定，但这些都不是无条件的等级定理。

### 9.4 如何检验迁移主张

不能只问“历史上是否拟合良好”，还应问：训练和检验环境究竟哪里不同？稳定关系是否有机制解释？改变行动是否会改变关系？哪些观测会使我们放弃这个解释？

迁移不是把过去整体复制到未来，而是提出范围明确、可以失败的结构假设。

<a id="s10"></a>
## 10. 从概率预测走向反馈决策

### 10.1 决策需要损失与约束

若状态为 $Y$、行动为 $a$、损失为 $L(a,Y)$，单一模型下的决策是

```math
a_t^*\in\arg\min_{a\in\mathcal A_t}
\mathbb E_{P_t}[L(a,Y)].
```

预测相同不代表行动相同：不同损失、资源约束与可逆性，会产生不同最优行动。决策目标也不能由概率分布独自决定。

### 10.2 显式处理模型不确定性

在候选模型集合 $\mathcal P_t$ 上，一种稳健准则是

```math
a_t^*\in\arg\min_{a\in\mathcal A_t}
\sup_{P\in\mathcal P_t}\mathbb E_P[L(a,Y)].
```

它关注候选范围内的最坏情况，但可能过度保守；结果高度依赖集合构造。若未来机制超出 $\mathcal P_t$，所谓稳健性也没有覆盖它。

因此，稳健准则需要与情景分析、暴露限制和模型修正共同使用，不能作为未知风险已被消除的证明。

### 10.3 反馈决策的基本循环

```math
\text{观测}\rightarrow\text{更新状态与模型}\rightarrow
\text{选择受约束行动}\rightarrow\text{观测后果}\rightarrow
\text{检验与修正}.
```

落地时至少应明确：

- **观测：** 哪些变量可实时获得？有何延迟和误差？
- **更新：** 新证据是在改变参数，还是提示模型结构失效？
- **行动：** 成本、资源边界和不可逆后果是什么？
- **评估：** 结果来自外部变化，还是行动改变了环境？
- **修正：** 哪些阈值触发降级、暂停、扩大情景范围或替换模型？

行动还可能帮助识别未知机制，这构成控制与学习的耦合；但为学习而采取的行动也有代价，不能把探索本身视为无风险收益。

### 10.4 反馈有效需要时间与稳定性条件

一种有用但非普遍定理的工作假设是

```math
\tau_{\mathrm{learn}}+\tau_{\mathrm{act}}
\ll\tau_{\mathrm{change}},
```

即学习与行动完成得比关键机制变化更快。若这一关系不成立，快速追逐最新数据也可能只是在追逐噪声。

反馈本身还可能因时滞、噪声、高增益和群体同步而放大不稳定。因此，反馈决策的优势是可以修正，不是保证每次修正都正确。

## 11. 方法落地与检查清单

### 11.1 七步研究流程

| 步骤 | 应产出的内容 | 关键检查 |
|---|---|---|
| 1. 定义任务 | 预测对象、时域、行动与损失 | 是轨迹预测、分布估计，还是决策？ |
| 2. 列出不确定性 | 状态、参数、模型及结构变化清单 | 是否把模型无知误写成精确概率？ |
| 3. 指明概率来源 | 制备机制、经验估计或先验依据 | 是否可识别，是否依赖未说明假设？ |
| 4. 确定结构与边界 | 守恒、约束、机制和有效环境 | 哪些可迁移，哪些仅为局部拟合？ |
| 5. 检验预测 | 按时间和环境划分的检验结果 | 是否泄漏未来信息，是否反复选择同一检验集？ |
| 6. 设计反馈 | 更新频率、行动约束和失效响应 | 学习、执行和机制变化时标是否匹配？ |
| 7. 审计结果 | 预测误差、决策损失、干预后变化 | 是随机误差、估计误差，还是机制改变？ |

### 11.2 概率预测应检查什么

以二元事件预测 $p_t$ 和结果 $y_t\in\{0,1\}$ 为例，Brier 分数为

```math
\mathrm{BS}=\frac1T\sum_{t=1}^{T}(p_t-y_t)^2.
```

它可以衡量概率预测误差，但总分无法独自揭示结构变化。还应按时间、环境和状态检查校准与区分能力，并考虑依赖数据下的统计误差。

恒定预测基准概率有时可以校准，却没有足够区分能力；较好的预测分数也不保证扣除行动成本后的决策更优。

### 11.3 三类系统应选择不同目标

| 对象 | 较合理的任务 | 必须检查的边界 |
|---|---|---|
| 三体混沌 | 有限时域轨道区间、给定初值分布下的事件概率 | 初值误差、近碰撞、数值稳定性与测度敏感性 |
| 平衡统计物理 | 宏观量、涨落、响应和适当系综下的统计规律 | 约束、有限尺寸、相关长度及弛豫时间 |
| 适应性市场 | 条件预测、机制情景与受约束反馈决策 | 制度变化、参与者适应、拥挤和行动影响 |

“完整预测不了”不等于“什么也做不了”。合理做法是缩小任务，寻找足够稳定的结构，并把失效条件写入方法。

## 12. 常见误区与结论

| 误区 | 更准确的表达 |
|---|---|
| 所有未知都天然对应唯一概率 | 可赋予测度不等于有充分依据选择唯一测度 |
| 三体混沌没有概率分布 | 给定初值测度即可传播分布，难点是依据与计算 |
| 混沌证明计算不可约 | 二者涉及不同问题，需要各自的条件与证明 |
| 统计物理成立是因为系统都遍历 | 系综、典型性、集中、动力学及观测时标共同重要 |
| 大自由度必然消除波动 | 强相关和临界现象可能使简单平均失效 |
| 非平稳意味着概率论无效 | 时变过程仍可有概率法则，但历史外推需要论证 |
| 条件分布变化必然非平稳 | 平稳过程的条件分布也可以随信息变化 |
| 金融与物理的区别就是非遍历与遍历 | 更深的区别涉及机制稳定性、可识别性与主体反馈 |
| 贝叶斯更新解决了归纳问题 | 更新仍以模型空间、先验及似然的适当性为前提 |
| 反馈可以保证适应成功 | 时滞、噪声和共同反应也可能使反馈失稳 |

本文得到的是一种分层方法论：先明确概率的来源，再区分数学推理、经验识别、计算可行性与跨环境迁移。对稳定机制，尽量建立可解释、可检验的分布模型；对适应性环境，进一步检验行动对分布的影响，并用受约束、可修正的反馈机制管理模型失效。

科学的目标不必是对全部未来逐点预言。它也可以是识别稳定约束、解释有效机制、界定预测期限，并在持续获得证据的过程中改进行动。承认认识论边界，不要求放弃概率；它要求把概率模型的条件、用途和失效方式表达得更清楚。
