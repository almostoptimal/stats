## 摘要

天气预报说"降水概率 60%"，医生说"手术成功率 90%"，模型说"明天上涨概率 55%"——这三个数字的**可信程度完全不同**，但看起来一模一样。这篇笔记回答的问题就是：一个概率数字凭什么可信？不可信的时候怎么办？

具体沿四个问题展开：**概率的本质是什么、现实中的概率分布怎么来的**（第 2 章）；**物理世界的概率**凭什么可靠（第 3–4 章）；**金融市场的概率**还剩多少可靠（第 5 章）；概率不够用时如何行动（第 6–8 章）。

概率论提供的是给定概率空间之后的严密推理规则；它不回答现实问题是否具有唯一、可识别且可迁移的概率分布。本文沿一条主线展开：**"一个系统有概率"要过五道关——数学存在、经验解释、统计识别、计算可行、跨环境有效**。三体混沌（第 3 章）说明确定性不保证可预测、"有概率"不等于"有依据"；统计物理（第 4 章）说明宏观规律为什么能在微观复杂性中出现，以及这依赖哪些条件；金融市场（第 5 章）在前两者之外还多了适应性与反身性——**预测会改变被预测的对象**。前半部分的结论不是"物理可以、金融不行"，而是：**每一层可靠性的代价都要单独论证，谁也不能替谁付账**。

后半部分处理概率不够用时的决策：归纳的边界、可迁移结构的三类对象，以及反馈修正的循环与时标（第 6–8 章）。

## 1. 核心问题：概率何时可靠

“这个系统有概率吗？”至少包含五个不同问题：

| 层次 | 实际问题 | 需要的依据 |
|---|---|---|
| 数学存在 | 能否在某个可测空间上定义概率测度？ | 测度论构造 |
| 物理或认识论解释 | 这个测度代表随机机制、制备方式，还是信念？ | 机制、实验设计或推断规则 |
| 统计识别 | 数据能否区分不同候选测度？ | 可识别性、观测条件、样本信息 |
| 计算可行 | 即使测度已知，能否计算所需概率或最优行动？ | 算法、近似误差、计算资源 |
| 跨环境有效 | 历史得到的规律能否用于未来和干预之后？ | 稳定性、结构假设、反馈分析 |

这些问题不能相互替代。一个模型可以数学上完全合法，却经验上缺乏支持；一个分布可以客观存在，却难以识别；一个已知的随机机制，也可能具有难以计算的尾部概率。

把这张表翻译成日常语言。以"模型预测明天沪深 300 上涨，概率 55%"为例，五道关分别是：

1. **数学存在**——"55%" 是不是在一个合法概率空间里定义的数？（这关几乎总能过，所以单独过它没意义）
2. **经验解释**——这个数代表什么的 55%？长期频率、今天的条件概率，还是模型作者的一份主观信心？
3. **统计识别**——手上的历史数据，能不能把"真值 55%"和"真值其实是 45%"区分开？数据不够时，55% 只是一个没有被检验过的数。
4. **计算可行**——即使真值已知，你要算的那个量（比如"下月最大回撤超 10% 的概率"）算得出来吗？
5. **跨环境有效**——这条规律是机制性的，还是恰好这段历史长这样？监管一变、参与者一学乖，它还在吗？

天气预报的降水概率大约能过第 4 关（算得出来），机制也足够稳定，第 5 关基本立得住；而上面那个"55%"可能连第 2 关都说不清——它代表什么，取决于模型作者没说出口的那套假设。

本文的基本立场是：**概率论的推理有效性，与现实概率模型的适用有效性，应分别论证。**全文据此分两半：第 2–5 章逐层检验"一个概率模型何时可信"——从数学存在一路查到跨环境迁移；第 6–8 章处理"可信度不足时如何决策与修正"。三体、统计物理和金融市场在文中不是三个并列话题，而是同一组检验在三种环境下的试金石：三体负责检验"确定性与概率的关系"，统计物理负责检验"宏观规律从何而来"，市场负责检验"预测与行动纠缠时还剩多少可靠性"。

## 2. 现实中的概率分布怎么来的：数学存在与经验正当性

**本章检验：第 1–2 关——这个数在数学上是否合法，经验上有没有依据。**

### 2.1 概率的本质是什么：四种经典解释

第 1 章的五道关问的是"一个概率数字何时可信"；本节先回答一个更前置的问题：当我们说"上涨概率 55%"时，这个数**指什么**。Kolmogorov 公理（1933）只规定运算规则，不规定解释——同一套公理之下，历史上有四种互不相容的经典答案（[解释之争总览](https://plato.stanford.edu/entries/probability-interpret/)见斯坦福哲学百科条目）。

**一、频率解释：概率是长期频率的极限。**对可重复试验，概率定义为

```math
p=\lim_{N\to\infty}\frac{n(A)}{N},
```

其中 n(A) 是 N 次重复中事件 A 发生的次数。代表是 von Mises（1928）的"集合"（Kollektiv）概念：概率只对可无限重复的实验序列有定义。优点是客观、可检验；代价是**一次性事件被排除在外**——"明天上涨"没有序列，严格的频率论者只能说这句话没有概率。

**二、倾向解释：概率是物理机制的单次倾向。**Popper（1957）把概率归属到实验装置本身：骰子的对称性、放射性核素的衰变常数。衰变时间 T 服从

```math
\Pr(T>t)=e^{-\lambda t},\qquad t_{1/2}=\frac{\ln2}{\lambda},
```

半衰期 t½ 是机制的属性，不需要任何重复序列。优点是允许单次事件的客观概率；弱点是**要求机制稳定**——第 5 章的主题恰恰是：金融市场里"装置本身"会被参与者的行为改写，倾向解释的地基随之松动。

**三、主观信念解释：概率是完备主体的赌价。**Ramsey（1926）与 de Finetti（1937）把概率定义为理性主体愿意接受的赌率，并以 Dutch book 定理论证：若一组赌价违背概率公理，对手可以构造无论结果如何都稳赢的赌注组合。de Finetti 定理进一步说明：把一串数据看作独立同分布，等价于对它们的共同分布持一个信念先验、再加可交换性假设。优点是覆盖一次性事件；代价是概率成了**主体的属性**而非世界的属性——两个同样理性的主体可以合理地给出不同数值。

这一区分有实验室证据。**Ellsberg（1961）的双瓮实验**：瓮 A 装 50 个红球和 50 个黑球，比例已知；瓮 B 同样装 100 个红黑球，但比例完全未知。多数人愿意为“从瓮 A 摸出红球”支付更高的价格——而按任何单一主观概率（对瓮 B 同样赋 50/50），两个赌局的期望完全相同。人对瓮 B 缺的不是一个数，而是**对“这个数是否可信”的信心**；强行给两个瓮配上同一个先验，就把这个差别抹掉了。Knight（1921）则把可赋概率的“风险”与不可赋概率的“不确定性”分开，并指出利润的来源正是后者。Ellsberg 的实验是这一区分在心理学中的实证版本，也预告了第 2.3 节“能定义 ≠ 有依据”的缺口。

**四、逻辑/证据解释：概率是证据对假说的支持度。**Keynes（1921）与 Carnap（1950）希望为"证据 E 在多大程度上支持假说 H"找到唯一客观的度量。这条路最大的障碍是无差别原则的任意性：Bertrand 悖论（1889）里，对"圆内随机弦比内接正方形边长更长"这同一个问题，三种同样"无差别"的参数化分别给出 1/2、1/3、1/4——与下一节圆盘取点的例子同源。

**本文的立场是不选边**，而是把四种解释当作"分布怎么来的"四条路径的索引：倾向解释对应机制稳定的物理世界（第 3–4 章），频率解释对应可重复的制备与测量（第 4 章的系综与典型性），主观解释对应只有一条历史路径的金融市场（第 5 章），逻辑解释的困境则预告了第 2.3 节"能定义 ≠ 有依据"的缺口。五道关检验的是：无论采取哪种解释，这个数都要在每一关出示自己的凭证。

**常见错误：**

- **把公理当解释。**满足 Kolmogorov 公理只说明运算自洽，不回答"这个数指什么"——缺口在第 2.3 节。
- **把频率解释用于一次性事件。**"明天下雨概率 60%"不是任何序列的频率，而是数值天气预报模式的倾向性输出加主观修正的混合物。
- **把可交换性当免费假设。**de Finetti 定理的还原以可交换性为前提，"数据的顺序不含信息"本身就是一条实质断言。
- **在机制可变的系统里用倾向解释。**参数随参与者行为漂移的系统里（第 5 章），"装置的倾向"没有固定所指。

### 2.2 概率公理规定什么

先看概率论自己能保证什么。现代概率论把"概率"定义为满足一组公理的测度，整个体系的出发点是概率空间

```math
(\Omega,\mathcal F,P),
```

其中 Ω 是样本空间，ℱ 是事件的 σ-代数，P 满足

```math
P(A)\geq 0,\qquad P(\Omega)=1,
```

以及对两两不交的事件 A₁, A₂, …，

```math
P\!\left(\bigcup_{n=1}^{\infty}A_n\right)
=\sum_{n=1}^{\infty}P(A_n).
```

公理给出一致的运算规则，却不替我们决定样本空间、信息集合或概率数值。把未知结果列成几个选项后赋予均匀概率，也不是由“无知”唯一推出的结论；换一种参数化，所谓均匀可能就改变了。一个具体的例子：在圆盘上"随机取一点"——按坐标均匀取是一种取法，按半径加权取是另一种，两种都自称"无偏"，但算出的"点落在中心小圆里"的概率完全不同。"均匀"不是一个客观事实，而是你先得选定的一个参数化方案。

### 2.3 “所有不确定性都有概率测度”如何回答

从纯数学角度，只要非空可测空间中选定一点 ω₀，就可以定义狄拉克测度

```math
\delta_{\omega_0}(A)=\mathbf 1_{\{\omega_0\in A\}}.
```

但这显然不能解决现实中的无知。**能赋予某个测度，不等于存在一个由现有证据充分支持的唯一测度。**用白话说：数学上你永远可以写下"瓮 B 有 50% 红球的概率是 1"这样的式子，它的合法性毫无问题——问题在于它对"瓮 B 里到底有多少红球"没有提供任何证据。**"能定义"与"有依据"之间的这道缝，就是本篇全部内容要量的事。**

还应区分：

- **机制不确定性：** 在采用的理论中，结果由随机机制产生。
- **状态不确定性：** 动力学给定，但初始状态、参数或观测不精确。
- **模型不确定性：** 不确定哪些变量、方程或机制适用。
- **结构性无知：** 相关事件、制度变化或新行为方式尚未进入建模范围。

这些层次可以同时存在。概率表示能够覆盖很多不确定性，但把它们全部压缩为一个精确分布，可能掩盖证据不足。

## 3. 物理世界的概率（上）：确定性系统的可预测性边界

**本章检验：第 4 关——就算分布已知，算不算得出来；先守住前提示：确定性不等于可预测。**

### 3.1 确定性方程不保证长期可预测

牛顿引力三体系统满足

```math
\ddot{\mathbf r}_i
=G\sum_{j\ne i}m_j
\frac{\mathbf r_j-\mathbf r_i}{\|\mathbf r_j-\mathbf r_i\|^3},
\qquad i=1,2,3.
```

在没有碰撞的有限时间区间内，只要初始状态完整给定，微分方程的存在唯一性定理就保证轨迹唯一。但"轨迹唯一"说的是初值决定演化，不等于有限精度的观测足以支撑任意长时间的精确预测——这两件事经常被混为一谈。

在具有正最大李雅普诺夫指数的区域，小扰动在线性近似有效时可表现为

```math
\|\delta x(t)\|\approx \|\delta x(0)\|e^{\lambda t},
\qquad \lambda>0.
```

若允许误差为 Δ、初始误差为 δ₀，则粗略预测时域为

```math
t_{\mathrm{pred}}\approx\lambda^{-1}\log(\Delta/\delta_0).
```

这只是误差指数增长阶段的粗略估计，不能无条件外推到误差饱和、近距离碰撞或其他特殊初始状态。三体问题也存在周期解和其他规则运动；不能说所有三体轨道都是混沌的。关于方程、特殊解及一般动力学背景，参见 [Chenciner 的三体问题综述](https://www.scholarpedia.org/article/Three_body)。

这个公式最值得记住的是它的**对数形状**。取 λ = 1/年、初始误差 1 米、允许误差 1 000 公里，预测时域约为 log(10⁶) ≈ 13.8 年。现在把初始精度提高一千倍（误差 1 毫米），预测时域只增加 log(10³) ≈ 6.9 年——**付出一千倍的测量代价，换回一半多一点的预测期**。混沌世界里，精度和预测期之间是打对折再打对折的交换律，不存在"测得足够准就能长期预测"的便宜事。

### 3.2 三体系统当然可以使用概率测度

设流映射为 Φᵗ，初始状态服从 μ₀。只要这个映射在所研究的范围内有良好定义，分布随时间的演化就是把它往前推：

```math
\mu_t=(\Phi^t)_\#\mu_0,
\qquad
\mu_t(A)=\mu_0\big((\Phi^t)^{-1}A\big).
```

因此，困难不是“混沌没有概率”，而是：初始测度来自什么测量或制备过程？结果对它有多敏感？计算能否可靠传播这种不确定性？

这个式子的日常读法：给每个可能的初值按测量精度配上"权重"，让力学方程自己把权重搬运到未来时刻，然后数一数落在你关心的区域里还剩多少权重。混沌不破坏这套搬运手续——它只是把权重摊得越来越开、越来越散。**"权重越摊越散"与"预测期有限"是同一件事的两种说法。**

如果初值完全指定，可取 μ₀ = δ(x₀)，其演化仍是单点测度。混沌不会仅凭动力学把精确已知初值变成客观随机初值。

### 3.3 概率存在不等于有自然的平衡分布

还有一个容易踩的坑：即便承认三体系统"有概率"，它也未必有像统计物理那样自然的平衡分布。无约束的引力系统可以逃逸，相应的能量壳也未必具有有限的相空间体积，所以不能不加条件地给三体系统写下一个归一化的"全局均匀平衡测度"。有限时间的初值分布、逃逸概率与平衡不变概率测度，是不同对象。

### 3.4 三种困难不能混为一谈

| 概念 | 主要问题 | 不自动意味着什么 |
|---|---|---|
| 混沌 | 初值误差是否随时间放大？ | 不意味着不存在统计规律 |
| 非可积性 | 是否缺少足够的独立守恒量以作通常意义的完全积分？ | 不意味着所有任务都不可计算 |
| 计算不可约性 | 指定预测任务能否显著快于逐步演化？ | 不意味着所有宏观量都没有简化表达 |

“没有简单闭式通解”“计算代价很高”“严格不可计算”“不存在渐近加速算法”是不同强度的命题。讨论“是否存在计算捷径”之前，还要先明确输入编码、输出精度、可用算法与成本口径——逐步迭代只是基准算法，不是“所有算法都必须如此”的证明。Wolfram 的“计算不可约性”是一种广泛的方法论主张，不能直接充当牛顿三体问题的复杂性下界定理；元胞自动机、Rule 110 与学界批评见《计算不可约性与科学方法》。对本文主线，只需保住一句话：**“算不出”与“没有概率”是两回事**——计算上不可约的系统，仍然可以在分布层面回答问题，前提是初值测度有依据（第 3.2 节）。

### 3.5 微观难预测仍可有宏观简化

即使完整轨迹难以压缩，守恒量、对称性、长期平均、尺度关系或粗粒化变量仍可能容易计算。总能量守恒并不要求先重建每个时刻的全部坐标。

科学因此不必只追求完整复现。它也可以寻找：**对当前问题足够、对细节不敏感、计算上可行的描述。**

<a id="s4"></a>
## 4. 物理世界的概率（下）：统计物理——宏观规律从何而来

**本章检验：第 2–3 关——物理世界的概率分布从哪来，凭什么能被数据识别。**

### 4.1 动力学为什么提供测度结构

哈密顿系统满足

```math
\dot q_i=\frac{\partial H}{\partial p_i},\qquad
\dot p_i=-\frac{\partial H}{\partial q_i}.
```

对足够光滑的哈密顿量，哈密顿向量场的散度为零，因此流保持刘维尔体积

```math
d\Gamma=\prod_{i=1}^{d}dq_i\,dp_i.
```

这提供了与动力学相容的测度结构，但**体积不变性本身不唯一决定实验中应采用的概率分布**。初始制备、能量和其他约束仍然重要。

### 4.2 微正则与正则分布的条件

对能量固定、相应归一化常数有限的系统，微正则分布形式上写为

```math
d\mu_E(x)=\frac{\delta(H(x)-E)d\Gamma}{Z_E},
\qquad
Z_E=\int\delta(H(x)-E)d\Gamma.
```

这里的 δ 表示能量壳上的诱导测度：在正则能量面上，它对应面元 dΣ/‖∇H‖，而不是不加权的曲面面积。如果还有其他独立守恒量，也要一并纳入约束。实际讨论中常用窄能量层代替这个形式记号，以免把它误当成普通的密度函数。

对于与大热浴弱耦合、处于热平衡且配分函数有限的系统，正则分布为

```math
\rho_\beta(x)=Z(\beta)^{-1}e^{-\beta H(x)},
\quad Z(\beta)=\int e^{-\beta H(x)}d\Gamma,
\quad \beta=(k_BT)^{-1}.
```

因此，这套定律的正当性来自明确条件下的物理建模，而非"物理对象天然服从某个已知分布"。两行公式的白话版：**微正则**=系统能量恰好固定时，"在能量面上人人机会均等"；**正则**=系统允许和一个温度为 T 的巨大热库交换能量，这时高能量状态的出现率按 e^(−βH) 打折（β 是温度的倒数，热库越热折扣越轻）。一杯热水之所以凉向室温而不是相反，宏观上就是这条分布在起作用——但注意它成立的前提：热库存在、弱耦合、已到平衡。三体系统哪条都不满足，所以 §3.3 说它写不出自然的平衡分布。

### 4.3 典型性相对于测度和宏观划分

设宏观状态 M 对应微观区域 Γ_M。以固定参考尺度使体积比无量纲，可定义玻尔兹曼熵

```math
S_B(M)=k_B\log\frac{m(\Gamma_M)}{m_{\mathrm{ref}}}.
```

如果平衡宏观区域 Γ_eq 占允许区域 Γ 的绝大部分，即

```math
\mu(\Gamma_{\mathrm{eq}})\geq1-\varepsilon,
```

那么相对于这个 μ，平衡宏观状态是典型的。典型性不是“没有假设的大多数”，它依赖参考测度、约束和粗粒化方式。

"占绝大部分"在物理世界里是压倒性的。数量级感受：一盒气体有 10²³ 量级的分子，"所有分子挤在半个盒子里"对应的微观状态占比是 e^(−10²³) 量级——即使从宇宙诞生起每秒抽查一万次，也抽不到一次。**平衡态不是动力学偏爱的状态，是它占的地盘实在太大**：随机演化几乎必然撞进它，就像抛 10²³ 次硬币几乎必然接近一半正面。这就是"典型性"三个字能撑起整座统计物理的原因。

还须区分静态体积结论与动态趋近平衡：区域很大，并不单独证明某个低熵初态会在实验时间内进入它。后者还需要动力学性质和初始条件的论证。量子理论中，[Goldstein 等的典型正则性研究](https://arxiv.org/abs/cond-mat/0511091)在相应能量约束与子系统条件下说明，大量纯态的子系统可呈现近似正则行为；这不是任意经典系统均会热化的证明。

### 4.4 大自由度为什么有帮助

若 X₁, …, X_N 独立同分布且方差有限，则

```math
\mathrm{Var}\!\left(\frac1N\sum_{i=1}^N X_i\right)
=\frac{\mathrm{Var}(X_1)}N.
```

在一般相关情形下，准确表达是

```math
\mathrm{Var}(\bar X_N)
=\frac1{N^2}\sum_{i,j=1}^{N}\mathrm{Cov}(X_i,X_j).
```

这揭示宏观稳定性的一个来源：当相关性足够弱，平均可以压低相对涨落；但临界点、长程相互作用和强相关可能破坏简单的 N^(-1/2) 缩放。大数目不是充分条件。

保险业把第一行公式做成了商业模式：单张保单的赔付波动很大，一万张独立保单的平均赔付波动只有单个的 1/√10000 = 1/100——"大数定律"是它的更响亮的名字。但一般式才是重点：相关性一旦变强（同一场巨灾同时打击所有保单），分母就不再是 N，平均的魔力失效。把"独立保单"换成"同涨同跌的资产"，就是组合分散化在危机中失灵的标准剧本。

### 4.5 四个概念的准确关系

**不变测度：** 对动力学映射 T，

```math
\mu(T^{-1}A)=\mu(A),\qquad A\in\mathcal F.
```

**严格平稳：** 随机过程所有有限维联合分布在时间平移下不变：

```math
(X_{t_1},\ldots,X_{t_k})\overset d=
(X_{t_1+h},\ldots,X_{t_k+h}).
```

若 x₀ 服从 μ 且 μ 对 T 不变，则 Xₜ = g(Tᵗx₀) 是平稳过程。平稳并不意味着每条轨道恒定，也不意味着无波动。

**遍历性：** 在测度保持系统中，每个满足 T⁻¹A = A（模零集）的不变事件，其概率都是 0 或 1。它排除了正测度的不变分区。

**强混合性：**

```math
\mu(A\cap T^{-n}B)\longrightarrow\mu(A)\mu(B).
```

强混合蕴含遍历，遍历一般不蕴含强混合。不变测度也不必唯一。

四个概念的白话对照：**不变**=统计规律不随日历改变（周一抛硬币和周日抛硬币同分布）；**严格平稳**=过程任何一段的性质只取决于"从哪看"，不取决于"哪一年看"；**遍历**=系统没有"永远进不去的区域"，一条足够长的轨道能看遍所有典型面貌；**强混合**=不但到得了，还会忘掉出发的位置——初期相关的痕迹随时间被洗掉。对数据工作的意义是一句话：**只有（近似的）遍历成立，"研究一条历史序列"才等价于"研究生成机制本身"**——这是所有历史统计和回测的隐含地基，也是它最该被质疑的地方。

### 4.6 遍历定理说什么、不说什么

设 T 保持概率测度 μ，f ∈ L¹(μ)，ℐ 是不变事件构成的 σ-代数。Birkhoff 定理给出

```math
\frac1N\sum_{n=0}^{N-1}f(T^n x)
\longrightarrow\mathbb E_\mu[f\mid\mathcal I](x)
\quad\text{对 }\mu\text{-几乎处处的 }x.
```

若系统遍历，则极限为

```math
\int f\,d\mu.
```

这个定理连接无限时间平均与系综平均，但不自动给出有限时间收敛速度，也不保证一次现实观测已足够长。参见 [Birkhoff 原始论文](https://doi.org/10.1073/pnas.17.2.656)。白话版：遍历成立时，"看得足够久"可以替代"看过所有平行世界"——这正是用历史数据估计概率的合法性来源。但定理的代价是只管无穷远：它不告诉你"够久"是多久，而现实中你永远只有有限历史。**有限历史下时间平均离系综平均还有多远，是定理留下的空白，也是实践中真正的风险所在。**

**一个著名误用需要在此拆掉**：用独立同分布收益做乘法增长时，期望财富按 (1+𝔼[R])ᵀ 增长，典型路径却按 exp(𝔼[log(1+R)]) 增长——由 Jensen 不等式，后者不会大于前者，而且即使收益率过程平稳且遍历，这个差别照样出现。它比较的是**不同的统计对象**，因此不能从这个差距推出“金融整体非遍历”：它警告的是“用错误的统计对象做决策”（拿期望增长代替路径增长去上杠杆），而不是“市场非遍历所以概率论失效”。完整算例（期望增长与路径增长何时给出相反答案、最优杠杆为何是 ℓ* = μ/σ²）见 Peters（2011, *Quantitative Finance*；2019, *Nature Physics*）与《未知世界中的最优动态决策》§13.1。

### 4.7 为什么遍历性不是统计物理的唯一基础

宏观观测量可能在绝大多数微观状态上接近同一值——即使系统并未探索全部相空间，仍可获得稳定预测。而可积系统、玻璃态、亚稳态和近可积系统这些反例则提醒我们：必须明确观测时标、观测量以及适用的系综。

因此，应分别问：测度是否合适？宏观量是否集中？动力学是否到达相关区域？所需时间是否可接受？“遍历”不能一次回答全部问题。

<a id="s5"></a>
## 5. 金融市场的概率：预测改变被预测的对象

**本章检验：第 5 关——跨环境有效；这里是预测与行动互相纠缠的极端环境。**

### 5.1 非平稳不等于没有概率

对于信息集 ℱₜ，仍可建模条件预测分布

```math
P_t(A)=\Pr(Y_{t+1}\in A\mid\mathcal F_t).
```

在标准可测空间等通常条件下，这可以用正则条件分布表达。未来分布可以随时间变化，而完整路径空间上仍存在一个概率法则。

还要避免把“条件分布变化”直接定义为“非平稳”：平稳过程的条件均值和条件方差也可以随已观测状态变化。严格非平稳指联合分布不满足时间平移不变性。

实践难点在识别：手里只有一条历史路径时，如何区分随机波动、隐藏状态变化和生成机制本身改变了？用近期数据估出的分布，未必就是下一阶段的分布。

### 5.2 适应性让机制成为内生变量

可用以下示意模型表达：

```math
x_{t+1}=F(x_t,a_t,\theta_t,\varepsilon_{t+1}),
```

```math
a_t=\pi_t(\mathcal F_t),\qquad
\theta_{t+1}=G(\theta_t,x_t,a_t,\eta_{t+1}).
```

其中 xₜ 为状态，aₜ 为参与者行动，θₜ 表示制度、技术或行为规则。主体会学习、模仿和竞争，行为改变价格及资源约束，改变后的环境又触发新一轮学习。

Arthur 的[复杂性经济学框架](https://sites.santafe.edu/~wbarthur/complexityeconomics.htm)强调行动与预期会响应它们共同生成的环境；这为分析市场适应性提供了一种机制视角，而非宣称所有市场模型都必须永远远离均衡。

最直观的例子：一个套利机会在被广泛知道之前是真实的；写进教材、被大量交易之后，价差被交易行为本身吃掉。"规律"与"规律的利用"在同一口锅里互相消耗——这就是参数 θₜ 被参与者行为内生改变的微观过程。统计物理里没有任何对应物：气体分子不会读你的论文，行星不会学着躲开望远镜。

### 5.3 反身性：预测可能改变预测对象

简化反馈链条是

```math
\text{预测}\longrightarrow\text{行动}\longrightarrow
\text{价格、约束与信息}\longrightarrow\text{新预测}.
```

预期可能自我实现，也可能自我否定；方向取决于机制。例如普遍预期某机会存在，会改变参与规模，从而改变机会本身。

经济学为这个现象准备了两个正式名字。**Lucas 批评（1976）**：用历史数据估出的政策—产出关系（如菲利普斯曲线），一旦政策制定者利用它来制定新政策，行为主体的预期随之改变，估出的关系本身就会失效——宏观计量的“参数”依赖正在被评估的政策体制。**Goodhart 定律**的通俗版本是：**“当一个压力指标变成目标，它就不再是一个好的压力指标”**——银行按某一风险指标被监管，就会重组资产负债表让指标好看，而真实风险换了个地方。Lucas 批评、Goodhart 定律与下文的 performative prediction，是同一件事在宏观经济、金融监管与机器学习中的三个版本：**估计对象与使用方式纠缠时，“历史规律”自带保质期**。

设部署参数 θ 会诱导数据分布 𝒟(θ)，部署后的风险为

```math
R(\theta)=\mathbb E_{Z\sim\mathcal D(\theta)}[\ell(\theta,Z)].
```

它与在固定历史分布 𝒟₀ 上最小化损失不是同一问题。这一形式来自[执行性预测研究](https://arxiv.org/abs/2002.06673)，可作为反身性的一个局部模型，但不穷尽金融反身性的全部社会与制度含义。一种常见的挽救思路是把隐藏状态、制度或时间纳入状态变量，把时变模型改写成形式上的齐次模型；但这并不保证新增状态可观测、可识别、存在平稳分布——“总能写出更大的模型”不等于“已经获得可用于决策的稳定知识”。

### 5.4 应比较适用结构，而不是贴遍历标签

| 比较维度 | 常见平衡统计物理建模 | 适应性金融市场建模 |
|---|---|---|
| 动力学 | 在适用尺度内可采用稳定、受实验支持的基本方程 | 有效行为规则受学习、政策、技术与组织影响 |
| 测度选择 | 守恒量、制备方式、热浴及几何结构提供较强约束 | 条件分布更依赖制度、行为假设和有限历史样本 |
| 主体行为 | 微观对象通常不根据研究者公布的预测修订策略 | 参与者会理解预测、竞争并调整行动 |
| 重复与控制 | 许多实验能控制约束并重复制备 | 历史场景难以完整复制，制度干预常有联动 |
| 宏观简化 | 大自由度和弱相关常支持集中与普适关系 | 同向反应、网络关联和拥挤可能放大共同波动 |
| 时间尺度 | 平衡、弛豫与观测时标需要明确比较 | 估计、学习、制度变化和执行时标共同作用 |
| 遍历性 | 在部分模型中有用，也可能不成立 | 在特定模型中可成立，但不能据此保证现实外推 |

这是一组典型建模差异，而不是将两个领域划分为绝对不相交的类别。非平衡物理也有驱动、反馈和历史依赖；市场也有会计恒等式、结算约束、合约规则和相对稳定的局部机制。

### 5.5 更准确的核心命题

**统计物理与金融的关键区别，在于有效规律、概率结构及其经验支撑的稳定程度，以及预测和行动是否会内生地改变这些结构。遍历性只是给定动力学与测度之后的性质。**

如果连“哪个动力学、哪个测度、哪个观测量、哪个时标”都未明确，直接问“市场是否遍历”常常缺乏确定的数学对象。

## 6. 归纳问题与可迁移结构

**本章定位：第 5 关的认识论根基——任何外推都欠一条持续性假设。**

### 6.1 历史证据不能无条件推出未来

从“过去观察到规律”到“未来仍成立”，必须增加某种持续性假设。用“过去外推曾经成功”来证明今后的外推可靠，又使用了同类归纳推理。

罗素的火鸡把这个困境演到了极致：一只火鸡连续 364 天在上午 9 点获得喂食，"上午 9 点 = 食物"这条归纳规律日益巩固；第 365 天是感恩节前夜。归纳**无法从内部**排除这种剧本——这不是悲观主义，而是给 §6.3 的"持续性假设"标价的理由：任何外推都欠一条假设，写清楚它，才谈得上检验它。

休谟问题并不证明经验研究无用，而是指出其正当性不能简化为无前提的演绎证明。相关哲学背景见[《归纳问题》](https://plato.stanford.edu/archives/spr2021/entries/induction-problem/)。

### 6.2 贝叶斯更新没有消除模型边界

在模型 M 内，

```math
p(\theta\mid D,M)
\propto p(D\mid\theta,M)p(\theta\mid M).
```

这规定怎样使用证据更新已有假设，却不保证 M 包含真实机制。对多个模型进行平均，仍依赖候选集合、先验和似然的适当性。后验集中也可能是在错误模型内部变得越来越自信。

### 6.3 迁移的对象可以比完整分布更小

设环境由 e 标记。边际分布 Pₑ(X,Y) 变化，不排除某个局部关系近似稳定，例如

```math
P_e(Y\mid X_S)\approx P_{e'}(Y\mid X_S).
```

但条件关系稳定不是因果性的充分证明；隐藏混杂、选择偏差和环境变化范围都可能影响判断。

可迁移结构可分成三类：

1. **恒等与约束：** 守恒、会计关系、资源约束、合约定义。其有效性依赖对象定义与适用制度。
2. **机制关系：** 在限定干预与环境范围内成立的因果或动力学关系。
3. **经验规律：** 跨样本或跨环境表现稳定的统计关系，需持续检验失效条件。

约束通常比精确参数更容易迁移，机制可能比边际相关更稳定，但这些都不是无条件的等级定理。

### 6.4 如何检验迁移主张

不能只问“历史上是否拟合良好”，还应问：训练和检验环境究竟哪里不同？稳定关系是否有机制解释？改变行动是否会改变关系？哪些观测会使我们放弃这个解释？

迁移不是把过去整体复制到未来，而是提出范围明确、可以失败的结构假设。

<a id="s7"></a>
## 7. 从概率预测走向反馈决策

**本章定位：概率不够用或不可信时的行动框架。**

### 7.1 决策需要损失与约束

预测相同不代表行动相同：不同损失、资源约束与可逆性，会产生不同最优行动。决策目标也不能由概率分布独自决定。

当单一测度缺乏支持、需要在候选测度集合上做稳健选择时，上下概率与最坏情况准则等工具的完整展开见《不确定性下如何行动》第三节（不精确概率、鲁棒优化等六种不依赖概率的工具），其与反馈控制的衔接见该文第七节。

### 7.2 反馈修正的基本循环

```math
\text{观测}\rightarrow\text{更新状态与模型}\rightarrow
\text{选择受约束行动}\rightarrow\text{观测后果}\rightarrow
\text{检验与修正}.
```

落地时至少应明确：

- **观测：** 哪些变量可实时获得？有何延迟和误差？
- **更新：** 新证据是在改变参数，还是提示模型结构失效？
- **行动：** 成本、资源边界和不可逆后果是什么？
- **评估：** 结果来自外部变化，还是行动改变了环境？
- **修正：** 哪些阈值触发降级、暂停、扩大情景范围或替换模型？

行动还可能帮助识别未知机制，这构成控制与学习的耦合；但为学习而采取的行动也有代价，不能把探索本身视为无风险收益。

### 7.3 反馈有效需要时间与稳定性条件

一种有用但非普遍定理的工作假设是

```math
\tau_{\mathrm{learn}}+\tau_{\mathrm{act}}
\ll\tau_{\mathrm{change}},
```

即学习与行动完成得比关键机制变化更快。若这一关系不成立，快速追逐最新数据也可能只是在追逐噪声。

这个条件的日常版：疫苗研发的周期必须远短于病原变异的周期，"根据最新毒株更新疫苗"才有意义；如果变异更快，你追的是一个不断变形的影子。交易里同构：调仓周期、信号衰减速度、风格轮动周期三者不匹配时，"紧跟最新数据"追到的是噪声——反馈的灵敏度不是越高越好，要和被跟踪对象的时钟匹配。

反馈本身还可能因时滞、噪声、高增益和群体同步而放大不稳定。因此，反馈决策的优势是可以修正，不是保证每次修正都正确。

## 8. 常见误区与结论

### 8.1 三类系统应选择不同目标

| 对象 | 较合理的任务 | 必须检查的边界 |
|---|---|---|
| 三体混沌 | 有限时域轨道区间、给定初值分布下的事件概率 | 初值误差、近碰撞、数值稳定性与测度敏感性 |
| 平衡统计物理 | 宏观量、涨落、响应和适当系综下的统计规律 | 约束、有限尺寸、相关长度及弛豫时间 |
| 适应性市场 | 条件预测、机制情景与受约束反馈决策 | 制度变化、参与者适应、拥挤和行动影响 |

“完整预测不了”不等于“什么也做不了”。合理做法是缩小任务，寻找足够稳定的结构，并把失效条件写入方法。

### 8.2 常见误区对照

| 误区 | 更准确的表达 |
|---|---|
| 所有未知都天然对应唯一概率 | 可赋予测度不等于有充分依据选择唯一测度 |
| 三体混沌没有概率分布 | 给定初值测度即可传播分布，难点是依据与计算 |
| 混沌证明计算不可约 | 二者涉及不同问题，需要各自的条件与证明 |
| 统计物理成立是因为系统都遍历 | 系综、典型性、集中、动力学及观测时标共同重要 |
| 大自由度必然消除波动 | 强相关和临界现象可能使简单平均失效 |
| 非平稳意味着概率论无效 | 时变过程仍可有概率法则，但历史外推需要论证 |
| 条件分布变化必然非平稳 | 平稳过程的条件分布也可以随信息变化 |
| 金融与物理的区别就是非遍历与遍历 | 更深的区别涉及机制稳定性、可识别性与主体反馈 |
| 贝叶斯更新解决了归纳问题 | 更新仍以模型空间、先验及似然的适当性为前提 |
| 反馈可以保证适应成功 | 时滞、噪声和共同反应也可能使反馈失稳 |

本文得到的是一种分层方法论：先明确概率的来源，再区分数学推理、经验识别、计算可行性与跨环境迁移。对稳定机制，尽量建立可解释、可检验的分布模型；对适应性环境，进一步检验行动对分布的影响，并用受约束、可修正的反馈机制管理模型失效。

科学的目标不必是对全部未来逐点预言。它也可以是识别稳定约束、解释有效机制、界定预测期限，并在持续获得证据的过程中改进行动。承认认识论边界，不要求放弃概率；它要求把概率模型的条件、用途和失效方式表达得更清楚。
