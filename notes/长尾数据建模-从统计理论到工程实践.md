## 1. 先建立一张整体地图

### 1.1 “长尾”至少包含四个不同问题

业务中常把“少数很大的值”“右偏”“厚尾”“异常值”统称为长尾，但这些概念对应的处理方法不同。

| 概念 | 主要含义 | 例子 | 首先应问的问题 |
|---|---|---|---|
| 右偏 | 分布不对称，右侧拖得更远 | 正值订单金额 | 正值金额是否来自乘法过程？ |
| 厚尾或重尾 | 尾概率衰减较慢，极端值更常见 | Student-t 收益率、Pareto 金额 | 哪些矩存在？尾部推断是否稳定？ |
| 零值集中 | 零点有较大的概率质量 | 30 天内未购买用户 | 零意味着未发生、未观测，还是缺失？ |
| 污染或异常值 | 观测不属于目标数据机制，或记录错误 | 币种单位错、重复订单 | 是否有证据支持清洗？ |

**右偏不意味着数学意义上的重尾。** Gamma 分布可以很右偏，但尾部按指数速度衰减。Lognormal 的矩母函数在正数处发散，是常见的重尾例子，却具有所有正整数阶矩。Student-t 的尾部是幂律型，其矩是否存在取决于自由度。

对于非负变量，一个常见的重尾定义是：

```math
\mathbb E\!\left[e^{tY}\right]=\infty,
\qquad \text{对所有 }t>0.
```

更强的正则变换尾假设写作：

```math
\Pr(Y>y)=y^{-\alpha}L(y),
\qquad y\to\infty,
```

其中 $`L`$ 是缓变函数，即对任意常数 $`c>0`$，

```math
\frac{L(cy)}{L(y)}\longrightarrow 1.
```

在这种假设下，$`k<\alpha`$ 的正阶矩有限，$`k>\alpha`$ 的正阶矩发散；边界 $`k=\alpha`$ 还取决于缓变部分。对于标准 Pareto 分布，边界矩发散。

这直接影响实践：

- 均值不存在时，“预测长期平均金额”需要重新定义目标。
- 方差不存在时，经典样本均值标准误与普通正态区间不能直接使用。
- 方差存在但很大时，有限样本中的总量和模型排名仍可能非常不稳定。

### 1.2 必须看条件分布，而不只看总体直方图

建模对象通常是：

```math
Y\mid X=x.
```

总体分布很宽，可能只是不同群体的混合。例如新客与企业客户各自金额稳定，但混在一起呈现很长的右尾。加入客户类型后，条件残差可能并不厚尾。

因此，应同时检查：

1. 原始标签的总体分布；
2. 主要业务群体内的分布；
3. 基线模型的条件残差；
4. 经预测尺度标准化后的残差。

### 1.3 将“模型”拆成三个组件

一个回归系统可以拆成：

```math
\underbrace{f_\theta(X)}_{\text{预测器}}
\quad+\quad
\underbrace{\mathcal L}_{\text{训练目标}}
\quad+\quad
\underbrace{\mathcal D}_{\text{决策规则}}.
```

预测器可以是线性模型、树或神经网络；损失决定它主要学习什么；决策规则把预测变成出价、预算、排序或风险限额。更换预测器并不会自动修复目标量选错的问题。

## 2. 先选目标量：mean、median、quantile

### 2.1 统计目标量是什么

设 $`F_x`$ 表示 $`Y\mid X=x`$ 的条件分布。目标量是该分布的某个函数：

```math
T(F_x).
```

例如：

```math
\mu(x)=\mathbb E[Y\mid X=x],
```

```math
q_\tau(x)=\inf\{y:F_x(y)\ge\tau\},
\qquad 0<\tau<1.
```

中位数是 $`\tau=0.5`$ 的分位数。业务目标和评估评分应匹配；这也是点预测评价中的基本原则。[1]

### 2.2 为什么平方损失学习均值

假设条件二阶矩有限。对任意候选值 $`a`$，

```math
\begin{aligned}
\mathbb E[(Y-a)^2\mid X=x]
&=\mathbb E[(Y-\mu+\mu-a)^2\mid X=x]\\
&=\mathrm{Var}(Y\mid X=x)+(\mu-a)^2.
\end{aligned}
```

交叉项为零，因为 $`\mathbb E[Y-\mu\mid X=x]=0`$。因此唯一最优解是：

```math
a^\star=\mu(x).
```

这个结论不要求 $`Y`$ 服从 Gaussian，也不要求方差恒定。Gaussian 是把平方损失解释为特定似然时增加的假设。

**有限样本模型不一定达到这个总体最优解。** 模型容量不足、正则化、优化误差、样本偏差和时间漂移都会使实际预测偏离条件均值。

### 2.3 为什么绝对损失学习中位数

假设 $`\mathbb E[|Y|\mid X=x]<\infty`$。若条件分布在 $`a`$ 附近连续，则：

```math
\frac{\partial}{\partial a}
\mathbb E[|Y-a|\mid X=x]
=2F_x(a)-1.
```

令导数为零，得到 $`F_x(a)=1/2`$。若分布有原子质量或平台，则用次梯度，最优解为中位数集合：

```math
F_x(a^-)\le \frac12\le F_x(a).
```

所以 MAE 不是“对均值更稳健的通用替代品”。它通常改变了估计目标。

### 2.4 一个必须记住的金额例子

假设：

```math
Y=
\begin{cases}
0, & \text{概率 }0.99,\\
1000, & \text{概率 }0.01.
\end{cases}
```

则：

```math
\mathbb E[Y]=10,\qquad q_{0.5}=0,\qquad q_{0.99}=0.
```

这里 $`q_{0.99}=0`$ 使用的是前面的左连续广义逆定义，因为 $`F(0)=0.99`$；例如 $`q_{0.995}=1000`$。

对 10 万个此类用户，期望总金额为 100 万元。逐人中位数相加仍然是零。

这说明：

```math
\mathbb E\!\left[\sum_iY_i\right]=\sum_i\mathbb E[Y_i],
```

但通常：

```math
q_\tau\!\left(\sum_iY_i\right)\ne\sum_iq_\tau(Y_i).
```

前一个等式只要求期望存在，不要求独立；后一个关系说明不能把个人 P90 简单相加，当作群体 P90。

### 2.5 从业务决策反推目标量

| 决策 | 优先目标量 | 典型评价 |
|---|---|---|
| 预算、预期收入、价值出价 | 条件均值 | 均值一致评分、总量校准、决策收益 |
| 描述典型用户 | 条件中位数 | MAE |
| 备货或容量 | 由缺货与积压成本确定的分位数 | Pinball loss、实际成本 |
| 尾部风险阈值 | 损失分位数 | 覆盖率、超越聚集、pinball loss |
| 超越阈值后的损失严重度 | Expected shortfall 等尾部量 | 相应联合评分与尾部回测 |

如果低估每单位损失 $`c_u`$，高估每单位损失 $`c_o`$，且成本是线性的，则最优分位数水平为：

```math
\tau=\frac{c_u}{c_u+c_o}.
```

分位数水平应由问题决定，而不只是因为“P90 看起来比较安全”。

## 3. NLL、最大似然、指数族与 GLM

### 3.1 NLL 与最大似然

给定样本 $`(x_i,y_i)_{i=1}^n`$，模型输出条件密度或概率质量 $`p_\theta(y\mid x)`$。在条件独立假设下：

```math
L(\theta)=\prod_{i=1}^np_\theta(y_i\mid x_i).
```

由于对数单调，最大化似然等价于最小化负对数似然：

```math
\widehat\theta
=\arg\min_\theta
\left\{-\sum_{i=1}^n\log p_\theta(y_i\mid x_i)\right\}.
```

平均 NLL 与总 NLL 的最优解相同，但正则化强度的相对尺度需要统一。

例如二分类模型：

```math
Z\mid X=x\sim\mathrm{Bernoulli}(\pi(x)),
```

对应：

```math
\ell_{\mathrm{BCE}}
=-z\log\pi-(1-z)\log(1-\pi).
```

多分类交叉熵对应 Categorical 模型。

### 3.2 “loss 对应分布”的准确理解

应区分两种解释：

1. **完整概率模型**：假设数据服从某个分布，估计全部必要参数，通过其 NLL 训练。
2. **针对目标量的评分**：某个损失的期望在正确均值或分位数处达到最小，即使完整分布假设不成立，也可能适用于该目标量。

例如，固定方差 Gaussian NLL 等价于 MSE；但 MSE 学均值并不依赖 Gaussian 正确。

如果分布模型设错，最大似然一般收敛到模型族内使期望 NLL 最小的“伪真参数”，而不保证每个业务目标量正确。标准误也可能需要 sandwich 修正。[2]

### 3.3 指数族与指数离散模型

一种常见形式是：

```math
p(y\mid\theta,\phi)
=\exp\left\{
\frac{y\theta-b(\theta)}{a(\phi)}
+c(y,\phi)
\right\}.
```

这里：

- $`\theta`$：自然参数；
- $`b(\theta)`$：累积量函数；
- $`\phi`$：离散或尺度参数；
- $`c(y,\phi)`$：规范化所需的项。

在相应正则条件下：

```math
\mu=b'(\theta),
\qquad
\mathrm{Var}(Y)=a(\phi)b''(\theta).
```

常用简化写法是：

```math
\mathrm{Var}(Y\mid X=x)=\phi V(\mu(x)),
```

其中 $`V`$ 是方差函数。Poisson 通常固定 $`\phi=1`$；样本权重或已知 exposure 还会改变具体表达。

### 3.4 GLM 的三个组成部分

经典 GLM 包括分布、线性预测子和连接函数：[3]

```math
\eta(x)=x^\top\beta,\qquad
g(\mu(x))=\eta(x).
```

例如正金额常用 log link：

```math
\mu(x)=e^{x^\top\beta}.
```

需要区分：

```math
\log\mathbb E[Y\mid X=x]
\quad\text{与}\quad
\mathbb E[\log Y\mid X=x].
```

**Gamma 回归的 log link 并不等于先对标签取对数再做 MSE。** 前者连接条件均值，后者改变了被拟合的随机变量。

树或神经网络可以替代 $`x^\top\beta`$，形成：

```math
g(\mu(x))=f_\theta(x).
```

此时可以保留相同的分布损失，但严格说不再是经典的线性 GLM。

### 3.5 方差—均值关系

| 分布 | 均值 | 方差 | 常用连接函数 |
|---|---|---|---|
| Gaussian | $`\mu`$ | $`\sigma^2`$ | Identity |
| Poisson | $`\mu`$ | $`\mu`$ | Log |
| Gamma | $`\mu`$ | $`\phi\mu^2`$ | Log |
| Tweedie | $`\mu`$ | $`\phi\mu^p`$ | Log |
| Lognormal | $`\mu`$ | $`\mu^2(e^{s^2}-1)`$ | 需明确建模的是原空间还是 log 空间 |
| Student-t | 当 $`\nu>1`$ 时为位置参数 | 当 $`\nu>2`$ 时为 $`s^2\nu/(\nu-2)`$ | 位置可为实数，尺度需为正 |

表中 Lognormal 的变异系数只有在 $`s`$ 固定时才恒定。对给定 $`\nu`$ 的 Student-t，$`s`$ 是尺度参数，并不是标准差。

### 3.6 分布未必完全正确，均值损失仍可能有用

对适当的均值损失，其对候选均值的导数可写成：

```math
\frac{\partial\ell(y,\mu)}{\partial\mu}
=\frac{\mu-y}{V(\mu)}.
```

当 $`V(\mu)>0`$，且交换求导与期望合法时：

```math
\frac{\partial}{\partial\mu}\mathbb E[\ell(Y,\mu)\mid X=x]
=\frac{\mu-\mathbb E[Y\mid X=x]}{V(\mu)}.
```

因此期望损失的导数在真实均值左侧为负、右侧为正。固定规格的 Poisson、Gamma、Tweedie 均值目标都可以从这个角度理解。

这里需要区分两个结论：在相应可积条件下，均值目标可能仍然正确；模型给出的方差、分位数和尾概率却不因此自动正确。将一个准似然均值模型升级为完整概率预测时，必须补上并验证分布与尺度假设。

比较完整 NLL 时还必须使用同一个观测量和基准测度。例如 log 金额空间的 Gaussian NLL 与原金额空间的 Gamma NLL 不可直接比较；前者变回原空间时需要 Jacobian 项。对含零数据，候选模型也必须对零分配合法概率，不能拿只在正值样本上算的 NLL 与全体样本 NLL直接比较。

## 4. 六类分布：假设、损失、梯度与预测

### 4.1 Gaussian：平方损失的概率解释

设：

```math
Y\mid X=x\sim\mathcal N(\mu(x),\sigma^2).
```

完整 NLL 为：

```math
\ell_G
=\frac12\log(2\pi\sigma^2)
+\frac{(y-\mu)^2}{2\sigma^2}.
```

当 $`\sigma`$ 固定时，优化 $`\mu`$ 等价于优化 MSE。对预测均值求导：

```math
\frac{\partial\ell_G}{\partial\mu}
=\frac{\mu-y}{\sigma^2}.
```

对固定预测值，观测 $`y`$ 越极端，梯度绝对值越大。若尾部样本真实且目标是均值，这种敏感性可能反映其经济重要性；若它们是污染，则可能破坏估计。

Gaussian 的支持集是整个实数轴。对严格非负金额，它可以作为均值回归基线，但完整预测分布会给负金额分配概率。

### 4.2 Poisson：计数，不是连续金额

设 $`Y`$ 是非负整数：

```math
p(y\mid\mu)=\frac{e^{-\mu}\mu^y}{y!},
\qquad y=0,1,2,\ldots.
```

完整 NLL：

```math
\ell_P=\mu-y\log\mu+\log\Gamma(y+1).
```

用 $`\eta=\log\mu`$ 参数化：

```math
\ell_P(\eta;y)=e^\eta-y\eta+C(y),
```

```math
\frac{\partial\ell_P}{\partial\eta}=\mu-y,
\qquad
\frac{\partial^2\ell_P}{\partial\eta^2}=\mu.
```

Poisson 同时约束了计数支持集、方差和零概率：

```math
\mathrm{Var}(Y\mid X)=\mu,
\qquad
\Pr(Y=0\mid X)=e^{-\mu}.
```

如果方差明显大于均值，可考虑负二项、随机效应、额外特征或混合机制。如果观测窗口长短不同，可引入已知 exposure：

```math
\log\mu_i=\log e_i+f_\theta(x_i),
```

其中 $`e_i`$ 是观察时长或暴露量，$`\log e_i`$ 是 offset。

Poisson 形式的目标有时也被用作非负目标的准似然；此时不能把连续金额当作真正的 Poisson 随机变量来解释完整预测区间。

### 4.3 Gamma：正值金额和相对波动

使用 shape-rate 参数化：

```math
p(y\mid k,\beta)
=\frac{\beta^k}{\Gamma(k)}
y^{k-1}e^{-\beta y},
\qquad y>0.
```

其均值和方差为：

```math
\mathbb E[Y]=\frac{k}{\beta},
\qquad
\mathrm{Var}(Y)=\frac{k}{\beta^2}.
```

令：

```math
k=\frac1\phi,\qquad
\beta=\frac{k}{\mu},
```

则：

```math
\mathrm{Var}(Y)=\phi\mu^2.
```

完整 NLL：

```math
\ell_\Gamma
=\frac{ky}{\mu}
+k\log\mu-k\log k+\log\Gamma(k)
-(k-1)\log y.
```

只有在 $`k`$ 固定、只优化 $`\mu`$ 时，才可丢掉与 $`\mu`$ 无关的项：

```math
\ell_\Gamma\propto\frac y\mu+\log\mu.
```

采用 log link $`\mu=e^\eta`$：

```math
\ell_\Gamma(\eta;y)\propto ye^{-\eta}+\eta,
```

```math
\frac{\partial\ell_\Gamma}{\partial\eta}
\propto1-\frac y\mu.
```

这个梯度关注实际值与预测值的比值。但在固定 $`\mu`$ 下，$`y\to\infty`$ 时梯度仍然无界。因此 **Gamma 不是有界影响的稳健损失**。

Gamma 的变异系数为：

```math
\mathrm{CV}
=\frac{\sqrt{\mathrm{Var}(Y)}}{\mathbb E[Y]}
=\sqrt\phi.
```

适用信号是：同类样本中，金额越大，标准差大致按同比例增大。Gamma 无法直接赋予 $`Y=0`$ 正概率，不能把含真实零值的标签不加说明地塞进 Gamma NLL。

### 4.4 Tweedie：零点质量与连续正值

Tweedie 指数离散模型具有方差函数：[4]

```math
\mathrm{Var}(Y\mid X=x)=\phi\mu(x)^p.
```

当 $`1<p<2`$ 时，它可表示为复合 Poisson-Gamma：

```math
N\sim\mathrm{Poisson}(\lambda),
\qquad
Y=\sum_{j=1}^N A_j,
```

```math
A_j\sim\mathrm{Gamma}(a,b),
```

其中这一处 Gamma 使用 **shape-scale** 参数化，$`b`$ 是 scale，且各 $`A_j`$ 独立于 $`N`$。参数对应为：

```math
\lambda=\frac{\mu^{2-p}}{\phi(2-p)},
\qquad
a=\frac{2-p}{p-1},
\qquad
b=\phi(p-1)\mu^{p-1}.
```

当 $`N=0`$ 时 $`Y=0`$，所以：

```math
\Pr(Y=0)=e^{-\lambda}.
```

可以自行检查：

```math
\mathbb E[Y]=\lambda ab=\mu,
```

```math
\mathrm{Var}(Y)
=\lambda\mathbb E[A^2]
=\phi\mu^p.
```

固定 $`p,\phi`$ 时，与均值有关的 NLL 部分为：

```math
\ell_{\mathrm{Tw}}(\mu;y)
=\frac1\phi
\left[
\frac{\mu^{2-p}}{2-p}
-\frac{y\mu^{1-p}}{1-p}
\right]+C(y,\phi,p).
```

对 $`\eta=\log\mu`$ 求导：

```math
\frac{\partial\ell_{\mathrm{Tw}}}{\partial\eta}
=\frac1\phi
\left(\mu^{2-p}-y\mu^{1-p}\right).
```

关键是正确理解这个目标：

- 固定 $`p,\phi`$ 时，省略 $`C`$ 不影响均值拟合。
- 若比较不同 $`p`$ 的完整概率模型，$`C`$ 不能随意省略。
- 若训练库只输出 $`\mu`$，不能据此直接生成可靠区间；还需要 $`\phi,p`$ 与完整分布的计算方法。
- 一个 Tweedie 分布将零概率和正值过程联结起来。真实零机制更独立时，Hurdle 可能更灵活。

常用单位 deviance 为：

```math
d_p(y,\mu)=2\left[
\frac{y^{2-p}}{(1-p)(2-p)}
-\frac{y\mu^{1-p}}{1-p}
+\frac{\mu^{2-p}}{2-p}
\right].
```

对于 $`1<p<2`$，取 $`0^{2-p}=0`$，因此可以处理 $`y=0`$。

固定 $`p`$ 下，deviance 可作为均值预测评分。**不同 $`p`$ 下评分的尺度和单位会变，不应只比较各模型自己的最小训练目标。** 选择 $`p`$ 时要用共同的验证标准，或比较完整、可比的预测似然。

### 4.5 Lognormal：乘法噪声与反变换

设：

```math
\log Y\mid X=x\sim\mathcal N(m(x),s^2(x)),
\qquad Y>0.
```

则：

```math
p(y\mid m,s)
=\frac1{ys\sqrt{2\pi}}
\exp\left[-\frac{(\log y-m)^2}{2s^2}\right].
```

完整 NLL：

```math
\ell_{\mathrm{LN}}
=\log y+\log s+\frac12\log(2\pi)
+\frac{(\log y-m)^2}{2s^2}.
```

$`\log y`$ 是变量变换的 Jacobian 项。对固定标签训练 $`m,s`$ 时可以省略它，但在原尺度报告密度或跨分布比较 NLL 时应保留。

三种常见输出分别是：

```math
\mathrm{Median}(Y\mid X=x)=e^{m(x)},
```

```math
\mathbb E[Y\mid X=x]=e^{m(x)+s^2(x)/2},
```

```math
q_\tau(x)=\exp\left[m(x)+s(x)\Phi^{-1}(\tau)\right].
```

方差：

```math
\mathrm{Var}(Y\mid X=x)
=e^{2m(x)+s^2(x)}\left(e^{s^2(x)}-1\right).
```

因此，“预测 log 金额再取指数”通常得到 log 空间均值的反变换；在 Lognormal 假设下它是中位数，不是原尺度均值。

若只假设：

```math
\log Y=m(X)+\varepsilon,
```

则：

```math
\mathbb E[Y\mid X=x]
=e^{m(x)}\mathbb E[e^\varepsilon\mid X=x].
```

Duan 的 smearing 思路用经验残差估计反变换因子。[5] 若残差分布不依赖 $`x`$，可估计一个共同因子；若存在异方差，则应考虑条件或分组因子，并用未参与拟合的残差检查偏差。

另一个容易忽略的陷阱：如果把 log 金额残差直接设为 Student-t，通常 $`\mathbb E[e^\varepsilon]`$ 发散。因此 **log-Student-t 不会自动给出有限的原尺度期望金额**。

### 4.6 Student-t：厚尾位置—尺度模型

使用自由度 $`\nu>0`$、位置 $`m`$、尺度 $`s>0`$：

```math
p(y\mid m,s,\nu)
=\frac{\Gamma((\nu+1)/2)}
{\Gamma(\nu/2)\sqrt{\nu\pi}\,s}
\left[1+\frac{(y-m)^2}{\nu s^2}\right]^{-(\nu+1)/2}.
```

完整 NLL：

```math
\begin{aligned}
\ell_t
={}&\log s+\frac12\log(\nu\pi)
+\log\Gamma\left(\frac\nu2\right)
-\log\Gamma\left(\frac{\nu+1}{2}\right)\\
&+\frac{\nu+1}{2}
\log\left[1+\frac{(y-m)^2}{\nu s^2}\right].
\end{aligned}
```

如果 $`\nu`$ 也要学习，涉及 $`\nu`$ 的规范化项不能丢掉。

记残差 $`r=y-m`$，则：

```math
\frac{\partial\ell_t}{\partial m}
=-\frac{(\nu+1)r}{\nu s^2+r^2}.
```

当 $`|r|`$ 很大时，位置梯度趋近于零。这种“下降到零”的得分称为 redescending。但这只是固定尺度和自由度时的位置方向结论，不能直接推出整个多参数模型具有很高的 breakdown point。

Student-t 的矩：

```math
\mathbb E[Y]=m,\qquad \nu>1,
```

```math
\mathrm{Var}(Y)=s^2\frac{\nu}{\nu-2},
\qquad \nu>2.
```

$`\nu\le1`$ 时通常的均值不存在；$`1<\nu\le2`$ 时均值存在而方差发散。对所有 $`\nu>0`$，对称分布的中位数仍为 $`m`$。

如果模型正确且 $`\nu>1`$，位置等于均值；如果真实条件分布明显不对称，拟合出来的 Student-t 位置一般不能当作真实条件均值。

### 4.7 一张对照表

| 方法 | 支持集 | 主要输出 | 最容易犯的错误 |
|---|---|---|---|
| Gaussian / MSE | 实数 | 均值；完整模型还需尺度 | 以为 MSE 学均值必须依赖正态假设 |
| Poisson | 非负整数 | 计数均值 | 忽略过度离散、exposure 和零率 |
| Gamma | 严格正连续 | 正值均值 | 直接处理真实零值；误称其梯度有界 |
| Tweedie，$`1<p<2`$ | 零与正连续 | 均值；完整分布还需额外参数 | 把均值预测器当完整概率分布 |
| Lognormal | 严格正连续 | log 位置、尺度，再反变换 | 用 $`e^m`$ 代替期望 |
| Student-t | 实数 | 位置、尺度、自由度 | 把 scale 当标准差；忽略矩存在条件 |

## 5. 稳健统计：M-estimation、影响函数与崩溃点

### 5.1 稳健性针对什么

一种常见污染模型是：

```math
F_\varepsilon=(1-\varepsilon)F_0+\varepsilon H.
```

$`F_0`$ 是关心的主体机制，$`H`$ 是污染分布。稳健估计希望少量任意污染不会严重改变结果。

但在 GMV 中，真实高消费用户可能本来就是 $`F_0`$ 的一部分。把他们当作 $`H`$ 并自动降权，可能偏离业务目标。

所以应分别回答：

1. 极端值真实吗？
2. 如果真实，它属于要预测的总体吗？
3. 业务目标是否需要包含它的贡献？

### 5.2 M-estimation

位置或回归 M 估计常写作：

```math
\widehat\beta
=\arg\min_\beta
\sum_{i=1}^n
\rho\left(\frac{y_i-x_i^\top\beta}{s}\right).
```

令：

```math
\psi(u)=\rho'(u).
```

固定 $`s`$ 时，一阶估计方程为：

```math
\sum_{i=1}^n
\psi\left(\frac{y_i-x_i^\top\beta}{s}\right)x_i=0.
```

残差得分 $`\psi`$ 的形状决定大残差如何进入估计方程。Huber 的经典工作为这种折中提供了系统框架。[6]

### 5.3 Huber 的损失和得分

对标准化残差 $`u=r/s`$：

```math
\rho_\delta(u)=
\begin{cases}
\frac12u^2,& |u|\le\delta,\\
\delta|u|-\frac12\delta^2,& |u|>\delta,
\end{cases}
```

```math
\psi_\delta(u)=
\begin{cases}
u,& |u|\le\delta,\\
\delta\,\mathrm{sign}(u),& |u|>\delta.
\end{cases}
```

小残差采用平方惩罚，大残差采用线性惩罚。$`\delta`$ 是相对于标准化残差的阈值；直接拿某个默认常数套在不同量纲的金额上，含义会改变。

如果使用稳健尺度，可从 MAD 出发：

```math
\mathrm{MAD}
=\mathrm{Median}\left(
|Y-\mathrm{Median}(Y)|
\right).
```

正态参考下常使用 $`\mathrm{MAD}/0.67449`$ 作为标准差尺度估计。零膨胀数据的 MAD 可能为零，因此金额数据不能机械套用。

### 5.4 Huber 学的是不是均值

Huber 的总体最优位置满足：

```math
\mathbb E\left[
\psi_\delta\left(\frac{Y-a}{s}\right)
\right]=0.
```

它一般既不等于均值，也不等于中位数。在适当的对称分布下，几种中心可以重合；在右偏分布中则通常不同。

因此，“从 MSE 换成 Huber，只是训练更稳定，预测目标不变”并不成立。若仍要稳健估计均值，需要专门讨论截断偏差、阈值随样本量变化，以及有限矩假设。

### 5.5 Influence function：局部敏感性

对统计泛函 $`T(F)`$，影响函数定义为：[7]

```math
\mathrm{IF}(z;T,F)
=\left.
\frac{\partial}{\partial\varepsilon}
T\big((1-\varepsilon)F+\varepsilon\Delta_z\big)
\right|_{\varepsilon=0}.
```

它衡量在位置 $`z`$ 加入微量污染时估计量如何变化。

均值的影响函数：

```math
\mathrm{IF}(z;\mu,F)=z-\mu.
```

它无界。

若中位数 $`m`$ 处的密度 $`f(m)>0`$ 且满足正则条件，则：

```math
\mathrm{IF}(z;\mathrm{Med},F)
=\frac{\frac12-\mathbf1\{z\le m\}}{f(m)}.
```

它对观测值的幅度有界。但若中心密度很小，界本身可能很大，说明“有界”不等于“估计一定精确”。

对于固定尺度的位置 M 估计，适当正则条件下：

```math
\mathrm{IF}(z;T,F)
=
\frac{s\,\psi((z-T)/s)}
{\mathbb E[\psi'((Y-T)/s)]}.
```

这解释了为什么有界 $`\psi`$ 能控制纯位置问题中的局部影响。

### 5.6 回归中的杠杆点

回归得分含有 $`x_i`$：

```math
\psi(r_i/s)x_i.
```

即使 $`\psi`$ 有界，只要特征向量允许无限大，该乘积仍可能无界。因此 Huber 或 LAD 回归对响应方向的极端残差稳健，并不自动对任意高杠杆特征稳健。

需要同时检查异常特征、杠杆值、设计矩阵和数据机制；必要时采用专门的高 breakdown 回归或杠杆控制方法。

### 5.7 Breakdown point：全局抗污染能力

有限样本替换崩溃点可概念性地写为：

```math
\varepsilon_n^\star(T)
=\min\left\{\frac mn:
\sup_{\widetilde{\mathcal D}_m}
\|T(\widetilde{\mathcal D}_m)-T(\mathcal D)\|
=\infty\right\}.
```

其中 $`\widetilde{\mathcal D}_m`$ 表示最多替换 $`m`$ 个观测得到的数据集。

样本均值只需替换一个观测就能被推到任意远，其 breakdown point 为 $`1/n`$。一维样本中位数的 breakdown point 渐近接近 $`1/2`$。

影响函数研究微量污染的局部作用，breakdown point 研究足够污染下是否完全失控。二者不是同一个概念。

### 5.8 MAE、Huber、Student-t 的稳健性比较

| 方法 | 标准化残差的得分形状 | 目标与代价 |
|---|---|---|
| 平方损失 | 随残差线性增长 | 均值目标；对大残差敏感 |
| 绝对损失 | 符号函数 | 中位数目标；在零点使用次梯度 |
| Huber | 先线性，后截成常数 | 稳健位置；阈值和尺度影响结果 |
| Student-t NLL | 大残差时趋近零 | 厚尾概率模型；可能非凸，依赖尺度和自由度 |

稳健损失也不能代替数据审计。对被错误放大 100 倍的金额，修正单位通常比依赖 loss 自动容忍更可靠。

### 5.9 M 估计的标准误：sandwich 结构

设估计量满足：

```math
\frac1n\sum_{i=1}^n\Psi(W_i,\widehat\theta)=0.
```

在 iid、可识别、局部可微、矩存在等正则条件下：

```math
\sqrt n(\widehat\theta-\theta_0)
\ \xrightarrow{d}\
\mathcal N\left(0,A^{-1}BA^{-\top}\right),
```

其中：

```math
A=\mathbb E\left[
\frac{\partial\Psi(W,\theta_0)}{\partial\theta^\top}
\right],
\qquad
B=\mathbb E\left[\Psi(W,\theta_0)\Psi(W,\theta_0)^\top\right].
```

正确似然模型在相应条件下有信息矩阵等式；误设模型通常不能直接利用该简化。sandwich 形式允许得分的方差与导数矩阵不同，但它仍需要相应矩有限，并不自动解决无限方差问题。

存在用户聚类或时间相关时，$`B`$ 还要替换成适当的聚类或长期协方差估计。MAE、分位数回归等非光滑问题也有对应理论，但不能未经处理直接套用上述光滑求导过程。

## 6. 分位数回归与 pinball loss

### 6.1 定义和直觉

令 $`u=y-q`$：

```math
\rho_\tau(u)
=u\big(\tau-\mathbf1\{u<0\}\big)
=
\begin{cases}
\tau u,&u\ge0,\\
(\tau-1)u,&u<0.
\end{cases}
```

以 $`\tau=0.9`$ 为例，真实值为 100：

- 预测 80：损失为 $`0.9\times20=18`$；
- 预测 120：损失为 $`0.1\times20=2`$。

同样大小的低估受到更重惩罚，因此模型会学习较高的条件分位数，而不是在训练后人为给预测加一个常数。[8]

### 6.2 为什么最优值是分位数

对连续分布并满足相应可积条件时：

```math
\begin{aligned}
\frac{\partial}{\partial q}
\mathbb E[\rho_\tau(Y-q)\mid X=x]
&=-\tau\Pr(Y\gt q\mid x)\\
&\quad +(1-\tau)\Pr(Y\lt q\mid x)\\
&=F_x(q)-\tau.
\end{aligned}
```

令其为零得 $`F_x(q)=\tau`$。

当有原子质量时，次梯度条件为：

```math
F_x(q^-)\le\tau\le F_x(q).
```

例如大量零值会使多个分位数同时为零，这是分布本身的性质，不一定是模型失效。

### 6.3 与非对称 Laplace 的关系

可构造密度：

```math
p(y\mid q,b,\tau)
=\frac{\tau(1-\tau)}b
\exp\left[
-\rho_\tau\left(\frac{y-q}{b}\right)
\right],
\qquad b>0.
```

固定 $`b,\tau`$ 时，NLL 与 pinball loss 等价。

但分位数回归的合理性不要求数据真的服从这个分布。把非对称 Laplace 当工作似然与把它当真实生成分布，是两个不同主张；后者还需要额外检验。

### 6.4 多分位数与交叉

独立训练 P10、P50、P90，可能出现 P90 小于 P50。常见处理包括：

1. 共享模型并使用单调增量参数化；
2. 在验证集上评估后做排序或等距回归后处理；
3. 在目标中增加交叉约束或惩罚。

一种参数化例子是：

```math
q_{0.1}=a,\qquad
q_{0.5}=a+\mathrm{softplus}(b),\qquad
q_{0.9}=q_{0.5}+\mathrm{softplus}(c).
```

它保证不交叉，但额外约束也可能影响拟合能力。

### 6.5 分位数与均值的关系

对可积随机变量：

```math
\mathbb E[Y\mid X=x]=\int_0^1q_\tau(x)\,\mathrm d\tau.
```

因此理论上可以由整个分位数函数恢复均值。但仅有 P50、P90、P99 通常不足以准确恢复极右偏分布的均值，尤其是最后 1% 的尾部可能贡献大量金额。

## 7. 异方差与 distributional regression

### 7.1 异方差不只是“金额越大误差越大”

异方差是：

```math
\mathrm{Var}(Y\mid X=x)
```

随 $`x`$ 改变。变化可能由均值、用户类型、促销状态、波动环境或其他因素驱动，未必能完全由一个固定的 variance-mean 关系描述。

### 7.2 异方差 Gaussian NLL

同时输出位置和尺度：

```math
\mu(x)=f_\theta(x),
\qquad
\sigma(x)=\mathrm{softplus}(g_\theta(x))+\epsilon.
```

NLL：

```math
\ell(y,x)
=\frac{(y-\mu(x))^2}{2\sigma^2(x)}
+\log\sigma(x)+\frac12\log(2\pi).
```

第一项允许高噪声区域有更大残差；第二项惩罚无意义地放大尺度。如果只写残差除以方差，却省略 $`\log\sigma`$，模型可能靠放大尺度逃避损失。

令 $`v=\log\sigma^2`$，则：

```math
\ell=\frac12\left[(y-\mu)^2e^{-v}+v\right]+C.
```

这种参数化常用于数值实现，但仍需防止极端的 $`v`$。

### 7.3 从均值回归到分布回归

分布回归预测多个分布参数：

```math
\theta_1(x),\theta_2(x),\ldots,\theta_K(x).
```

例如：

- Gamma：$`\mu(x)`$ 与 $`\phi(x)`$；
- Lognormal：$`m(x)`$ 与 $`s(x)`$；
- Student-t：$`m(x)`$、$`s(x)`$，必要时再加入 $`\nu(x)`$；
- Hurdle：$`\pi(x)`$ 与正值分布参数。

位置、尺度和形状分别建模的系统思想可参见 GAMLSS。[9] 神经网络可以共享底层特征，再接多个参数输出头，但参数多并不代表结果一定更可靠。

### 7.4 必须防止的退化

当模型足够灵活，可以在训练样本上令残差近零，同时把尺度压到接近零，NLL 可能出现退化。实践中应：

1. 设置与数据量纲匹配的尺度下界；
2. 使用验证集早停与适当正则化；
3. 先使用全局或分组形状参数，再考虑逐样本形状；
4. 监控尺度分布、极端 NLL 与覆盖率；
5. 不把训练集上的窄区间当作泛化能力。

### 7.5 如何检查完整分布

连续条件分布正确时，概率积分变换：

```math
U_i=F_{\widehat\theta(x_i)}(y_i)
```

在理想条件下近似均匀。可以检查 PIT 直方图及其分组表现。

对零点有原子质量的分布，普通 PIT 不是均匀的；可使用随机化 PIT：

```math
U_i=F(y_i^-)+V_i\big(F(y_i)-F(y_i^-)\big),
\qquad V_i\sim\mathrm{Uniform}(0,1).
```

总体 PIT 合理仍可能掩盖某些用户群体或时间段失准，因此还要分层诊断。

## 8. 数据审计与长尾诊断

### 8.1 第一步：定义标签口径

对金额模型，至少要写清：

- 预测单位是用户、订单、商品、账户还是门店；
- 预测窗口是未来 7 天、30 天，还是终身；
- 标签是支付金额、净收入、毛利还是折现贡献；
- 退款、撤销、税费、运费和汇率如何处理；
- 所有样本是否已完成观察窗口；
- 特征在实际预测时是否可用。

如果标签是净额且允许负值，则“非负金额”的模型假设不再自动成立。可以考虑分别预测正向销售与退款，再计算净额；两部分的相关性还会影响净额区间。

### 8.2 支持集与零值

先统计负值比例、零比例、非整数比例、缺失比例及取值范围。

**零值多不等于零膨胀。** 零膨胀通常指：相对于某个基准分布所预期的零概率，实际零值更多。没有基准模型时，更准确的描述是“零值集中”。

零值至少可能表示：

1. 观察期内确实没有事件；
2. 事件发生了但金额为零；
3. 数据还没回流或标签未成熟；
4. 缺失值被错误填成零；
5. 业务资格不允许事件发生。

第 1 类可以建模；第 3、4 类首先是标签与观测问题。

### 8.3 用分位数和集中度描述尾部

常用统计量：

```math
Q_{0.5},\ Q_{0.9},\ Q_{0.99},\ Q_{0.999},
\quad
\frac{Q_{0.99}}{Q_{0.5}},
\quad
\frac{Q_{0.999}}{Q_{0.99}}.
```

若中位数为零，第一种比值无意义，应改看正值子样本。

设 $`S_k`$ 为真实标签最大的前 $`k`$ 比例样本，金额集中度：

```math
C_k=\frac{\sum_{i\in S_k}y_i}{\sum_{i=1}^ny_i}.
```

它描述真实数据有多集中，与按模型预测排序的 Top-K capture 不同。

对非负金额，可画经验生存函数：

```math
\widehat{\overline F}(y)
=\frac1n\sum_{i=1}^n\mathbf1\{Y_i>y\}.
```

在双对数坐标下，Pareto 型尾部可能近似线性；但“看起来像直线”不是充分证据。阈值选择、混合分布和有限样本都能造成类似形状。

### 8.4 不要过度依赖样本偏度和峰度

偏度和峰度依赖高阶矩。当尾部很厚时，这些矩可能不存在；即使存在，估计也可能被少数观测主导。

因此应同时报告：

- 稳定的中部统计量；
- 分位数和尾部样本数量；
- 最大若干样本的来源审计；
- 按时间、渠道、群体划分的分布；
- 指标对移除或保留顶部样本的敏感性。

### 8.5 variance-mean 诊断为什么要条件化

可以先用不含未来信息的基线模型生成样本外均值预测，再按预测值分箱。在每个箱内计算样本均值、方差和样本量。

但分箱方差并不等于真正的条件方差。由全方差公式：

```math
\mathrm{Var}(Y\mid B)
=\mathbb E[\mathrm{Var}(Y\mid X)\mid B]
+\mathrm{Var}(\mathbb E[Y\mid X]\mid B).
```

箱内群体不均匀时，第二项会抬高观测方差。不同尺度参数、离群值和小样本同样会影响估计。

因此对：

```math
\log v_b\approx a+p\log\mu_b
```

的拟合只能提供候选线索。不能仅凭斜率约为 1.5，就断言数据服从 Tweedie。

### 8.6 Hill 估计可以做什么

若有正则变换尾假设，设降序统计量为 $`Y_{(1)}\ge\cdots\ge Y_{(n)}`$，可估计尾指数倒数：

```math
\widehat\xi_k
=\frac1k\sum_{j=1}^k
\log\frac{Y_{(j)}}{Y_{(k+1)}},
\qquad
\widehat\alpha_k=\frac1{\widehat\xi_k}.
```

较小的 $`k`$ 方差大，较大的 $`k`$ 可能把非尾部区域混入而引入偏差。应画不同 $`k`$ 的稳定性图，并结合生成机制。它不适用于所有右偏数据，也不能以一次尾指数估计“证明”均值或方差存在。

### 8.7 审计结果应形成可执行结论

| 审计发现 | 建模含义 | 后续动作 |
|---|---|---|
| 零多、正值连续 | 需要显式支持零 | Tweedie 或 Hurdle |
| 正值 CV 近稳定 | 相对波动可能近固定 | 比较 Gamma 与固定 log 尺度 Lognormal |
| log 残差尺度随群体变化 | 固定 smearing 可能失效 | 异方差 Lognormal 或条件 smearing |
| 波动聚集 | iid 假设不合理 | 时间序列验证、动态尺度、块重采样 |
| 极端值来自单位或重复错误 | 标签污染 | 修正源数据与口径 |
| 极端值真实且贡献大 | 尾部是业务组成 | 保留并检查总量、排序、区间 |

## 9. 数据处理与模型选择流程

### 9.1 log、log1p 与反变换

对 $`Y>0`$，log 变换天然适合乘法结构。对 $`Y\ge0`$，log1p 方便包含零，但学习的是：

```math
\mathbb E[\log(1+Y)\mid X=x].
```

简单执行：

```math
\exp\left(\mathbb E[\log(1+Y)\mid X=x]\right)-1
```

一般不等于原尺度均值。

如果将 $`\log(1+Y)`$ 近似为 Gaussian，并套用 lognormal 反变换，还需意识到：普通 Gaussian 对负的变换值也分配概率，反变换后会产生 $`-1<Y<0`$。因此这通常是近似预测工具，不是严格支持非负金额的完整分布模型。

### 9.2 clip 与 winsorize 改变了什么

令：

```math
Y^{(c)}=\min(Y,c).
```

若对裁剪标签使用均值一致损失，目标成为：

```math
\mathbb E[Y^{(c)}\mid X].
```

真实均值与它的差为：

```math
\mathbb E[Y\mid X]
-\mathbb E[Y^{(c)}\mid X]
=\mathbb E[(Y-c)_+\mid X].
```

右侧就是被删除的尾部贡献。若业务需要原始总金额，裁剪之后必须另行估计这部分，或明确改变了预测目标。

目标截断、预测截断、梯度裁剪也不同：

- 目标截断直接改变标签及 estimand；
- 预测截断约束输出范围，可能引入偏差；
- 梯度裁剪限制优化更新的幅度，不等价于同一个显式标签模型，但也可能影响实际优化结果。

### 9.3 加权训练不只是“让大客户更重要”

对非负权重 $`w(X,Y)`$，加权平方损失的条件最优解为：

```math
a^\star(x)
=\frac{\mathbb E[w(X,Y)Y\mid X=x]}
{\mathbb E[w(X,Y)\mid X=x]}.
```

如果权重只依赖 $`X`$，在无限制条件函数空间中不改变该点的均值目标；但有限容量模型中会改变不同区域之间的拟合取舍。

如果权重依赖 $`Y`$，例如 $`w=Y`$，目标一般变成：

```math
\frac{\mathbb E[Y^2\mid X=x]}
{\mathbb E[Y\mid X=x]},
```

而不再是原始条件均值。对重尾数据，这还会引入更高阶矩要求。

对负样本下采样、转化样本过采样，应处理抽样概率或概率校正；否则分类头的输出往往不再是原总体的转化概率。

### 9.4 选择模型与 loss 的实际顺序

```text
确定业务决策与目标量
│
├─ 需要中位数或固定风险分位数
│  └─ MAE / pinball；检查覆盖率、交叉和时间稳定性
│
└─ 需要均值或完整预测分布
   │
   ├─ 非负整数计数
   │  └─ Poisson；过度离散时比较负二项等扩展
   │
   ├─ 严格正连续
   │  ├─ 相对波动较稳定：Gamma 候选
   │  └─ log 空间近对称：Lognormal 候选
   │
   ├─ 零 + 正连续
   │  ├─ 复合过程约束合理：Tweedie
   │  └─ 零/正值过程需分别建模：Hurdle
   │
   └─ 可正可负
      ├─ 残差近对称轻尾：Gaussian 或异方差 Gaussian
      └─ 残差厚尾：Student-t；偏态明显时考虑更灵活分布

所有路径都需要：数据审计 → 样本外校准 → 时间外验证 → 决策评价
```

这棵树用于缩小候选范围。它不能代替真实验证，也不意味着每个问题只能用一个模型。

## 10. GMV 与 LTV：Tweedie、Hurdle 与两阶段模型

### 10.1 明确预测对象

以用户未来 30 天 GMV 为例：

```math
Y_{i,t}
=\sum_{\text{订单发生在 }(t,t+30]}
\text{该订单计入口径的金额}.
```

用户特征只能使用 $`t`$ 时刻以前已经可见的信息。若退款要到后续才能确认，标签成熟时间必须包含这段延迟。

“终身 LTV”比固定 30 天金额更复杂，常包含：

```math
\mathrm{LTV}(x)
=\mathbb E\left[
\sum_{h=1}^{\infty}
\frac{M_h}{(1+d)^h}
\ \middle|\ X=x
\right],
```

其中 $`M_h`$ 可表示未来贡献利润，$`d`$ 是折现率。仅凭短期未成熟标签，不能直接识别无限期价值；需明确预测期限、留存机制、删失和外推假设。

### 10.2 Hurdle 的概率模型

设：

```math
Z=\mathbf1\{Y>0\},
\qquad
\pi(x)=\Pr(Y>0\mid X=x).
```

用正值密度 $`f_+(y\mid x)`$ 建模 $`Y\mid Y>0,X=x`$：

```math
p(y\mid x)=
\begin{cases}
1-\pi(x),&y=0,\\
\pi(x)f_+(y\mid x),&y>0.
\end{cases}
```

这里密度相对于“零点质量加正半轴 Lebesgue 测度”的混合基准定义。它合法地同时包含离散零与连续正值。

单样本 NLL：

```math
\ell_{\mathrm{H}}
=-(1-z)\log(1-\pi)
-z\log\pi
-z\log f_+(y\mid x).
```

也就是 BCE 加正值样本上的金额 NLL。

如果两个模型参数完全独立，分别最小化各自样本平均损失不会改变各自最优解。若共享神经网络底层，则正值损失除以正样本数还是全样本数，会改变相对权重；随意乘一个系数也就不再是原样本联合 NLL 的同一优化目标。

### 10.3 Hurdle 与 zero-inflated 的区别

Hurdle 模型中，正值部分不产生零；全部零由门控部分生成。

Zero-inflated 模型则把额外零机制与一个本身也可能产生零的基准分布混合。例如 zero-inflated Poisson 的零既可能来自“结构性零”，也可能来自 Poisson 过程。

对 Bernoulli + Gamma 或 Bernoulli + Lognormal，由于正值分布本身没有零质量，称作 Hurdle 或两部分模型更直接。

### 10.4 均值、方差和分位数如何推断

设正值部分均值和方差为 $`\mu_+(x),v_+(x)`$。则：

```math
\mathbb E[Y\mid x]=\pi(x)\mu_+(x),
```

```math
\mathrm{Var}(Y\mid x)
=\pi(x)v_+(x)
+\pi(x)(1-\pi(x))\mu_+^2(x).
```

第一项来自正值金额波动，第二项来自是否发生事件的不确定性。

若正值分布连续且支持严格正值，则：

```math
q_\tau(x)=
\begin{cases}
0,&\tau\le1-\pi(x),\\
F_+^{-1}\!\left(
\dfrac{\tau-1+\pi(x)}{\pi(x)}
\right),&\tau>1-\pi(x).
\end{cases}
```

所以总体 P90 并不等于“转化概率乘正值 P90”。分位数不能像期望一样做这种乘法。

### 10.5 BCE + Gamma

分类头输出 $`\pi(x)`$；正值金额头输出 Gamma 条件均值 $`\mu_+(x)`$。原尺度期望直接为：

```math
\widehat\mu(x)=\widehat\pi(x)\widehat\mu_+(x).
```

如果还估计 $`\phi_+(x)`$，可得到完整正值 Gamma 分布，并组合出混合分布的区间。

需要注意：分类头概率失准或正值均值失准，都可能使乘积失准。仅仅分别看 AUC 和正值 MAE 不能保证总 GMV 正确。

### 10.6 BCE + Lognormal

正值部分模型：

```math
\log Y\mid(Y>0,X=x)
\sim\mathcal N(m_+(x),s_+^2(x)).
```

因此：

```math
\widehat\mu(x)
=\widehat\pi(x)
\exp\left[
\widehat m_+(x)+\frac12\widehat s_+^2(x)
\right].
```

这是“概率 × 条件原尺度均值”。如果把第二项写成 $`e^{\widehat m_+}`$，会漏掉尾部对均值的贡献。

### 10.7 一个可手算的完整例子

假设某用户群：

```math
\pi=0.1,\qquad
\log Y\mid Y>0\sim\mathcal N(\log100,1).
```

则正值金额的：

```math
\mathrm{Median}(Y\mid Y>0)=100,
```

```math
\mu_+=100e^{1/2}\approx164.8721.
```

全体用户均值：

```math
\mu=0.1\times164.8721\approx16.4872.
```

整体 P50 和 P90 均为 0；P95 对应正值部分的 P50：

```math
q_{0.95}=100.
```

整体 P99 对应正值部分的 P90：

```math
q_{0.99}
=100\exp(\Phi^{-1}(0.9))
\approx360.2224.
```

若有 10 万个该群体用户，期望总金额约 164.87 万元。错误地使用 $`0.1\times100=10`$ 作为均值，会只预测 100 万元。

这个计算是分布假设下的解析例子，不是实测模型效果。群体总额的预测区间还需要用户之间的依赖结构。

### 10.8 Tweedie 与 Hurdle 如何比较

| 方面 | Tweedie | Hurdle |
|---|---|---|
| 均值预测 | 单模型直接输出 | 两阶段输出相乘 |
| 零概率 | 与均值、离散度、幂参数联结 | 可由分类头单独建模 |
| 维护成本 | 通常较低 | 需管理两阶段与联合校准 |
| 完整分布 | 计算可能较复杂 | 取决于正值分布，通常容易组合 |
| 失准定位 | 较难拆成转化与客单价问题 | 可分别定位概率与正值金额 |

如果广告价值目标已经定义为“每次曝光的无条件期望价值”，就不应再次乘一个已经包含在其中的转化概率。应明确每个预测头的条件事件和观察单位，避免重复计算概率。

## 11. 金融收益率：波动、Student-t 与 quantile risk

### 11.1 首先区分收益率定义

简单收益率：

```math
R_t=\frac{P_t}{P_{t-1}}-1.
```

对于正价格资产，它的理论下界为 $`-1`$。对数收益率：

```math
r_t=\log P_t-\log P_{t-1}
```

可取任意实数。使用无界 Student-t 拟合简单收益率时，属于近似支持集；使用 log return 时支持集匹配更直接。

### 11.2 分开建模均值与波动

收益率常写成：

```math
r_t=m_t+s_t\varepsilon_t,
```

其中 $`m_t,s_t`$ 都只能依赖 $`\mathcal F_{t-1}`$ 中的信息。均值可预测性弱并不意味着风险不可预测；动态波动模型应与简单基线比较。

例如 GARCH(1,1) 的条件方差结构为：[10]

```math
h_t=\omega+\alpha(r_{t-1}-m_{t-1})^2+\beta h_{t-1}.
```

若创新被标准化为方差 1，则 $`h_t`$ 是条件方差。对普通尺度参数为 $`s_t`$ 的 Student-t，方差为 $`s_t^2\nu/(\nu-2)`$；必须统一参数化，避免风险被错误缩放。

### 11.3 Student-t NLL 的实践选择

可令：

```math
m_t=f_\theta(X_{t-1}),
\qquad
s_t=\mathrm{softplus}(g_\theta(X_{t-1}))+\epsilon.
```

先用全局固定或可学习 $`\nu`$，再考虑更复杂的形状参数。若要求方差存在，可参数化：

```math
\nu=2+\mathrm{softplus}(a).
```

此约束保证的是模型方差存在，不是证明真实收益率一定具有有限方差。

还应检查标准化残差：

```math
u_t=\frac{r_t-\widehat m_t}{\widehat s_t}.
```

如果它们仍有波动聚集、偏态或尾部时变，单一对称 Student-t 可能仍然不足。

### 11.4 统一风险符号

令损失：

```math
L_t=-r_t.
```

则高置信水平的 VaR 定义为：

```math
\mathrm{VaR}_\tau(L_t\mid\mathcal F_{t-1})
=q_\tau(L_t\mid\mathcal F_{t-1}).
```

如果收益率分布连续，有：

```math
\mathrm{VaR}_\tau(L_t)
=-q_{1-\tau}(r_t).
```

保持“损失上尾”或“收益率下尾”的一种约定，可以减少 P1、P99 和符号混乱。

### 11.5 VaR 与 expected shortfall

对可积损失变量，一般定义：

```math
\mathrm{ES}_\tau(L)
=\frac1{1-\tau}
\int_\tau^1q_u(L)\,\mathrm du.
```

当分布连续且没有边界原子质量时，可写成相应的超阈值条件期望。VaR 描述阈值，ES 描述上尾平均严重度。

ES 通常不能用单一普通 pinball loss 单独学习；VaR 与 ES 在适当条件下可以通过联合一致评分共同评价和估计。[11]

对于 Student-t 风险模型，ES 的有限性还要求一阶矩存在。

### 11.6 风险回测

定义超越指标：

```math
I_t=\mathbf1\{L_t>\widehat q_{\tau,t}\}.
```

若条件分位数连续且正确，则超越率目标约为 $`1-\tau`$。但整体超越率达标还不够：超越可能集中在连续高波动日。

需要至少检查：

- 超越频率与样本数量；
- 超越是否聚集；
- 按波动状态和时间段分层的覆盖；
- pinball loss 和不同模型的配对损失差；
- 极端事件窗口与数据回流、复权、停牌等口径。

例如 1000 个观测下评估 P99，理论上只期待约 10 次超越。一次或两次事件就可能明显改变结果，不能过度解读微小差异。

## 12. 训练、评估、校准与时间外验证

### 12.1 训练损失与最终验收指标

训练时的目标函数应与 estimand 匹配；验收还要覆盖业务约束、分组稳定性和时间漂移。

| 任务 | 主要指标 | 辅助指标 | 不能据此单独下结论 |
|---|---|---|---|
| 原尺度期望金额 | MSE、固定规格的 deviance、总量偏差 | MAE、分组误差 | 只有 log-RMSE 很低 |
| 金额排名 | Top-K capture、预算下价值 | 分组校准 | 只有总量准确 |
| 转化概率 | Logloss、Brier、概率校准 | AUC、PR-AUC | 只有 AUC 很高 |
| 分位数 | Pinball loss、覆盖率 | 区间宽度、分组覆盖 | 只有区间很窄 |
| 完整分布 | 完整 NLL、适当的分布评分 | PIT、尾部诊断 | 只有均值准确 |

MAE 可以作为均值预测器的描述性误差，但如果只按 MAE 挑选模型，会偏好中位数方向，未必与均值目标一致。

### 12.2 为什么不推荐零值金额直接用 MAPE

MAPE 含有：

```math
\frac{|y-\widehat y|}{|y|}.
```

当 $`y=0`$ 时没有定义；当 $`y`$ 很小时权重极大。简单加一个很小的常数，会引入任意的量纲和权重选择。

非负金额有时使用：

```math
\mathrm{WAPE}
=\frac{\sum_i|y_i-\widehat y_i|}{\sum_i y_i}.
```

它适合描述总体相对误差，但分母为零时仍无定义，而且分子仍是绝对误差，不能当作条件均值的一致训练目标。

### 12.3 Aggregate calibration

对群体 $`G`$，定义：

```math
\mathrm{AC}(G)
=\frac{\sum_{i\in G}\widehat\mu_i}
{\sum_{i\in G}y_i}.
```

若 $`\mathrm{AC}=0.8`$，表示预测总量相对于实际总量低 20%。有限样本中即使正确模型也不会精确等于 1，所以应结合样本量、置信区间和多个时间窗判断。

应按渠道、品类、新老客、国家或地区、时间以及**预测值分箱**检查。分箱应避免利用测试期未来标签定义线上无法获得的人群。

总体校准可能掩盖 A 群体高估与 B 群体低估相互抵消。另一方面，所有用户预测同一个恰当常数，也可能具有不错的总量校准，却没有排序价值。

### 12.4 后校准

最简单的乘法校准：

```math
c=\frac{\sum_{i\in C}y_i}
{\sum_{i\in C}\widehat\mu_i},
\qquad
\widehat\mu_i^{\,\mathrm{cal}}=c\widehat\mu_i,
```

其中 $`C`$ 是独立校准集。

它改善的是校准窗口中的总量，不保证下一个时期有效。样本少的分组校准需要收缩或合并分组，避免把尾部噪声放大。不能用最终测试集估计 $`c`$ 再报告其“测试集校准改善”。

### 12.5 Top-K capture

按预测值降序选择前 $`k`$ 比例样本，记集合为 $`\widehat S_k`$：

```math
\mathrm{Capture}(k)
=\frac{\sum_{i\in\widehat S_k}y_i}
{\sum_i y_i}.
```

可同时报告多个预算比例下的曲线，例如 1%、5%、10%、20%。若随机抽取固定比例且选择独立于金额，在给定非零总金额的总体上，其 capture 的期望约为该比例。

需要固定并披露：

- $`k`$ 是人数比例、人数个数还是成本预算；
- 并列预测如何处理；
- 每个用户的触达成本是否相同；
- 同一测试集上是否反复调参。

Capture 依赖已经观察到的结果，不等于干预的因果增量收益。若投放会改变用户行为，还需要实验或恰当的因果评价。

### 12.6 时间外验证与标签窗口

建议把用途分开：

```text
训练区间 → 验证区间 → 校准区间 → 最终测试区间
   拟合       选模型       校准参数       一次性验收
```

每一折都要根据“当时实际可获得的信息”构造训练集。例如在日期 $`T`$ 上线预测 30 天标签，能用来训练的观察起点需足够早，使其 30 天标签和退款延迟在 $`T`$ 前完成。

这不只是按特征日期排序。还应检查：

- 标签结束时间是否穿过验证边界；
- 同一用户的重复快照是否造成强依赖；
- 编码、标准化和缺失填补是否只用训练数据拟合；
- 促销、市场状态或策略变化是否落在不同窗口。

需要 embargo 或 purge 的长度由标签窗口与可用时点决定，不应机械规定每种任务都间隔相同天数。

### 12.7 训练稳定性的实务顺序

先检查标签错误、支持集和尺度，再调整学习率、叶节点大小、正则化、批量大小和早停。对金额按固定货币单位缩放有助于数值稳定，但应记录反变换。

若 $`Y'=Y/c`$，Gamma 的无量纲离散度保持不变，而 Tweedie 的离散度变为：

```math
\phi'=\phi c^{p-2}.
```

尺度参数、金额阈值和区间也必须一起转换。

## 13. Inference、bootstrap 与不确定性

### 13.1 先区分两种 inference

机器学习部署中的 inference 通常指“给新输入产生预测”；统计 inference 指“对参数、目标量或假设进行推断”。

还应区分：

| 不确定性对象 | 例子 | 典型方法 |
|---|---|---|
| 未来结果随机性 | 一个用户未来花多少钱 | 条件分布或预测分位数 |
| 参数估计不确定性 | 模型均值估计有多不稳定 | 重训 bootstrap、渐近方差、贝叶斯方法 |
| 群体总量波动 | 全渠道下月 GMV | 联合预测分布、时间或群体场景模拟 |
| 数据与机制变化 | 大促策略或市场结构改变 | 漂移分析、压力情景、滚动验证 |

一个模型集成的分歧并不自动涵盖以上全部来源。

### 13.2 经典均值 CLT 的条件

在 iid、有限方差条件下：

```math
\sqrt n(\overline Y-\mu)
\ \xrightarrow{d}\
\mathcal N(0,\sigma^2).
```

于是常用标准误为 $`s/\sqrt n`$。

若尾指数处于 $`1<\alpha<2`$ 且满足稳定极限定理所需条件，均值存在但方差不存在。此时中心化总和一般需要与 $`\alpha`$ 和缓变因子有关的缩放，极限通常不是 Gaussian。

因此增加样本量并不意味着可以无条件套用同一套正态区间。

### 13.3 普通 bootstrap 何时会出问题

普通非参数 bootstrap 从经验分布中有放回抽取与原样本同样大小的数据，再重复计算统计量。

对于经典无限方差均值问题，普通 $`n`$-out-of-$`n`$ bootstrap 可能不一致；这有明确的理论反例。[12] 即使方差有限，极端尾部样本稀少也会导致有限样本覆盖差。

应避免三种误解：

1. “不假设分布”不等于“不需要正则条件”。
2. 重采样不能凭空创造原样本从未覆盖的极端尾部机制。
3. 10000 次重采样只降低 bootstrap Monte Carlo 误差，不等于增加原始信息量。

### 13.4 极厚尾下的替代方案

可以研究 subsampling、$`m`$-out-of-$`n`$ bootstrap、尾部模型或适合有限矩条件的稳健均值估计，但必须明确统计量、归一化方式和适用条件。

常见的 $`m`$-out-of-$`n`$ 思路要求：

```math
m\to\infty,\qquad \frac mn\to0.
```

它不是“随便把 bootstrap 样本量减小”就自动正确；选择 $`m`$ 与把小样本分布转换回目标样本尺度都需要理论依据与敏感性分析。

### 13.5 分位数可能比均值更容易推断，但也有条件

对 iid 连续分布，如果 $`q_\tau`$ 附近密度正且连续，则：

```math
\sqrt n(\widehat q_\tau-q_\tau)
\ \xrightarrow{d}\
\mathcal N\left(
0,\frac{\tau(1-\tau)}{f(q_\tau)^2}
\right).
```

这一结论不要求总体方差有限。但极端分位数处的密度往往很小，方差仍可能很大；当 $`\tau`$ 随样本量接近 1 时，还需极端分位数理论。

零膨胀分布在原子点不满足上述连续正密度条件，不能直接套用这个方差公式。

### 13.6 用户聚类与时间块

同一个用户的多条交易记录相关时，应以用户作为重采样单位，并完整保留其记录。若所有用户同时受到促销或宏观冲击，只有用户聚类可能仍不足。

时间序列可考虑 moving block、circular block 或 stationary bootstrap。块长需要同时覆盖主要依赖尺度并保留足够有效块数；存在明显非平稳漂移时，仅使用块抽样也不能修复所有问题。

模型比较应使用同一重采样单位对两个模型的损失差进行配对重采样，而不是把两个模型当作独立实验。

### 13.7 固定模型 bootstrap 与重训 bootstrap

对固定预测值重采样测试集，可估计“这批评估样本对指标的抽样不确定性”。它没有覆盖重新采集训练数据后模型发生变化的部分。

重训 bootstrap 则对训练样本按适当单位重采样，重复完整拟合、校准和评估流程。代价更高，但针对的是不同的不确定性问题。

两者都不能自动覆盖将来的结构性变化。

### 13.8 群体总量的不确定性

令 $`S=\sum_iY_i`$，则：

```math
\mathbb E[S\mid X]=\sum_i\mu_i,
```

```math
\mathrm{Var}(S\mid X)
=\sum_i\mathrm{Var}(Y_i\mid X)
+2\sum_{i\lt j}\mathrm{Cov}(Y_i,Y_j\mid X).
```

忽略共同促销、节假日或市场冲击，可能让总量区间明显过窄。即使每个用户的边际分布都正确，也不足以确定总量分布；还需要依赖结构。

模拟总量时，可在共享的日期、活动或宏观状态下联合生成用户结果，而非无条件把所有用户独立抽样。

### 13.9 Conformalized quantile regression

先在训练集上估计上下分位数 $`\widehat q_L,\widehat q_U`$。在独立校准集上定义：

```math
R_i=\max\{\widehat q_L(x_i)-y_i,\ y_i-\widehat q_U(x_i)\}.
```

取经有限样本修正的高分位数 $`\widehat r`$，输出：

```math
\left[
\widehat q_L(x)-\widehat r,\ 
\widehat q_U(x)+\widehat r
\right].
```

在校准样本与未来样本满足可交换性等条件时，CQR 提供边际覆盖保证。[13] 这个保证不是“每个 $`x`$、每个群体、每个未来时间段都具有同样覆盖率”。

金融时间序列和业务漂移常破坏可交换性，因此需要适用于依赖或漂移的扩展与实际回测，不能只贴上 conformal 标签。

```python
import numpy as np
from scipy.special import expit

rng = np.random.default_rng(20260922)
n, d = 12000, 6
X = rng.normal(size=(n, d)).astype(np.float32)

m_true = 4.5 + 0.5 * X[:, 2] + 0.2 * X[:, 3]
s_true = 0.6 + 0.4 * expit(X[:, 4])

z = rng.binomial(1, pi_true)
y_pos = np.exp(m_true + s_true * rng.normal(size=n))
y = (z * y_pos).astype(np.float64)
mu_true = pi_true * np.exp(m_true + 0.5 * s_true**2)

# Fixed partitions for a reproducible demonstration.
# Real projects must split by observation and label-availability time.

X_tr, y_tr = X[:i1], y[:i1]

X_te, y_te = X[i3:], y[i3:]
```

### 14.2 最小数据审计

```python
def audit_nonnegative(y):
    y = np.asarray(y, dtype=float)
    if y.ndim != 1 or len(y) == 0:
        raise ValueError("Expected a nonempty one-dimensional target.")
    if not np.isfinite(y).all():
        raise ValueError("Target contains missing or non-finite values.")
    if (y < 0).any():
        raise ValueError("Negative targets need a different model or label definition.")

    pos = y[y > 0]
    total = y.sum()
    k = max(1, int(np.ceil(0.01 * len(y))))
    return {
        "n": len(y),
        "zero_rate": float(np.mean(y == 0)),
        "mean": float(np.mean(y)),
        "positive_quantiles": (
            np.quantile(pos, [0.5, 0.9, 0.99]).tolist()
            if len(pos) else None
        ),
        "true_top_1pct_share": (
            float(np.sort(y)[-k:].sum() / total)
            if total > 0 else None
        ),
    }

print(audit_nonnegative(y_tr))
```

负标签在此处触发错误是因为示例明确针对非负目标；实际业务应检查净额定义，而不是直接删除所有负值。

### 14.3 统一指标与总量校准

```python
def amount_metrics(y, pred, top_fraction=0.10):
    y = np.asarray(y, dtype=float)
    pred = np.asarray(pred, dtype=float)
    if y.shape != pred.shape or y.ndim != 1 or len(y) == 0:
        raise ValueError("Targets and predictions must be aligned 1D arrays.")
    if not (np.isfinite(y).all() and np.isfinite(pred).all()):
        raise ValueError("Metrics require finite inputs.")
    if (y < 0).any() or (pred < 0).any():
        raise ValueError("This metric bundle is for nonnegative amounts.")
    if not 0 < top_fraction <= 1:
        raise ValueError("top_fraction must lie in (0, 1].")

    total = y.sum()
    k = max(1, int(np.ceil(top_fraction * len(y))))
    # Stable tie handling follows input order; record this rule in evaluation.
    top = np.argsort(-pred, kind="stable")[:k]
    return {
        "mae": float(np.mean(np.abs(y - pred))),
        "rmse": float(np.sqrt(np.mean((y - pred)**2))),
        "aggregate_ratio": float(pred.sum() / total) if total > 0 else None,
        "wape": float(np.abs(y - pred).sum() / total) if total > 0 else None,
        "capture": float(y[top].sum() / total) if total > 0 else None,
    }

def fit_total_multiplier(y_cal, pred_cal):
    y_cal = np.asarray(y_cal, dtype=float)
    pred_cal = np.asarray(pred_cal, dtype=float)
    if y_cal.shape != pred_cal.shape:
        raise ValueError("Calibration inputs must be aligned.")
    if not (np.isfinite(y_cal).all() and np.isfinite(pred_cal).all()):
        raise ValueError("Calibration inputs must be finite.")
    if (y_cal < 0).any() or (pred_cal < 0).any():
        raise ValueError("Expected nonnegative amounts.")
    if y_cal.sum() <= 0 or pred_cal.sum() <= 0:
        raise ValueError("Calibration window has no usable total.")
    return float(y_cal.sum() / pred_cal.sum())
```

分母为零时返回未定义或显式报错，比加一个极小数后生成貌似合理的指标更清楚。

### 14.4 LightGBM：Tweedie 候选模型

LightGBM 支持 Tweedie、Gamma、binary 和 quantile 等目标。[14] 下面对多个 $`p`$ 使用同一验证 MSE 选模，避免直接比较不同 $`p`$ 下省略常数项的目标值。

```python
import lightgbm as lgb

audit_nonnegative(y_tr)
candidates = []

for power in [1.2, 1.5, 1.8]:
    model = lgb.LGBMRegressor(
        objective="tweedie",
        tweedie_variance_power=power,
        metric="l2",
        n_estimators=2000,
        learning_rate=0.03,
        num_leaves=31,
        min_child_samples=80,
        reg_lambda=2.0,
        subsample=0.8,
        subsample_freq=1,
        colsample_bytree=0.8,
        random_state=7,
        n_jobs=4,
        verbosity=-1,
    )
    model.fit(
        X_tr, y_tr,
        eval_set=[(X_va, y_va)],
        eval_metric="l2",
        callbacks=[lgb.early_stopping(80, verbose=False)],
    )
    pred_va = model.predict(X_va)
    score = float(np.mean((y_va - pred_va)**2))
    candidates.append((score, power, model))

_, best_power, tweedie_model = min(candidates, key=lambda row: row[0])
pred_ca = tweedie_model.predict(X_ca)
multiplier = fit_total_multiplier(y_ca, pred_ca)

pred_te_raw = tweedie_model.predict(X_te)
pred_te_cal = multiplier * pred_te_raw
print("Selected power:", best_power)
print("Raw:", amount_metrics(y_te, pred_te_raw))
print("Calibrated:", amount_metrics(y_te, pred_te_cal))
```

这里以均值任务为前提使用 MSE。真实业务还应预先确定总量偏差、分组表现和排名的验收规则，而不是看到测试结果后选择最有利的指标。

### 14.5 LightGBM：BCE + Gamma

```python
z_tr = (y_tr > 0).astype(int)
z_va = (y_va > 0).astype(int)
pos_tr, pos_va = y_tr > 0, y_va > 0

if len(np.unique(z_tr)) != 2 or len(np.unique(z_va)) != 2:
    raise ValueError("Both classes are needed in this example.")
if pos_tr.sum() < 100 or pos_va.sum() < 30:
    raise ValueError("Too few positive examples for this demonstration.")

pi_model = lgb.LGBMClassifier(
    objective="binary",
    n_estimators=1500, learning_rate=0.03,
    num_leaves=15, min_child_samples=80,
    reg_lambda=2.0, random_state=7,
    n_jobs=4, verbosity=-1,
)
pi_model.fit(
    X_tr, z_tr,
    eval_set=[(X_va, z_va)],
    eval_metric="binary_logloss",
    callbacks=[lgb.early_stopping(80, verbose=False)],
)

gamma_model = lgb.LGBMRegressor(
    objective="gamma",
    n_estimators=1500, learning_rate=0.03,
    num_leaves=15, min_child_samples=40,
    reg_lambda=2.0, random_state=7,
    n_jobs=4, verbosity=-1,
)
gamma_model.fit(
    X_tr[pos_tr], y_tr[pos_tr],
    eval_set=[(X_va[pos_va], y_va[pos_va])],
    eval_metric="gamma",
    callbacks=[lgb.early_stopping(80, verbose=False)],
)

def predict_hurdle_gamma(X_new):
    pi = pi_model.predict_proba(X_new)[:, 1]
    mu_positive = gamma_model.predict(X_new)
    return pi * mu_positive

hurdle_c = fit_total_multiplier(y_ca, predict_hurdle_gamma(X_ca))
hurdle_pred = hurdle_c * predict_hurdle_gamma(X_te)
print(amount_metrics(y_te, hurdle_pred))
```

这里的 Gamma 树只负责均值。要生成 Gamma 预测区间，还需估计离散度并检查分布假设。总量乘法校准也没有单独校准分类概率，应另看概率校准曲线。

### 14.6 log 金额模型与 smearing

下面是无需假设严格 Lognormal 的共同 smearing 近似：

```python
log_model = lgb.LGBMRegressor(
    objective="regression",
    n_estimators=1500, learning_rate=0.03,
    num_leaves=15, min_child_samples=40,
    reg_lambda=2.0, random_state=7,
    n_jobs=4, verbosity=-1,
)
log_model.fit(
    X_tr[pos_tr], np.log(y_tr[pos_tr]),
    eval_set=[(X_va[pos_va], np.log(y_va[pos_va]))],
    eval_metric="l2",
    callbacks=[lgb.early_stopping(80, verbose=False)],
)

pos_ca = y_ca > 0
if pos_ca.sum() < 30:
    raise ValueError("Too few calibration positives.")
log_residual = np.log(y_ca[pos_ca]) - log_model.predict(X_ca[pos_ca])
smearing = float(np.mean(np.exp(log_residual)))

pi_te = pi_model.predict_proba(X_te)[:, 1]
mu_positive_te = np.exp(log_model.predict(X_te)) * smearing
pred_log_smear = pi_te * mu_positive_te
print(amount_metrics(y_te, pred_log_smear))
```

这段代码**不是异方差 Lognormal 的完整 MLE**。合成数据中特意令 $`s`$ 随特征变化，因此共同 smearing 也可能存在分组偏差。更完整的方法是同时估计 $`m(x),s(x)`$，再使用解析原尺度均值。

```python
    random_state=7,
    n_jobs=4,
)
xgb_quantile.fit(X_tr, y_tr, eval_set=[(X_va, y_va)], verbose=False)
q_te = xgb_quantile.predict(X_te)
u = y_te - q_te
pinball = np.mean(np.maximum(tau * u, (tau - 1.0) * u))
print("Pinball:", float(pinball))
print("Pr(Y <= q):", float(np.mean(y_te <= q_te)))
```

对含零原子质量的 GMV，经验 $`\Pr(Y\le q_\tau)`$ 可能大于 $`\tau`$，即使分位数正确也如此。金融风险任务可将标签替换为损失 $`L=-r`$，但仍需重新构造时间切分和特征。

### 14.8 PyTorch：异方差 Student-t 收益率模型

以下模型预测位置、尺度和全局自由度。PyTorch 的 StudentT、Gamma、LogNormal 分布均提供 log_prob 接口，可避免手写 NLL 时遗漏规范化项。[16]

先生成独立的合成收益率数据：

```python
import copy
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset
from torch.distributions import StudentT, Gamma, LogNormal
from scipy.stats import t as scipy_t

torch.manual_seed(7)
rng_r = np.random.default_rng(7)
X_r = rng_r.normal(size=(8000, 5)).astype(np.float32)
loc_r = 0.001 * X_r[:, 0]
scale_r = 0.005 + 0.015 * expit(X_r[:, 1])
r = loc_r + scale_r * rng_r.standard_t(df=5, size=len(X_r))

X_r_tr, r_tr = X_r[:5000], r[:5000]
X_r_va, r_va = X_r[5000:6500], r[5000:6500]
X_r_te, r_te = X_r[6500:], r[6500:]
```

此合成过程有条件异方差，但没有构造真实市场的时间依赖，主要用于理解代码与参数化。

训练函数：

```python
class StudentNet(nn.Module):
    def __init__(self, n_features):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_features, 32),
            nn.SiLU(),
            nn.Linear(32, 32),
            nn.SiLU(),
            nn.Linear(32, 2),
        )
        self.raw_df = nn.Parameter(torch.tensor(1.0))

    def forward(self, x):
        out = self.net(x)
        loc = out[:, 0]
        scale = torch.nn.functional.softplus(out[:, 1]) + 1e-4
        df = 2.0 + torch.nn.functional.softplus(self.raw_df)
        return StudentT(df=df, loc=loc, scale=scale)


def fit_student_model(X_train, y_train, X_valid, y_valid):
    X_train = np.asarray(X_train, dtype=np.float32)
    X_valid = np.asarray(X_valid, dtype=np.float32)
    y_train = np.asarray(y_train, dtype=np.float32)
    y_valid = np.asarray(y_valid, dtype=np.float32)

    x_center = X_train.mean(axis=0)
    x_scale = X_train.std(axis=0)
    x_scale = np.where(x_scale > 1e-8, x_scale, 1.0)
    y_center = float(y_train.mean())
    y_scale = float(y_train.std())
    if y_scale <= 1e-8:
        raise ValueError("Training target has negligible variation.")

    xt = torch.from_numpy((X_train - x_center) / x_scale)
    yt = torch.from_numpy((y_train - y_center) / y_scale)
    xv = torch.from_numpy((X_valid - x_center) / x_scale)
    yv = torch.from_numpy((y_valid - y_center) / y_scale)
    loader = DataLoader(TensorDataset(xt, yt), batch_size=256, shuffle=True)

    model = StudentNet(X_train.shape[1])
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
    best_state, best_nll, stale = None, float("inf"), 0

    for epoch in range(200):
        model.train()
        for xb, yb in loader:
            optimizer.zero_grad()
            loss = -model(xb).log_prob(yb).mean()
            if not torch.isfinite(loss):
                raise FloatingPointError("Non-finite training NLL.")
            loss.backward()
            nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0)
            optimizer.step()

        model.eval()
        with torch.no_grad():
            valid_nll = float(-model(xv).log_prob(yv).mean())
        if not np.isfinite(valid_nll):
            raise FloatingPointError("Non-finite validation NLL.")
        if valid_nll < best_nll - 1e-5:
            best_nll = valid_nll
            best_state = copy.deepcopy(model.state_dict())
            stale = 0
        else:
            stale += 1
            if stale >= 20:
                break

    model.load_state_dict(best_state)
    model.eval()
    return model, (x_center, x_scale, y_center, y_scale)


student_model, transform = fit_student_model(X_r_tr, r_tr, X_r_va, r_va)
```

这里 shuffle 的对象是已经完成历史切分后的训练样本，示例假设是普通条件分布回归。如果使用状态连续的序列模型，则需根据模型结构保留相应序列顺序。

把预测还原到收益率尺度，再计算 VaR 和 ES：

```python
def predict_student(model, transform, X_new):
    x_center, x_scale, y_center, y_scale = transform
    xt = torch.from_numpy(
        ((np.asarray(X_new, dtype=np.float32) - x_center) / x_scale)
        .astype(np.float32)
    )
    model.eval()
    with torch.no_grad():
        dist = model(xt)
        loc = dist.loc.cpu().numpy() * y_scale + y_center
        scale = dist.scale.cpu().numpy() * y_scale
        df = dist.df.cpu().numpy()
    return loc, scale, df


loc_hat, scale_hat, df_hat = predict_student(student_model, transform, X_r_te)

# Loss L = -return. Symmetry keeps the scale and df unchanged.
tau = 0.99
z_tau = scipy_t.ppf(tau, df_hat)
var_loss = -loc_hat + scale_hat * z_tau
es_loss = -loc_hat + scale_hat * (
    (df_hat + z_tau**2) / (df_hat - 1.0)
) * scipy_t.pdf(z_tau, df_hat) / (1.0 - tau)

loss_observed = -r_te
exceedance = np.mean(loss_observed > var_loss)
return_nll = -np.mean(
    scipy_t.logpdf(r_te, df=df_hat, loc=loc_hat, scale=scale_hat)
)
print("Test exceedance rate:", float(exceedance))
print("Original-scale NLL:", float(return_nll))
```

这里的 VaR 和 ES 是基于 Student-t 模型的预测，ES 公式要求 $`\nu>1`$。输出了风险数值并不代表通过了回测；还要进行第 11、12、13 节的检验。

### 14.9 PyTorch 中其他损失的最小实现

```python
def gamma_nll(y, mu, phi):
    # All inputs broadcast to the same sample shape.
    if not torch.all(y > 0):
        raise ValueError("Gamma likelihood requires strictly positive targets.")
    k = 1.0 / phi
    return -Gamma(concentration=k, rate=k / mu).log_prob(y).mean()


def lognormal_nll(y, m, s):
    if not torch.all(y > 0):
        raise ValueError("Lognormal likelihood requires positive targets.")
    return -LogNormal(loc=m, scale=s).log_prob(y).mean()


def pinball_loss(y, q, tau):
    residual = y - q
    return torch.maximum(
        tau * residual, (tau - 1.0) * residual
    ).mean()
```

$`\mu,\phi,s`$ 应通过正值参数化产生。若 $`y`$ 为形状 $`(n,)`$ 而多分位数输出为 $`(n,K)`$，需要显式使用 $`y[:,None]`$，避免不期望的广播。

### 14.10 用户聚类 bootstrap 的指标示例

下面只评估固定模型的 aggregate ratio，不重训模型：

```python
def cluster_ratio_interval(y, pred, user_id, repeats=1000, seed=7):
    y = np.asarray(y, dtype=float)
    pred = np.asarray(pred, dtype=float)
    user_id = np.asarray(user_id)
    if y.ndim != 1 or y.shape != pred.shape or y.shape != user_id.shape:
        raise ValueError("Inputs must be aligned one-dimensional arrays.")
    if not (np.isfinite(y).all() and np.isfinite(pred).all()):
        raise ValueError("Expected finite amounts.")
    if (y < 0).any() or (pred < 0).any() or y.sum() <= 0:
        raise ValueError("Expected nonnegative amounts with a positive total.")

    _, index = np.unique(user_id, return_inverse=True)
    m = int(index.max()) + 1
    if m < 2:
        raise ValueError("Need more than one independent cluster.")
    y_by_user = np.bincount(index, weights=y, minlength=m)
    p_by_user = np.bincount(index, weights=pred, minlength=m)

    rng_boot = np.random.default_rng(seed)
    ratios = np.empty(repeats)
    for b in range(repeats):
        sampled = rng_boot.integers(0, m, size=m)
        denominator = y_by_user[sampled].sum()
        if denominator <= 0:
            raise ValueError("A bootstrap replicate has zero observed total.")
        ratios[b] = p_by_user[sampled].sum() / denominator
    return np.quantile(ratios, [0.025, 0.975])
```

该 percentile 区间只在相应重采样假设合理、统计量足够稳定时才有可用性。它不解决无限方差、强时间依赖或结构性漂移问题；没有发生非有限数值，也不代表覆盖率正确。

## 15. 完整工作流、易错点与自测

### 15.1 一套可以执行的工作流

**第一步：写清决策。** 明确预测服务于预算、排序、用户画像还是风险阈值，确定 mean、median 或 quantile。

**第二步：写清标签。** 定义观察单位、窗口、币种、退款、成熟时间和特征可用时点。

**第三步：完成审计。** 看 support、零、正值分布、条件残差、集中度、variance-mean 与异常来源。

**第四步：建立简单基线。** 用历史常数、分组均值或基础 GLM，确认复杂模型带来的改进。

**第五步：选择少量合理候选。** 金额比较 Tweedie、BCE + Gamma、BCE + Lognormal；收益率比较简单波动基线、Gaussian / Student-t 分布回归和分位数模型。

**第六步：按同一标准选模。** 预先定义指标，固定时间切分，避免跨尺度 NLL 或不同 $`p`$ 的不可比目标造成误选。

**第七步：独立校准。** 对概率、总量或区间分别处理，明确校准集用途。

**第八步：做最终时间外验收。** 同时检查个体误差、分组总量、Top-K、尾部覆盖以及业务结果。

**第九步：报告不确定性。** 写清区间针对什么、使用何种重采样单位、是否重训、依赖哪些矩条件。

**第十步：上线监控。** 监控标签延迟、零率、尾部集中度、分组偏差、预测尺度、风险超越与数据漂移。

### 15.2 十二个常见误区

| 误区 | 修正 |
|---|---|
| 长尾就应该换 MAE | 先确认是否可以把均值目标改为中位数 |
| MSE 必须假设正态 | 均值最优性与 Gaussian 似然解释是不同层面 |
| Gamma 是稳健损失 | 其金额梯度仍可能无界；它主要编码支持集和方差结构 |
| 右偏一定是重尾 | Gamma 可右偏但属于轻尾 |
| 对 log 金额做 MSE 再 exp 就是均值 | 需要反变换修正与相应分布条件 |
| Tweedie 自动解决所有零值问题 | 零率约束和真实业务机制可能不匹配 |
| Hurdle 的分位数等于概率乘正值分位数 | 只有均值可直接按这类乘法分解 |
| Student-t 的 scale 就是标准差 | 标准差还依赖自由度，且需 $`\nu>2`$ |
| Huber 自动防御高杠杆点 | 回归得分仍含特征向量 |
| bootstrap 不需要任何分布条件 | 重尾、依赖与非正则统计量均可能使其失效 |
| 总量准说明个人排序也准 | 两者应分别评价 |
| 个体 P99 相加就是总量 P99 | 总量分布取决于依赖结构，分位数通常不可加 |

### 15.3 学习自测

**问题 1：为什么 GMV 有 90% 的零值时，中位数模型可能没有出价价值？**

因为中位数可为零，而原尺度条件均值仍可能由剩余 10% 的正值贡献决定。是否出价还涉及成本与增量收益，但不能先把正值尾部的期望贡献丢掉。

**问题 2：若正值 Lognormal 的 $`m`$ 固定，$`s`$ 从 0.5 增加到 1，中位数和均值如何变化？**

中位数不变；均值之比为：

```math
\frac{\exp(m+1/2)}{\exp(m+0.25/2)}
=e^{0.375}\approx1.455.
```

更多右尾不确定性提高了原尺度均值，即使 log 位置没变。

**问题 3：如果 Gamma 模型在一个样本上预测 100，真实金额从 1000 增到 10000，其 log-mean 梯度会不会饱和？**

不会。省略固定形状因子后，梯度由 $`1-1000/100=-9`$ 变为 $`1-10000/100=-99`$，绝对值继续增大。

**问题 4：Student-t 自由度为 1.5，能否报告基于该分布方差的标准差？**

不能。均值存在，但方差无限。可以报告分位数等存在且定义明确的量，或重新考虑是否需要约束自由度。

**问题 5：总体 P90 为零，模型是不是失败了？**

不一定。如果真实零概率至少为 90%，按广义逆定义 P90 本来就可以为零。需要检查的是条件零概率与分位数定义，而不是强制输出正数。

**问题 6：总量校准率为 1，但 Top-10% capture 很差，意味着什么？**

均值总量没有明显偏差，但模型无法把高价值个体排到前面。应检查特征、组内区分能力和最终筛选目标。

**问题 7：可以用一万个 bootstrap 样本弥补只有两次尾部事件的问题吗？**

不能。重复抽样不能补充尚未观察到的尾部信息。需要报告原始事件数量、模型假设和对极端事件的敏感性。

### 15.4 最后需要形成的判断能力

面对一个新数据集，应能依次回答：

1. 这个标签允许哪些值，零意味着什么？
2. 长尾来自真实生成机制、群体混合，还是数据污染？
3. 业务需要的是期望、典型值、阈值还是完整分布？
4. 当前 loss 的总体最优解是什么，是否与业务一致？
5. inference 时如何把模型参数变成业务量？
6. 校准、尾部、排序和时间外表现是否都经过检查？
7. 区间与显著性结论依赖哪些矩条件和独立性假设？

这些问题比记住“某种长尾对应某个 loss”更有助于形成稳定的建模方法。
