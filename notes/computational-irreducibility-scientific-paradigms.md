# 从计算不可约性到未来科学范式

**一份关于计算、统计、数学结构、复杂系统与科学方法论的系统总结**

我们这轮讨论从一个非常朴素的问题开始：

> **为什么三体问题的物理方程如此简单，但经过几百年的数学发展，我们仍然难以直接预测它的长期运动？**

随后，我们逐渐讨论了计算不可约性、解析解的意义、现代统计学对假设的放松、科学史上的抽象革命、复杂系统的宏观规律，以及未来人工智能和科学研究的范式。这些看似不同的问题，实际上围绕着同一个主题：

> 世界并不保证以适合人类理解和计算的方式运行。科学的任务，不只是寻找规律，还包括发现什么能够被简化、什么必须计算、什么可以被可靠推断，以及如何在不可消除的复杂性中采取行动。

本文沿着四条主线展开，最后汇总为统一的科学哲学与七条研究原则，尝试建立一个有内在逻辑的理论框架。

> **第一篇：复杂性的本质**

## 一、简单的自然规律，为什么能够产生复杂的世界？

经典物理学的一项伟大成就是发现：大量看似不同的自然现象，可以由少数简单的数学规律解释。

例如，牛顿第二定律：

```math
F=ma
```

万有引力定律：

```math
F=G\frac{m_1m_2}{r^2}
```

这些公式非常简洁。由此很容易形成一种直觉：

> 简单的基本规律 → 简单的未来预测？

但这个推论并不成立。

### 例子：从二体问题到三体问题

对于牛顿引力作用下的两个质点，可以将运动化为等效单体的中心力问题，得到开普勒轨道。轨道可以是椭圆、抛物线或双曲线。

- **二体运动**：具有丰富的可积结构，可利用轨道参数描述。

- **三体运动**：一般不可积，轨道可能呈现高度复杂的行为。

加入第三个天体后：

```math
\ddot{\mathbf r}_i = G\sum_{j\ne i} m_j \frac{\mathbf r_j-\mathbf r_i} {\|\mathbf r_j-\mathbf r_i\|^3}
```

方程没有发生本质上的变化。但求解结构发生了巨大变化。一般三体问题缺乏二体问题中的可积结构，并且可能出现混沌、复杂散射和逃逸行为。由此得到第一个核心结论：**微观规则的简洁性，与系统长期行为的复杂性，是两个不同维度。**

## 二、计算不可约性：知道规律，也未必能跳过演化过程

Stephen Wolfram 推广的计算不可约性思想，进一步解释了为什么简单规则可能产生难以预测的结果。考虑：

```math
x_{t+1}=F(x_t)
```

要预测第 $`T`$ 步状态：

```math
x_T=F^T(x_0)
```

关键不在于能否写下这个表达式，而在于能否绕过中间演化。对于：

```math
x_{t+1}=2x_t
```

我们得到：

```math
x_T=2^Tx_0
```

因此可以使用快速幂等算法。但某些系统可能不存在类似的通用加速算法，完整未来状态的计算可能需要执行大量中间步骤。

### 例子：元胞自动机

Rule 30 只根据每个格子与其相邻格子的状态更新，却能产生不规则的复杂图案。Rule 90 则具有明显的代数结构，可以利用二项式系数模 2 进行计算。两者的局部规则都很简单，但可利用的计算结构不同。Rule 30 被广泛用作计算不可约性的候选例子，但其严格的最优计算时间下界并未由这种复杂图案本身得到证明。

### 必须区分的四种困难

| 概念     | 根本限制           | 典型例子   |
| ------ | -------------- | ------ |
| 非可积性   | 缺乏足够的可积结构      | 一般三体问题 |
| 混沌     | 初始误差被动力学放大     | 混沌三体轨道 |
| 不可计算性  | 不存在解决某类问题的通用算法 | 停机问题   |
| 计算不可约性 | 可能不存在显著更快的预测捷径 | 某些计算系统 |

它们之间有联系，但互不等价。一个混沌系统未必计算不可约；一个不可积系统也未必不存在快速近似算法。

### 三体问题未来还会有解吗？

实际上，三体问题早已有数值求解方法，并且存在特殊的周期轨道。Sundman 在 1912 年还建立了某些条件下的收敛级数表示，只是计算效率很低。

因此，三体问题不是完全「没有数学解」。真正的问题是：

> **是否存在一般、简洁且高效的长期预测方法？**

对此，目前没有一个肯定的答案，也不能严格断言所有这样的捷径必然不存在。三体问题提醒我们：发现动力学规律，与发现高效求解算法，是两个独立的科学任务。

## 三、解析解本身也是一种计算程序

这是你在讨论中提出的一个非常重要的观点。即使我们得到：

```math
x=\sqrt2
```

如果要求它的前一百位小数，仍然需要计算。对于：

```math
x=e^\pi+\sqrt7
```

情况也是一样。

因此，解析解并不意味着计算已经结束。从计算视角看，一个数学表达式也是一种程序。

例如，我们可以比较两种复杂度：

- **描述复杂度** $`K(x)`$：描述对象所需的最短程序长度。
- **求值复杂度** $`C(x,\epsilon)`$：把对象计算到精度 $`\epsilon`$ 所需的资源。

二者不是同一个概念。一个对象可以具有非常简短的数学描述，但精确求值仍然需要大量计算。反过来，一个很长的表达式，也可能包含能够高效计算的局部结构。

### 特殊函数的例子

考虑：

```math
y'=y
```

我们写出：

```math
y(x)=Ce^x
```

如果把一个更复杂的微分方程的解定义为特殊函数 $`H(x)`$，然后写：

```math
y(x)=H(x)
```

仅仅赋予名字并没有真正解决计算问题。特殊函数真正有价值，是因为我们发现了其恒等式、渐近展开、递推关系及数值算法。所以：

**数学表达的压缩，不等于计算成本的压缩。**

但解析解还有一项数值方法无法直接替代的优势：证明普遍结构。

例如：

```math
x(t)=A\cos(\omega t+\phi)
```

立即表明：

```math
|x(t)|\le |A|
```

对所有 $`t`$ 成立。这不是计算某一个数值，而是一次性获得关于无限多个时间点的知识。

因此，数学至少同时追求：

- 对象的简洁表示；
- 高效的数值求值；
- 对一般性质的严格证明。

这些目标有关联，但不能彼此替代。

> **第二篇：数学的结构革命**

## 四、伟大的数学突破，经常不是解决问题，而是改变问题

你提出的解析几何和群论两个例子，是整场讨论的重要转折点。它们提醒我们：科学进步不是单纯地提高计算能力，而是不断寻找能够重新组织问题的数学语言。

### 例子一：从欧氏几何到解析几何

在古典平面几何中，复杂问题常常依赖巧妙的辅助线和图形构造。解析几何引入坐标：

- 点 → $`(x,y)`$
- 直线 → $`ax+by+c=0`$
- 圆 → $`(x-a)^2+(y-b)^2=r^2`$

这样，几何图形之间的位置关系就可以转化为代数方程。这是一次表示方式的革命。以前每个问题可能需要独特的几何技巧，现在一大类问题能够使用统一的代数方法。

### 例子二：从代数方程到 Galois 理论

数学家长期尝试寻找一般五次方程的根式通解：

```math
a_5x^5+a_4x^4+\cdots+a_0=0
```

Abel–Ruffini 定理表明，一般五次方程不存在根式通解。Galois 理论则进一步解释了原因：根式可解性受到根的置换对称性约束。在通常的特征零框架下：

> **根式可解 ⇔ Galois 群是可解群。**

一般五次方程的 Galois 群为 $`S_5`$，而 $`S_5`$ 不是可解群。注意，这不是说五次方程的根不能计算。它们可以通过数值算法或更广义的特殊函数来表示。真正得到证明的是：某一类求解方法存在不可突破的能力边界。这比发现一个具体公式更具有普遍意义。

### 数学史中反复出现的模式

- **第一阶段 · 求具体答案**  
  如何证明这个几何命题？如何求这个方程的根？

- **第二阶段 · 寻找共同结构**  
  哪些坐标、对称性、不变量能够统一这些问题？

- **第三阶段 · 研究可解性与能力边界**  
  哪些问题可以解决？哪些方法原则上不可能成功？

- **第四阶段 · 产生新的理论领域**  
  研究对象从单个答案上升为整个结构及其普遍规律。

这在其他学科中也不断出现。

例如，Poincaré 将动力系统研究从寻找具体轨道，扩展为研究相空间、周期轨道及稳定性。Shannon 将通信问题上升为研究信息、熵和信道容量。现代统计决策理论则不再只研究某个估计器，而是研究一整类估计器能达到的最优风险。

## 五、科学中的「不可能性定理」为什么如此重要？

这是群论、计算理论与现代统计学之间一条非常深刻的联系。数学研究通常可以问两类问题：

- **构造性问题**：是否能够找到一种方法完成任务？
- **极限性问题**：是否能够证明所有某一类方法都无法突破某个限制？

后者往往更难，但也更有理论价值。

### 例子一：Galois 理论

证明一般五次方程不能通过根式求解。限制的是求解方法类别。

### 例子二：图灵停机问题

不存在一个通用算法，能够对所有任意程序和输入都正确判定程序是否停机。这是可计算性的限制。

### 例子三：计算复杂性

对于某类问题，我们希望证明：

```math
\inf_{\mathcal A} \sup_{x\in\mathcal X} \mathrm{Time}(\mathcal A,x) \ge C(n)
```

这里算法需要满足指定的正确性要求。如果这样的下界成立，就说明任何合格算法都必须付出相应的计算成本。

### 例子四：统计极小极大下界

定义：

```math
R_n^* = \inf_{\hat\theta} \sup_{P\in\mathcal P} \mathbb E_P \left[ L(\hat\theta,\theta(P)) \right]
```

它研究的不是某个估计器，而是整个统计问题中最好的估计器能够达到什么精度。

例如，考虑：

```math
X_1,\ldots,X_n \overset{iid}{\sim} N(\mu,\sigma^2)
```

其中 $`\sigma^2`$ 已知，$`\mu\in\mathbb R`$。在平方损失下，均值估计的极小极大风险为：

```math
R_n^*=\frac{\sigma^2}{n}
```

样本均值达到这个风险。这意味着我们不只是证明样本均值「很好」，还证明在这个问题类别下，没有估计器能够获得更低的最大风险。

### 这些理论的共同哲学

不只研究已经找到的最好方法，而是研究所有可能方法的极限。这是一种从「算法研究」走向「问题本身的理论」的思想。但需要强调：**不可能性结论总是相对于具体假设、目标和允许的方法而言。**

一般五次方程没有根式通解，不代表它不能求数值解；某个统计模型下的下界，也不代表增加额外信息后仍然无法改善。

## 六、复杂系统的宏观规律：科学为什么能够绕过微观复杂性？

这里存在一个看似矛盾的现象。一方面，复杂系统的微观演化可能非常难以预测。另一方面，现实中大量宏观规律却十分简单。为什么？

答案的一部分是：宏观理论可能只需要少数与研究目标有关的变量。

### 例子一：统计力学与热力学

一个气体系统包含大量分子。如果要求计算每个分子的未来位置和速度，问题极其复杂。但宏观层面，我们可以使用：

```math
PV=nRT
```

描述满足理想气体近似条件的平衡状态。这不是因为微观轨迹突然变得简单。而是因为宏观规律不依赖所有微观细节。

### 例子二：重整化群

在连续相变附近，不同材料可能呈现相同的临界指数。原因与尺度变换下的有效自由度、相关方向和不动点结构有关。微观世界千差万别，但某些宏观性质却属于相同的普适类。这揭示了科学中一种极为重要的简化：

不需要知道所有微观参数，仍然可能预测一类系统共同的宏观行为。

### 例子三：机器学习的表示学习

给定复杂输入：

```math
X\in\mathbb R^d
```

我们希望找到低维表示：

```math
Z=\phi(X)\in\mathbb R^k,\qquad k\ll d
```

使得对某个目标 $`Y`$：

```math
P(Y\mid X)\approx P(Y\mid Z)
```

这意味着可以丢弃许多与目标无关的信息。但有一个关键限制：同一种压缩未必适用于所有任务。预测用户点击率所需要的信息，未必足以预测用户长期收入；预测金融收益的表示，也未必适用于尾部风险。所以，科学上的简化应当是：

> **针对目标寻找充分信息**

而不是追求无条件的最大压缩。

### 从这里得到的科学原则

**微观复杂性与宏观可约性可以同时存在。**

真正需要研究的是：

```math
Z_t=\phi(X_t)
```

是否存在简单的宏观动力学：

```math
Z_{t+1}\approx G(Z_t)
```

以及这种近似在什么时间尺度、空间尺度和误差容忍度下成立。这将计算不可约性与涌现理论连接起来。

> **第三篇：现代统计学与决策理论**

## 七、现代统计学正在从理想模型，走向最小必要假设

你观察到现代统计学逐渐放松 IID、正态性和模型正确性假设，这确实是统计学重要的发展趋势。但我认为应当更准确地表述为：

**现代统计学并不是不要假设，而是研究某个结论究竟依赖哪些最小条件，并在这些条件下提供尽可能可靠的保证。**

### 7.1 从正态分布到更广泛的分布类

经典统计经常研究：

```math
X_1,\ldots,X_n \overset{iid}{\sim} N(\mu,\sigma^2)
```

因为正态模型可以获得很多精确结果。但实际数据可能厚尾、偏态、异方差，甚至存在极端值。现代统计的一条路线是尽量减少具体分布形式的限制。

例如 Hoeffding 不等式只需要独立性和有界性，不要求变量完全同分布，也不要求正态性。对于独立的 $`X_i\in[a,b]`$：

```math
\Pr\left( |\bar X-\mathbb E\bar X|\ge\epsilon \right) \le 2e^{-2n\epsilon^2/(b-a)^2}
```

这是一个有限样本保证。

### 7.2 从渐近结果到非渐近理论

经典理论经常关注：

```math
n\to\infty
```

但我们现实中使用的始终是有限数据。

因此现代非渐近统计试图建立：

```math
\Pr\left( \|\hat\theta-\theta_0\| \le B(n,p,\delta) \right) \ge1-\delta
```

其中误差界明确依赖样本量、维度和置信水平。

例如，在适当条件下，稀疏线性回归具有：

```math
\|\hat\beta-\beta^*\|_2 \lesssim \sigma\sqrt{\frac{s\log p}{n}}
```

这里最重要的思想是：

**通过可利用的结构，而不是简单依赖样本量无限增大，来克服高维问题。**

### 7.3 从 IID 到依赖数据

对于金融时间序列：

```math
r_t=\sigma_t\epsilon_t
```

即使 $`\epsilon_t`$ 之间相互独立，波动率 $`\sigma_t`$ 也可能具有时间依赖。这会形成波动聚集。假设一个弱平稳序列的自协方差为：

```math
\gamma(k)=\mathrm{Cov}(X_t,X_{t+k})
```

那么样本均值的方差是：

```math
\mathrm{Var}(\bar X_n) = \frac1n\left[ \gamma(0) + 2\sum_{k=1}^{n-1} \left(1-\frac{k}{n}\right)\gamma(k) \right]
```

可见，时间相关性会改变均值估计的不确定性。在适当的自协方差可求和条件下，其渐近方差由长期方差决定：

```math
\Omega=\gamma(0)+2\sum_{k=1}^\infty\gamma(k)
```

这也是 HAC 协方差估计、Block Bootstrap 等技术的重要动机。所以，当 IID 失效时，不应继续使用所有 IID 公式，也不必认为统计推断完全失效。正确的方向是刻画依赖结构。

### 7.4 从轻尾模型到稳健统计

对于广告收入、金融收益等长尾变量，样本均值可能受到少量极端观测的强烈影响。假设：

```math
\mathbb E[X^2]<\infty
```

但 $`X`$ 具有厚尾。普通均值在均方误差意义下仍然有良好性质，却未必拥有理想的有限样本高概率集中行为。稳健均值估计，例如 median-of-means，通过分组求均值、再取中位数，可以在有限方差假设下获得接近：

```math
|\hat\mu-\mu| \lesssim \sigma\sqrt{\frac{\log(1/\delta)}{n}}
```

的高概率误差界，前提是采用适当的分组方案和样本条件。这里的意义不是「不再存在长尾」，而是改变估计方法，使极端观测不至于严重破坏统计保证。

### 7.5 从模型正确到正交估计

你熟悉的 DML、R-Learner、DR-Learner 都与这个方向相关。我们不再要求高维辅助模型处处准确，而是构造目标估计程序，降低某些辅助误差的影响。

例如 Neyman 正交性：

```math
\left. \frac{\partial}{\partial r} \mathbb E[ \psi(Z;\theta_0,\eta_0+rh) ] \right|_{r=0} =0
```

使辅助模型误差的一阶影响消失。这并不能消除所有模型假设，也不能自动确保 CATE 模型正确。但它说明：

与其把全部资源投入精确恢复高维数据生成过程，不如让目标估计对不重要的模型误差不敏感。

### 7.6 从点预测到预测保证

保形预测（Conformal Prediction）在交换性条件下可以构造满足：

```math
\Pr(Y_{n+1}\in C(X_{n+1})) \ge1-\alpha
```

的有限样本边际覆盖预测集合。它不需要指定一个正确的参数分布模型。但如果测试数据发生任意的非平稳漂移，这个保证一般不再自动成立。这恰好体现了现代统计学的成熟：

我们不只是声称一种方法有效，而是精确说明它在哪些条件下有效。

### 现代统计思想的总体变化

| 传统研究重点   | 扩展后的研究重点    |
| -------- | ----------- |
| 假设一个精确分布 | 研究更广泛的分布类   |
| 证明大样本性质  | 研究有限样本误差    |
| 假设样本独立   | 刻画时间或空间依赖   |
| 假设模型完全正确 | 降低对模型错设的敏感性 |
| 估计完整概率模型 | 集中估计目标参数    |
| 寻找高效估计器  | 同时研究效率与稳健性  |
| 给出预测数值   | 同时给出不确定性保证  |

但这些不是旧理论被新理论简单淘汰。参数模型、渐近分析和 IID 仍然有巨大价值。关键是判断它们能否合理服务于具体问题。

## 八、统计复杂性、计算复杂性和信息复杂性并不是一回事

这是前面多个话题可以统一的地方。考虑估计某个未知参数 $`\theta`$。即使我们拥有无限计算能力，也未必能从有限数据中精确估计它。反过来，即使拥有足够数据，最优估计器也可能计算代价极高。

因此至少存在四个不同的限制。

- **信息限制**：数据中是否包含足够的信息来区分不同机制？

- **统计限制**：在有限样本下，估计误差最小能达到多少？

- **计算限制**：达到某个精度需要多少运算资源？

- **实验限制**：我们能获得哪些观测，能进行哪些干预？

### 例子一：统计不可识别性

假设观察数据中：

```math
Y=\theta_1+\theta_2+\epsilon
```

但无法单独观测 $`\theta_1,\theta_2`$ 的作用。那么即使样本无限大，也最多识别二者之和：

```math
\theta_1+\theta_2
```

无法分别识别两个参数。这不是计算机不够快，而是信息本身不足。

### 例子二：高维统计的计算障碍

某些高维统计问题存在精确但计算代价高昂的组合优化方法。与此同时，Lasso 等凸优化方法可能具有更好的计算可行性，但依赖不同的信号强度和设计条件。

因此，**统计上可恢复**与**可以高效恢复**并不总是等价。

### 例子三：因果不可识别性

假设观察到：

```math
P(Y\mid A=1)\neq P(Y\mid A=0)
```

并不能直接得出：

```math
\mathbb E[Y(1)-Y(0)]\neq0
```

因为选择进入处理组可能由混杂因素造成。我们需要随机实验或额外的识别假设。这一限制不是增加模型容量就能够自动消除的。

### 联合资源视角

一种研究问题的方式，是将算法看成受到资源限制的估计程序：

```math
R^*(n,B) = \inf_{\substack{\hat\theta:\\ \mathrm{Cost}(\hat\theta)\le B}} \sup_{P\in\mathcal P} \mathbb E_P \left[ L(\hat\theta,\theta(P)) \right]
```

其中：

- $`n`$：样本量；
- $`B`$：计算预算；
- $`\mathcal P`$：允许的数据生成分布；
- $`L`$：损失函数。

这个定义说明，最优统计性能可能依赖于我们允许投入多少计算。同样，还可以把主动实验的数量和成本纳入框架。这也是未来统计学、计算理论与科学实验设计值得进一步融合的方向。

## 九、从预测世界到优化决策

传统机器学习高度重视预测误差：

```math
\min_f\mathbb E[(Y-f(X))^2]
```

但一个预测模型再准确，也不保证它能产生好的决策。因为决策往往还取决于风险、成本、约束与长期反馈。

### 例子一：RCT 中的最优干预

假设我们有随机实验数据，目标是给不同用户选择激励策略。对于二元处理：

```math
\tau(x) = \mathbb E[Y(1)-Y(0)\mid X=x]
```

如果干预具有成本 $`c(x)`$，则在一个简化的收益最大化问题中，可以选择：

```math
\pi(x) = \mathbb I\{\tau(x)>c(x)\}
```

这里假设结果和成本以可比较的价值单位表示，并且没有额外的整体资源约束。重要的是：我们不需要精确预测用户在干预后每一项行为的完整轨迹。

**我们需要的是与干预决策相关的增量效应。**

如果预算有限，则问题会变成带约束的策略优化。

### 例子二：强化学习

对于马尔可夫决策过程，价值函数为：

```math
Q^\pi(s,a) = \mathbb E_\pi \left[ \sum_{t=0}^{\infty}\gamma^tR_t \mid S_0=s,A_0=a \right]
```

价值函数把未来可能发生的大量路径，压缩为一个与当前决策相关的期望量。这是一种目标驱动的计算压缩。虽然价值函数本身也可能难以估计，但它避免了必须显式列举所有未来轨迹。

### 例子三：面对 Regime Shift 的稳健决策

假设环境分布会发生变化。我们可以选择尝试预测：

```math
P(Z_{t+1}\mid X_t)
```

其中 $`Z_t`$ 表示市场状态。但也可以直接优化策略在多个环境下的稳健性：

```math
\pi^* = \arg\max_\pi \min_{P\in\mathcal P} V_P(\pi)
```

前者试图准确预测变化，后者试图减小对预测正确性的依赖。两者并非互斥。实际上，可以将状态预测用于提高效率，再用稳健约束控制误判造成的风险。

### 核心结论

> **完整预测的困难，并不意味着有效决策必然困难。**

一个系统可能无法被高效地完整模拟，但仍然存在可以利用的统计优势、控制规律或稳定策略。这正是现代统计决策理论、因果推断和强化学习之间的重要联系。

## 十、金融市场：一个同时受到信息、统计、计算和竞争限制的系统

量化投资是我们讨论的这些思想非常好的实际应用。金融市场中的困难不只是价格波动复杂，还包括市场参与者会不断调整自己的行为。可以将价格演化抽象为：

```math
P_{t+1} = F(P_t,X_t,A_t,\epsilon_{t+1})
```

其中：

- $`X_t`$：经济和市场状态；
- $`A_t`$：市场参与者的交易行为；
- $`\epsilon_{t+1}`$：新信息与外生冲击。

与固定规则的经典动力系统不同，金融市场中的参与者会学习、竞争并改变策略。

因此，它是一种复杂适应系统。

### 10.1 历史有效，不代表未来有效

假设某个因子满足：

```math
\mathbb E[r_{t+1}\mid X_t=x]>0
```

如果大量交易者发现这个规律，就可能提前买入，使该规律所对应的超额收益减少。于是：

```math
P_{\text{future}}(r\mid X) \neq P_{\text{historical}}(r\mid X)
```

这种变化可能来自竞争、交易成本、市场结构改变等原因。不过，Alpha 并不必然消失。某些收益来源可能对应承担风险、提供流动性或利用其他参与者的约束。

因此，量化研究不能只问一个规律过去是否存在，还要问它为什么可能持续存在。

### 10.2 计算越强，越容易出现回测过拟合

假设我们测试 $`M`$ 个实际上没有预测能力的独立策略。每个策略的样本内 Sharpe 估计包含随机误差：

```math
\hat S_j=\epsilon_j
```

在理想化高斯噪声条件下，最大噪声 Sharpe 随候选数量增加，其主导量级近似为：

```math
\mathbb E[\max_j\hat S_j] \sim \sigma\sqrt{2\log M}
```

这意味着：

**计算能力使我们能够搜索更多策略，但不会自动增加真实的市场预测信息。**

搜索越多，如果验证方法没有相应改进，就越容易发现貌似优秀、实际无效的策略。这与统计学中的多重检验、选择偏差和泛化误差直接相关。

### 10.3 量化投资应该预测什么？

不一定是未来完整价格路径。可以重点预测：

```math
\begin{aligned}
\mu_t &= \mathbb E[r_{t+1}\mid X_t], \\
\Sigma_t &= \mathrm{Cov}(r_{t+1}\mid X_t).
\end{aligned}
```

以及交易成本、尾部风险和流动性。最终将其转化为组合决策：

```math
w_t^* = \arg\max_w \left[ \hat\mu_t^\top w -\frac{\lambda}{2}w^\top\hat\Sigma_t w -\mathrm{Cost}(w,w_{t-1}) \right]
```

这体现了从预测到决策的转变。

### 对个人量化策略的具体启示

以 A 股行业 ETF 为例。与其一开始使用庞大的深度学习模型预测所有行业未来价格，不如先建立一套简洁但可严格检验的系统。

- **第一层 · 提取有效状态**  
  研究趋势、动量、波动率、行业相关性和市场流动性。

- **第二层 · 估计决策相关变量**  
  预测行业相对收益、组合风险与交易成本。

- **第三层 · 进行受约束的组合优化**  
  控制集中度、仓位、换手和回撤风险。

- **第四层 · 样本外验证与持续更新**  
  检测 Regime Shift、策略失效和真实交易表现。

这里最重要的不是模型的复杂程度，而是策略能否通过严格的样本外评估，以及扣除成本后是否仍然具有经济价值。金融市场给我们的特殊启示是：

> 一个模型即使在统计上可预测、计算上可实现，也未必在经济上有价值。

因此，量化投资同时面临统计极限、计算极限和经济竞争极限。

## 十一、AI 将如何改变未来科学？

回顾科学史，科学家主要通过理论推导、实验观察和数值计算寻找规律。未来 AI 可能进一步改变这一工作流程。但我认为真正重要的不是让 AI 自动写论文，而是构建一种可以不断提出、检验和修正假设的科研系统。

### 11.1 从被动学习到主动实验

传统机器学习通常获得数据集：

```math
D=\{(X_i,Y_i)\}_{i=1}^n
```

然后训练模型。主动实验则会问：

下一个实验应该在哪里进行，才能带来最大的知识增益？

例如，可以将实验选择表示为：

```math
a^* = \arg\max_a \left[ \mathbb E[\mathrm{IG}(a)] -\lambda\mathrm{Cost}(a) \right]
```

其中 $`\mathrm{IG}(a)`$ 是实验带来的信息增益。这与主动学习、贝叶斯实验设计、多臂老虎机和强化学习相联系。

### 11.2 从静态模型到闭环科研

未来科研可能形成如下循环：

1. 提出科学假设。
2. 选择信息价值最高的实验。
3. 自动执行实验、计算与统计推断。
4. 独立验证结果并更新理论。
5. 循环发现、证伪、修正和深化。

这里 AI 可以承担大量搜索、计算、实验规划和模式发现工作。但必须强调，**假设生成速度不等于科学知识增长速度。**

如果 AI 能迅速生成一百万个候选理论，却无法进行严谨验证，科学仍然可能陷入大规模的选择偏差和伪发现。未来实验科学很可能更加重视可复现性、因果识别、独立验证和不确定性控制。

### 11.3 未来科学中人类的角色

我认为人类科学家的价值会越来越集中于三个方面。

1. **提出真正重要的问题**，而不是盲目优化已有指标。
2. **发明新的抽象和表示方式**，而不只是增加算法搜索量。
3. **判断什么样的证据足以支持某个科学结论**。

AI 可以帮助科学家快速探索大量候选规律，但科学的评价标准仍然需要围绕证据、可检验性及真实世界的解释能力建立。

## 十二、统一的科学哲学：接受复杂性，寻找可约性，研究能力边界

回到这场讨论的起点。我们最初的直觉是：

世界既然由数学规律支配，为什么不能通过数学轻松求出未来？

三体问题让我们意识到，规律简单不等于计算简单。计算不可约性进一步提出，有些演化过程可能不存在可以显著跳过的计算捷径。解析几何和群论提醒我们，有时最伟大的突破不是更努力地计算，而是改变问题的表示方式。统计力学和重整化群则告诉我们，即使微观世界极其复杂，宏观层面仍可能存在简单的有效规律。

现代统计学进一步表明，不必依赖完全正确的理想化模型，也可以在明确的条件下获得可靠的有限样本结论。因果推断和强化学习则把重点从完整预测世界，转向支持干预与行动。这些思想可以汇总为一套新的科学问题分类。

### 12.1 科学问题的五种复杂度

| 维度       | 要回答的问题             | 代表理论               |
| -------- | ------------------ | ------------------ |
| 描述复杂度    | 描述一个对象或规律，需要多少信息？  | Kolmogorov 复杂度、信息论 |
| 计算复杂度    | 计算答案，需要多少运算？       | 计算复杂性、算法理论         |
| 统计复杂度    | 估计规律，需要多少数据？       | 非渐近统计、极小极大理论       |
| 识别与实验复杂度 | 区分不同机制，需要怎样的观测或干预？ | 因果推断、实验设计          |
| 决策复杂度    | 在不确定环境中，如何有效行动？    | 决策理论、控制、强化学习       |

它们并不是同一种复杂性的不同名称，而是互相关联又不可相互替代的限制。

例如：

- 一个系统可能有极短的描述，却需要极高的计算成本。
- 一个目标可能计算非常容易，却因为缺乏信息而不可识别。
- 一个预测模型可能有很高的准确率，但不能直接回答因果干预问题。
- 一个完整模型可能很难建立，而一个直接优化决策的模型却已经足够有用。

因此，未来科学的重要工作之一，可能就是研究这些限制之间的关系。

### 12.2 未来科学不仅研究自然，也研究认识自然的代价

可以考虑一个统一的研究框架。假设我们具有样本量 $`n`$、计算预算 $`B`$、实验资源 $`E`$，并面临一类可能的数据生成机制 $`\mathcal P`$。我们希望找到满足这些限制的研究或决策程序：

```math
(\mathcal A^*,\pi^*) = \arg\min_{\mathcal A,\pi} \sup_{P\in\mathcal P} \mathbb E_P[L(\mathcal A,\pi;P)]
```

要求：

```math
\begin{aligned}
\mathrm{Cost}_{\text{compute}} &\le B, \\
\mathrm{Cost}_{\text{experiment}} &\le E.
\end{aligned}
```

这里 $`\mathcal A`$ 表示估计或计算程序，$`\pi`$ 表示实验或行动策略。严格形式化时还必须指定观测模型、允许的算法及损失函数。这一框架把问题从：

 > 「答案是什么？」

扩展为：

> **在我们拥有的知识和资源条件下，最好能够知道什么、预测什么，以及采取什么行动？**

我认为这是一种非常具有代表性的现代科学思想。

## 十三、科学研究可以遵循的七条原则

将上述理论落到实际科研，我会总结为七条方法论原则。

1. **先明确目标，再选择模型。**  
   研究需要精确轨迹、统计规律、因果解释，还是最优决策？不同目标需要不同方法。

2. **主动寻找结构，而不是盲目增加计算。**  
   检查对称性、守恒量、稀疏性、低维表示和可利用的宏观变量。

3. **区分信息不足和计算不足。**  
   无论计算机有多强，都无法从根本不可识别的数据中恢复唯一答案。

4. **使用最小必要假设。**  
   不把方便计算的假设误认为现实世界的真实结构。

5. **研究模型失效的边界。**  
   不只验证模型何时有效，也要明确其适用条件、误差界和脆弱性。

6. **在计算昂贵时，考虑改变问题。**  
   研究更有价值的宏观量、近似目标或决策变量，而不是执着于完整求解。

7. **建立持续反馈的研究系统。**  
   通过实验、样本外验证和新证据不断修正模型，而不是把一次性的拟合结果当作终极真理。

## 最终结论：科学并不是从简单走向复杂，而是从朴素走向成熟

经过这系列讨论，我认为需要避免两种极端。

**第一种极端是：**

相信世界必然存在某个足够简单的公式，只要数学足够发达，我们就能轻易预测一切。三体问题、混沌与计算复杂性提醒我们，这种期待未必成立。

**第二种极端则是：**

因为世界复杂，就认为只有复杂模型、大规模计算和黑箱 AI 才能逼近真实。这同样不正确。统计力学、群论、重整化群和现代统计学恰恰说明，寻找可约结构、有效抽象与可靠的局部结论，仍然是科学最强大的能力。 

**所以，未来科学的成熟，并不是放弃简单性，而是改变我们对简单性的态度。**

不再预先相信世界必须简单，而是主动研究：

> **哪些复杂性是本质的？**  
> 哪些结构允许简化？  
> 哪些计算可以避免？  
> 哪些知识可以可靠获得？  
> 哪些问题必须重新表述？

我想用三个层次概括科学思想的发展：

### 第一层 · 描述世界

**世界遵循什么规律？**

牛顿力学、经典数学、物理定律。

### 第二层 · 理解结构与极限

**这些规律允许我们知道什么？**

群论、动力系统、统计学、计算复杂性。

### 第三层 · 有效认识与行动

**在有限知识和资源下，如何最好地探索与行动？**

因果实验、稳健决策、主动学习、AI 科研。

这三个层次不是互相取代，而是共同组成更加完整的科学方法。我们的整场讨论最终可以浓缩成一句话：

> 承认世界的复杂性，寻找真实存在的简单结构；承认认识和计算的极限，通过新的抽象、严谨的统计推断与持续实验，获得尽可能可靠的知识和有效的决策。

科学最伟大的时刻，未必是终于解开一道困扰人类几百年的难题。它也可能是像解析几何和 Galois 理论那样，突然发现一种新的数学语言，让我们意识到：原来应该研究的，并不是那道题的答案，而是决定一整类问题能否得到答案的结构。
